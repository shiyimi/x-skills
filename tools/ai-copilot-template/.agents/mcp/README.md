# MCP

本目录用于记录项目外部工具和 MCP 接入方式。

## 维护要求

- MCP/tool 配置按项目用户填写内容原样维护。
- AI 不主动改写 `env` 字段，不强制迁移为环境变量。
- 调整 MCP 配置前，先确认会影响哪些工具接入。
- 不为了“规范化”拆分、合并或重写用户已有 MCP 配置。

## 建议格式

```json
{
  "mcpServers": {
    "SERVER_NAME": {
      "command": "<COMMAND>",
      "args": ["<ARG_1>", "<ARG_2>"],
      "env": {
        "ACCESS_TOKEN": "<USER_CONFIGURED_VALUE>"
      }
    }
  }
}
```
