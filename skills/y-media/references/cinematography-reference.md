# 影视要素词典 · Cinematography Reference

> 本文件是分镜表每一列的**参数化填写词典**。当 [storyboard-methodology.md](storyboard-methodology.md) §3 要求"方向 + 色温 + 光比 + 光质"时,从这里取具体数值与术语,不要写"暖光""柔和"这种无参数形容词。与 [influence-factors.md](influence-factors.md) 配合使用:本词典定义"填什么",影响因子定义"填到什么程度才有效"。

---

## 1. 景别 Shot Size

景别决定信息密度与情绪距离。竖屏 9:16 下景别取舍与横屏不同——竖构图天然压缩横向空间,中近景以上才填得满画面。

| 景别 | 主体占比 | 等效焦段(全画幅) | 情绪功能 | 适用骨架 |
| --- | --- | --- | --- | --- |
| 大远景 ELS | <10% | 14-24mm 广角 | 建立环境、渺小感、史诗 | B 起/合、C 转 |
| 远景 LS | 10-25% | 24-35mm | 交代人物与环境关系 | B 起、A 收 |
| 全景 FS | 25-50% | 35-50mm | 完整动作、肢体语言 | A 演示、B 承 |
| 中景 MS | 50-60%(膝/腰以上) | 50-85mm | 对话、日常感、社交距离 | A 卖点、B 承 |
| 中近景 MCU | 60-75%(胸以上) | 85-100mm | 亲密对话、表情初现 | A 核心、B 转 |
| 近景 CU | 75-90%(面部为主) | 100-135mm | 情绪、微表情 | B 转、C 转 |
| 特写 BCU | >90%(局部) | 135mm+ 微距 | 细节爆点、感官冲击 | A 高潮、ASMR |
| 极特写 ECU | 单一纹理 | 微距镜头 | 质感、ASMR、抽象 | A 高潮、ASMR |

**机位角度**(与景别组合写):平视 eye-level(中性)、仰拍 low-angle(力量/崇拜)、俯拍 high-angle(脆弱/支配)、鸟瞰 bird's-eye(抽象/上帝视角)、荷兰角 Dutch angle(不安/动感)。

**填写范式**: `中近景·略低角度(机位略低于主体,仰10°)` —— 景别 + 角度 + 具体度数/参照。

## 2. 运镜 Camera Movement

一镜最多 2 种运动组合(§3 反模式);运动必须带速度与方向,否则模型给默认匀速。

| 运镜 | 英文 | 写法范式 | 情绪 | 注意 |
| --- | --- | --- | --- | --- |
| 推 | dolly-in / push-in | `缓推(dolly-in),由远及近,速度0.3m/s` | 聚焦、压迫、亲密 | 速度>0.8m/s 显急促 |
| 拉 | dolly-out / pull-out | `缓拉(dolly-out),由近及远,速度0.4m/s` | 释放、疏离、收束 | 收尾镜常用 |
| 摇 | pan(水平)/ tilt(竖直) | `平摇(pan),自左向右,角速度15°/s` | 环顾、跟随、揭示 | 竖屏少用大范围pan |
| 移 | tracking / trucking | `横移跟拍(tracking),自左向右,速度1.2m/s` | 并行、陪伴、流动 | 速度与主体同步 |
| 升降 | crane / jib | `缓升(crane-up),高度从1m到3m,2s` | 升华、俯瞰、仪式 | 竖屏收尾镜高效 |
| 环绕 | arc shot / orbit | `环绕小角度(arc,约45°弧),速度0.5m/s` | 立体感、欣赏、定格高光 | 全环绕(360°)慎用,易晕 |
| 手持 | handheld | `手持微晃(handheld),幅度±2°,频率0.5Hz` | 纪实、紧张、在场 | 治愈片慎用 |
| 斯坦尼康 | Steadicam | `稳定器跟拍(Steadicam),速度1.0m/s` | 流畅、专业、电影感 | 默认流畅首选 |
| 变焦 | zoom in/out | `缓变焦(zoom-in),24mm→85mm,3s` | 压缩空间、揭示 | 慎用,易显廉价;推拉更自然 |
| 固定 | static / locked-off | `固定(static)` | 凝视、稳定、留白 | 特写/ASMR 常用 |

**组合范式**: `固定+微推(static + micro push,推程0.2m)` —— 主运动 + 副运动 + 量化参数。

**速度参考**: 静止 0 / 极慢 0.1-0.3m/s / 缓 0.3-0.6m/s / 中 0.6-1.2m/s / 快 1.2-2.0m/s / 冲刺 >2.0m/s。

## 3. 光影 Lighting

光影是视频生成中最容易被模型做差的一层。必须写满四要素:**光位 + 色温 + 光比 + 光质**。

### 3.1 光位 Light Position

| 光位 | 角度 | 效果 | 适用 |
| --- | --- | --- | --- |
| 正面光 | 0°(相机方向) | 平坦、清晰、去阴影 | 美妆、产品正面 |
| 侧光 | 45-90° | 立体感、质感、阴影 | 通用首选 |
| 侧逆光 | 90-135° | 轮廓勾边、氛围 | 人物/动物毛发、玻璃 |
| 逆光 | 135-180° | 剪影、发丝光、通透感 | 治愈、唯美、高光镜 |
| 顶光 | 正上方 | 戏剧、雕塑感、眼窝阴影 | 高潮、力量 |
| 底光 | 正下方 | 恐怖、诡异、审讯 | 慎用 |
| 环境光 | 无方向 | 均匀填充、去死角 | 补光用,不单独用 |

**三点布光**(人像/产品标准):主光 key(45°侧,最强) + 辅光 fill(对侧,弱,降阴影) + 轮廓光 rim/back(逆光,勾边)。写法: `主光45°侧+辅光对侧+轮廓光150°逆光,主:辅=2:1`。

### 3.2 色温 Color Temperature

| 色温 | 视觉 | 时段/场景 | 情绪 |
| --- | --- | --- | --- |
| 2000-3000K | 烛光橙黄 | 烛光、夜景暖灯 | 温馨、私密 |
| 3000-4000K | 暖白 | 室内暖灯、黄昏 | 温暖、居家 |
| 4000-5000K | 中性白 | 清晨、室内日光 | 自然、中性 |
| 5000-5600K | 日光白 | 正午、晴天 | 清晰、真实 |
| 5600-6500K | 冷白 | 阴天、阴影 | 冷静、专业 |
| 6500-7500K | 蓝白 | 雪景、高海拔 | 清冷、孤寂 |
| 7500K+ | 深蓝 | 赛博、夜景冷调 | 科技、疏离 |

**填写范式**: `4500K` 写具体数值,不写"暖光"。同片色温漂移控制在 ±300K 内(刻意转场除外)。

### 3.3 光比 Lighting Ratio

主光与辅光的亮度比,决定对比度与戏剧性。

| 光比 | 效果 | 适用 |
| --- | --- | --- |
| 1:1 | 平坦、无阴影 | 美妆、产品均匀 |
| 2:1 | 自然、柔和 | 通用、治愈、日常 |
| 3:1 | 立体、有戏剧 | 人像、叙事 |
| 4:1-8:1 | 强对比、电影感 | 高潮、悬疑 |
| 8:1+ | 剪影、极戏剧 | 逆光剪影、艺术 |

### 3.4 光质 Light Quality

| 光质 | 特征 | 实现 | 适用 |
| --- | --- | --- | --- |
| 硬光 hard | 边缘锐利、阴影深、高对比 | 直射光/聚光灯 | 力量、戏剧、男性 |
| 柔光 soft | 边缘模糊、阴影浅、过渡渐 | 柔光箱/漫射/阴天 | 治愈、美妆、女性、儿童 |
| 半硬 semi | 介于两者 | 反射伞/透光板 | 通用 |

**填写范式**: `清晨侧逆光·4500K·柔光·光比3:1(逆光勾边)` —— 光位·色温·光质·光比(+ 功能注释)。

### 3.5 时段光(自然光参考)

| 时段 | 色温 | 角度 | 特征 |
| --- | --- | --- | --- |
| 蓝调时刻 blue hour(日出前/日落后) | 8000-10000K | 低 | 蓝紫漫射,柔和静谧 |
| 黄金时刻 golden hour(日出后/日落前1h) | 3200-4000K | 15-30° | 暖金长投影,治愈首选 |
| 正午 harsh noon | 5500K | 90° | 顶光硬阴影,少用 |
| 下午 late afternoon | 4500-5000K | 45-60° | 中性自然,通用 |
| 阴天 overcast | 6000-7000K | 漫射 | 柔光无影,人像友好 |

## 4. 色彩 Color

### 4.1 色彩三要素

| 要素 | 范围 | 填写 |
| --- | --- | --- |
| 色相 hue | 色轮位置 | 主色+辅色命名(嫩绿+暖金) |
| 饱和度 saturation | 0-100(或±dB) | `饱和度+10` / `降饱和-15` |
| 明度 luminance | 0-100 | `明度+5`(亮)/ `明度-10`(暗) |

### 4.2 调色风格 LUT 参考

| 风格 | 色板 | 情绪 | 适用 |
| --- | --- | --- | --- |
| 自然真实 | 原色,饱和±0 | 真实、纪录 | 自然、产品 |
| 暖治愈 | 暖金+嫩绿,饱和+10 | 温暖、治愈 | 治愈、亲子、动物 |
| 冷质感 | 青蓝+灰白,饱和-10 | 高级、疏离 | 科技、极简 |
| 复古胶片 | 橙青对比,颗粒,饱和-5 | 怀旧、文艺 | 生活、溯源 |
| 高饱和燃 | 红黄+高对比,饱和+20 | 燃、冲击 | 带货、开箱 |
| 黑金 | 黑底+金,低饱和 | 奢华、高级 | 珠宝、奢品 |
| 莫兰迪 | 灰调低饱和,明度+5 | 安静、高级 | 家居、氛围 |

### 4.3 配色策略

- **单色系**: 同色相不同明度,统一安静(治愈/氛围)
- **邻近色**: 色轮相邻,和谐(自然/生活)
- **互补色**: 色轮对角,冲击(视觉爆点/对比)
- **三色**: 色轮等分,丰富但难控(慎用,信息流易乱)

**填写范式**: `嫩绿主+暖金辅,天空淡橙→淡蓝渐变,饱和度+10` —— 主色+辅色+渐变/对比+饱和偏移。

## 5. 声音 Sound

视频生成的音频三层(人声/环境/BGM)各自有参数化填写标准。

### 5.1 音量参考 dB

| dB | 听感 | 参考 |
| --- | --- | --- |
| 0 dBFS | 削波失真 | 绝对上限 |
| -6 dB | 很响 | 爆点音效、CTA |
| -12 dB | 响 | BGM 高潮 |
| -16 dB | 中 | BGM 主体 |
| -20 dB | 轻柔 | 环境音主体 |
| -24 dB | 轻 | 人声私语、远景环境 |
| -30 dB | 极轻 | 底噪、收尾余韵 |
| -60 dB | 几乎无声 | 静音留白 |

**相对关系**: BGM -16dB 时,人声通常 +6dB(-10dB),环境音 -6dB(-22dB)。爆点前可全降 6-12dB 反衬。

### 5.2 人声 Voice

| 类型 | 写法 | 参数 |
| --- | --- | --- |
| 有对白 | `女声25-30,达人语气,每句1次换气,"关键词"前0.3s微停,尾字气音收尾,比BGM高6dB,避免播音腔` | 年龄+语气+换气+停顿+尾音+音量+反播音腔 |
| 纯OS心声 | `男声低沉30-35,内心独白感,慢速0.8x,气声,比BGM高3dB` | 年龄+质感+语速+气声+音量 |
| 无对白 | `无对白 · 镜2转身呼气(-24dB)/镜4微笑吸气(-27dB)/镜5衣物摩擦(-22dB)` | 标注生理音+时机+dB |

### 5.3 环境音 Ambient / SFX

每镜 2-3 个可辨识拟声词 + 关键音效点单独标。

| 场景 | 拟声词库 |
| --- | --- |
| 自然-草地 | 沙沙、窸窣、簌簌 |
| 自然-水 | 潺潺、哗啦、滴答、咕嘟 |
| 自然-风 | 呼、嗖、呜 |
| 动物-蹄 | 嗒嗒、嘚嘚、铛铛 |
| 动物-鸣 | 嘶、唧、啾、啼 |
| 食物-咀嚼 | 咔嚓、嘎嘣、吧唧 |
| 食物-烹饪 | 嗞啦、咕嘟、噗 |
| 包装 | 嘶啦、咔哒、噗 |
| 布料 | 沙沙、唰、窸窣 |
| 玻璃/陶瓷 | 叮、叮当、咔 |

**音效点写法**: `音效点(镜3·2.5s): 裙摆"沙沙"加重3dB` —— 镜次·时机·音效名·处理。

### 5.4 BGM

四字段必填:**风格(乐器+BPM) + 情绪 + 入点/淡出时点 + 关键节点**。

| 风格皮肤 | 乐器 | BPM | 情绪 |
| --- | --- | --- | --- |
| 清新民谣 | 木吉他+钟琴 | 90-110 | 治愈、轻快 |
| 暖流行 | 钢琴+弦乐+鼓 | 100-120 | 温暖、上行 |
| 钢琴独奏 | 钢琴 | 60-80 | 高级、孤独 |
| 氛围 pad | 合成器pad | 60-80 | 氛围、空灵 |
| 鼓点build-up | 电子鼓+合成器 | 110-140 | 燃、爽、卡点 |
| 暖民谣 | 木吉他+口琴 | 65-90 | 温情、怀旧 |
| 古风 | 古琴+尺八+民乐 | 60-80 | 溯源、匠作 |
| trap | 鼓机+808bass | 100-130 | 酷、街头 |

**写法范式**: `清新民谣(木吉他+钟琴,95BPM,无歌词) · 轻快治愈 · 0s入3s到-18dB · 镜3副歌推满·镜6淡出至-30dB`。

## 6. 剪辑节奏 Editing Rhythm

### 6.1 镜长与节奏

| 节奏 | 单镜时长 | 镜数/15s | 适用 |
| --- | --- | --- | --- |
| 极快 | 0.8-1.5s | 10-12 | 带货卡点、开箱 |
| 快 | 1.5-2.5s | 7-9 | 测评、利益 |
| 中 | 2.5-4.0s | 5-6 | 种草、叙事 |
| 慢 | 4.0-6.0s | 3-4 | 品牌、氛围、ASMR |
| 极慢 | >6s | 2-3 | 艺术、长镜头 |

### 6.2 转场(生成模型少用硬转场,多用运动接续)

| 转场 | 写法 | 适用 |
| --- | --- | --- |
| 动作匹配 | 上一镜动作延续到下一镜 | 叙事流畅 |
| 运动接续 | 上一镜运镜方向=下一镜运镜方向 | 模型直出首选 |
| 光线接续 | 上一镜末光=下一镜首光 | 色温连续 |
| 焦点转换 | 上一镜失焦=下一镜聚焦 | 柔和过渡 |
| 硬切 | 直接切换 | 快节奏,慎用 |
| 淡入淡出 | `0.3s交叉淡入` | 段落分隔 |

### 6.3 情绪曲线(15s 范式)

```
骨架A(带货): 高起→维持→7s爆点→收CTA
骨架B(叙事): 缓起→渐升→7s情绪反转→收束
骨架C(共鸣): 痛点起→堆积→7s转折→金句收
```

## 7. 构图 Composition

竖屏 9:16 构图与横屏差异大,主体放置与留白逻辑不同。

| 构图法 | 写法 | 适用 |
| --- | --- | --- |
| 三分法 | 主体置于三分线交点 | 通用 |
| 中心构图 | 主体居中 | 产品、特写、竖屏人物 |
| 引导线 | 环境线条指向主体 | 风景、纵深 |
| 框架构图 | 前景框住主体 | 层次、窥视 |
| 留白 | 主体占<40%,大量负空间 | 氛围、极简、高级 |
| 满构图 | 主体>80% | 冲击、特写、ASMR |
| 对称 | 左右/上下对称 | 仪式、稳定 |

**前景/中景/背景三层**(§3 道具/环境列):竖屏必须有明确前景(虚焦),否则画面扁平。写法: `前景:带露珠的草尖(虚焦)/中景:小马驹/背景:远山+晨雾`。

## 8. 焦段与景深 Focal Length & DoF

| 焦段(全画幅等效) | 景别 | 景深 | 压缩感 |
| --- | --- | --- | --- |
| 14-24mm 超广角 | 大远景 | 深 | 拉伸、戏剧 |
| 24-35mm 广角 | 远景-全景 | 深-中 | 自然、环境感 |
| 35-50mm 标准 | 全景-中景 | 中 | 接近人眼 |
| 50-85mm 中焦 | 中景-中近景 | 中-浅 | 略压缩、人像友好 |
| 85-135mm 长焦 | 中近景-特写 | 浅 | 压缩、虚化、电影感 |
| 135mm+ 长焦 | 特写 | 极浅 | 强压缩、梦幻虚化 |

**竖屏建议**: 16mm(广角建立环境)↔ 85mm(中焦特写)之间切换,跨度过大(如16mm↔200mm)模型易出错。浅景深是竖屏虚化背景、突出主体的关键。

## 9. 帧率与快门 Frame Rate & Shutter

| 参数 | 取值 | 效果 |
| --- | --- | --- |
| 帧率 fps | 24 | 电影感、运动模糊 |
| | 30 | 电视感、清晰 |
| | 60 | 流畅、运动、游戏 |
| | 120+ | 慢动作素材 |
| 快门角度 | 180° | 标准运动模糊(24fps→1/48s) |
| | 90° | 清晰、运动定格 |
| | 360° | 重模糊、梦幻 |

**填写范式**: `24fps,快门180°` 写进全局约束,模型据此给运动模糊。

## 10. 主体描述 Subject Description

主体描述决定模型生成的保真度。抽象词→随机;具体词→稳定。

| 维度 | 抽象(避免) | 具体(采用) |
| --- | --- | --- |
| 动物 | "一匹小马" | "约6个月大的小马驹,棕白相间,鬃毛蓬松,四肢修长" |
| 人物 | "一个女孩" | "25岁亚洲女性,齐肩黑发,圆脸,穿米白棉麻连衣裙" |
| 产品 | "一瓶香水" | "50ml透明方瓶香水,金色金属瓶盖,淡琥珀色液体,瓶身刻字'XX'" |
| 食物 | "一块蛋糕" | "6寸草莓奶油蛋糕,白色抹面,顶部3颗鲜草莓,侧切露出双层海绵" |
| 场景 | "一片草地" | "清晨草甸,嫩绿草尖带露珠,零星白色雏菊与黄色蒲公英,远处低矮丘陵" |

**锁定原则**(系列一致性): 主体描述词全片/全系列锁同一套,改一个词模型就漂移。

## 11. 约束块 Constraint Block

每条 prompt 末尾必须有约束块,告诉模型"不要什么"。结构:

```
全局约束: 避免纯色渐变背景,避免棚拍空盒子感;色调从X自然过渡到Y,过渡流畅不跳戏;[路线约束:字幕/无字幕];[主体物理约束];[技术参数:fps/快门/景深/焦段];[情绪约束]。
```

**有效约束**(具体可执行): `禁止恐怖谷或畸形马匹` / `24fps,快门180°` / `禁止出现任何文字`。

**无效约束**(抽象难执行): `要有高级感` / `画质要好` / `自然一点`。
