## 1. 场景定性

| 维度 | 内容 |
| --- | --- |
| 板块共性 | 产品外观 + 卖点细节 + 利益点证明;**主体识别度 100%** |
| 首选骨架 | 骨架A showcase(9-12 镜,1.0-2.5s,信息密);少数走骨架B(高客单/品牌) |
| 视听路线 | 含字幕(卖点/价格/规格);**含 6 类字幕**全部上场(钩/数据/背书/CTA) |
| 路径选择 | ① **G 纯生成**(无实拍) ② **H 分段混合**(产品实拍 + 场景 AI) ③ **E 纯剪辑**(实拍已备) |
| 叙事禁区 | 避免过度修图/穿模/塑料感;避免对标竞品拉踩;避免医疗/极限承诺 |
| 美学母体 | 取决于品类(见 §2 子场景);共通:**主体居中 + 背景虚化 + 单一光源** |

### 1.1 商业场景的"产品四元素"清单(每条带货视频必填)

| 元素 | 含义 | 展示层写法 | 典型位置 |
| --- | --- | --- | --- |
| **外观(Look)** | 颜色/形状/材质/工艺 | 主色 + 辅色 + 工艺特征 | 镜1 钩子镜 / 镜3 卖点镜 |
| **功能(Function)** | 解决什么问题/怎么用 | 使用动作 + 前后对比 | 镜4 利益镜 / 镜5 场景镜 |
| **信任(Proof)** | 资质/销量/成分/产地 | 数据 + 品牌 + 第三方 | 镜6 背书镜 |
| **驱动(Hook)** | 价格/优惠/限时/限量 | 价格锚 + 紧迫文案 | 镜7 CTA 镜 / 镜8 收尾镜 |

> **自检**:四元素在 15s 内都要出现(可以合并到同一镜,但要 0.5-2s 闪过);**任一缺失 = 转化率断崖**。

## 2. 子场景卡片(6 大品类,按需路由)

### 2.1 美妆个护(Beauty & Personal Care)

- **场景定性**: 细节 + 质地 + 前后对比 + 强 i2v
- **首选骨架**: 骨架A(9-12 镜,1.0-2.5s)
- **光影模板**: 环形灯 5000K(质地特写) / 侧光 4500K(模特局部)
- **音频皮肤**: 清新流行(木吉他+钟琴,90-110BPM) / 美妆品牌独有"开盖音"
- **7秒高潮点**: 质地特写(乳液/精华/口红色)/ 上脸瞬间 / 前后对比同框
- **典型 6 镜**:
  1. 镜头特写产品外观(钩子镜)★ 2. 质地特写(挤/抹/涂)★ 3. 上脸/上手 micro-action ★
  4. 前后对比同框 5. 资质/成分字幕 6. 价格+CTA ★
- **环境模板(3+1)**: 浅色大理石台面 / 化妆镜 / 绿植 + 顶光柔光
- **AI 生成禁区**: 化妆品穿模/塑料感;人物面部变形;颜色过艳
- **品牌名零错字**:R5 铁律,品牌/成分/SPF 值逐字核对

### 2.2 服饰穿搭(Fashion & Accessories)

- **场景定性**: 强 i2v + 多角度 + 细节材质
- **首选骨架**: 骨架A(快切换装) / 骨架B(品牌大片,5-7 镜)
- **光影模板**: 街拍侧光 4500K(自然感) / 棚拍柔光 5000K(质感)
- **音频皮肤**: 时尚电子 / 鼓点 build-up / 清新民谣(看调性)
- **7秒高潮点**: 变装瞬间 / 转身动态 / 细节拉链/缝线
- **典型 6 镜**:
  1. 街拍远景(氛围) 2. 中景走动 ★ 3. 细节(面料/缝线/拉链)★ 4. 转身 / 回头 ★
  5. 多角度同框 6. 价格+CTA ★
- **环境模板(3+1)**: 城市街景 / 棚拍背景 / 镜面 + 自然光或环形灯
- **AI 生成禁区**: 服饰穿模/错位;品牌 logo 变形;面料塑料感
- **i2v 必填**:产品图/真人图作为 §6.1 输入,锁主体一致

### 2.3 家居家纺(Home & Living)

- **场景定性**: 场景化 + 治愈 + 真实使用
- **首选骨架**: 骨架B慢切(5-7 镜,2-4s)/ 骨架A(快切卖点)
- **光影模板**: 侧窗 4000K(早午餐)/ 顶光 4500K(卧室/客厅)
- **音频皮肤**: 钢琴独奏 / 暖民谣(治愈感) / ASMR 极淡(质感)
- **7秒高潮点**: 阳光洒入 / 蒸汽升腾 / 拉链/折叠动作
- **典型 5 镜**:
  1. 房间全景(钩子)★ 2. 产品入镜(中景)★ 3. 使用 micro-action(铺/折/擦)★
  4. 细节特写(材质/缝线) 5. 价格+CTA ★
- **环境模板(3+1)**: 实木家具 / 亚麻布 / 绿植/鲜花 + 侧窗自然光
- **AI 生成禁区**: 房间穿模/物品漂浮;塑料感;品牌 logo 错误

### 2.4 数码家电(Tech & Appliances)

- **场景定性**: 参数 + 实测 + 强对比
- **首选骨架**: 骨架A(9-12 镜,1.0-2.0s)/ 骨架B(高端长测评,5-7 镜)
- **光影模板**: 顶光 5000K(科技感)/ 暗背景顶光(高端展示)
- **音频皮肤**: 合成器电子(脉冲音效,115-130BPM)/ 极淡科技 pad
- **7秒高潮点**: 开机/启动瞬间 / 数据飞涨 / 屏幕特写
- **典型 6 镜**:
  1. 产品全景(暗背景,科技感)★ 2. 开机/启动(声音+画面同步)★ 3. 屏幕特写
  4. 实测对比(左旧右新)★ 5. 数据/参数字幕(数字逐字) 6. 价格+CTA ★
- **环境模板(3+1)**: 暗色桌面 / 数字屏幕 / 线材 + 顶光
- **AI 生成禁区**: 屏幕内容穿模/乱码;按钮/接口错位;数字乱跳
- **数字零错字**:参数/价格/型号逐字核对(R5 铁律)

### 2.5 母婴亲子(Baby & Family)

- **场景定性**: 温情 + 安全 + 信任背书
- **首选骨架**: 骨架B慢切(5-7 镜,2-4s)/ 骨架C(共情)
- **光影模板**: 暖光 3500K(母婴安全)/ 侧窗 4000K(亲子日常)
- **音频皮肤**: 弦乐+钢琴+暖民谣(65-90BPM)/ 钟琴(温馨)
- **7秒高潮点**: 宝宝笑 / 妈妈抚触 / 安全感细节
- **典型 5 镜**:
  1. 宝宝/亲子日常(钩子)★ 2. 产品特写(奶粉/纸尿裤/玩具)★ 3. 使用 micro-action ★
  4. 安全/成分字幕(资质、成分、认证) 5. 价格+CTA ★
- **环境模板(3+1)**: 婴儿房 / 木质玩具 / 棉织物 + 暖光
- **AI 生成禁区**: 宝宝面部穿模(伦理高敏);颜色过艳(母婴敏感);危险动作
- **真实宝宝慎用 AI**:涉及 0-3 岁宝宝面部建议走 E 纯剪辑路径(§1.2),AI 生成禁用

### 2.6 通用带货 / 通用产品演示(Generic Product Demo)

- **场景定性**: 跨品类 / 无明确品类归属 / 试用品
- **首选骨架**: 骨架A(9-12 镜)
- **光影模板**: 顶光 4500K 柔光(通用安全牌)
- **音频皮肤**: 鼓点 build-up + drop(转化) / 清新民谣(种草)
- **7秒高潮点**: 产品开箱 / 核心功能 / 价格爆点
- **典型 6 镜**:
  1. 开箱瞬间(钩子)★ 2. 产品全景 ★ 3. 核心功能 micro-action ★
  4. 前后/同框对比 5. 数据/资质 6. 价格+CTA ★
- **环境模板(3+1)**: 浅色背景 / 木质桌面 / 极简道具 + 顶光
- **AI 生成禁区**: 通用翻车点(穿模/塑料感/颜色异常)

**静音法则(§4.4)在商业场景的典型应用**:

- 转化类末镜:钟琴淡出只留环境音(M3),留余韵

## 7. 字幕设计(商业场景必须含字幕)

> §5 已经定义了 6 类字幕与 5 风格锁定,商业场景**6 类全用**。

| 类型 | 商业场景必用 | 示例(美妆) |
| --- | --- | --- |
| ① 钩子 | ✓ 0-2s 痛点问句 | "敏感肌能用吗?" |
| ② 数据/卖点 | ✓ 核心镜 3-7 | "1.5% 玻色因" |
| ③ 信任背书 | ✓ 中后段 | "国家药监局备案" |
| ④ CTA | ✓ 末镜 | "前1000名立减50" |
| ⑤ 氛围/口播同步 | — (无真人) | — |
| ⑥ 金句/治愈收尾 | — (商业转化类一般不用) | — |

**5 风格锁定(商业场景默认)**:

- 字体:思源黑体 Bold / 阿里巴巴普惠体
- 色板:主白 `#FFFFFF` + 卖点金 `#FFD700`(≤2 色)
- 位置:钩子/CTA 居中,数据卖点下 1/3
- 动画:弹入放大 0.3s + 停留 1.5s + 缓淡出 0.3s
- 描边:黑边 2px(保证亮/暗背景都可读)

**R5 零错字铁律**:

- 品牌名/型号/成分/SPF 值/价格/资质/限量数字 **逐字核对**
- 长品牌名(如 "ESTĒE LAUDER 雅诗兰黛")按引号 `"ESTĒE LAUDER 雅诗兰黛"` 写入 prompt,模型逐字渲染
- 数字单位(99元/1mm/24h)逐字核对,不简写
- 任何"全球第一/销量冠军"等绝对化用语**禁用**(广告法)

## 8. 反模式(商业场景常见翻车点)

| 反模式 | 症状 | 修复 |
| --- | --- | --- |
| 产品穿模 | 物品漂浮/穿插 | 加 `product keeps natural shape, no deformation, no floating` |
| 塑料感 | 颜色过饱和/反光异常 | 降饱和 -5,加 `natural material texture, no plastic look` |
| 品牌错字 | 品牌名拼错/logo 变形 | 强制 R5,品牌/型号逐字核对 |
| 数字乱跳 | 价格/规格/容量错乱 | 数字逐字核对,加 `numbers and brand names in quotes must be rendered exactly as written` |
| 价格无紧迫感 | 转化类不给优惠锚 | CTA 加 `前 N 名 / 仅限今日 / 限时 24h` |
| 真人面部变形 | 模特脸/手穿模 | 涉及真人的走 E 纯剪辑,AI 不出镜;走 H 路径时用手部/局部特写代替 |
| 颜色过艳 | 美妆/服饰过饱和 | 降饱和 -5 ~ -10,加 `natural skin tone, natural fabric color` |
| 背景太花 | 产品被背景抢戏 | 背景虚化 + 浅色系,主体占画面 50%+ |
| 静音用错 | 静音卡错位置 | 静音法则 §4.4:价格爆点前/数据字幕前/质感末镜;其他位置 BGM 满 |
| 0-3 岁宝宝面部 AI 生成 | 伦理高敏 | 走 E 纯剪辑,AI 不生成;局部特写(手脚/产品)可以 AI |

## 9. 商业场景的合规清单(发布前必查)

| 维度 | 必查 |
| --- | --- |
| 广告法 | 无"最/第一/国家级/销量冠军"等绝对化用语 |
| 品牌名 | 逐字核对,逐字渲染 |
| 价格/优惠 | 数字 + 单位 + 期限均明确 |
| 资质/认证 | 有据可查,不可伪造 |
| 功效 | 不做医疗承诺;化妆品不写"治疗" |
| 母婴 | 不出现 0-3 岁宝宝面部(AI 生成禁用) |
| 版权 BGM | 不直接用《Faded》等版权曲,改无版权皮肤 |
