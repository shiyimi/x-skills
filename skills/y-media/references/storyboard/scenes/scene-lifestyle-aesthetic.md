## 2. 子场景卡片

### 2.1 晨间日常(早安/咖啡/晨光)

- **场景定性**: 慢节奏 + 光影疗愈 + 日常仪式
- **光影模板**: 侧窗光 4000K 柔光光比 2:1 / 晨光 3500K 金色侧光
- **音频皮肤**: 暖民谣 65-90BPM / 钢琴独奏 60-80BPM / 环境音为主 BGM 极淡
- **7秒高潮点**: 蒸汽升腾 / 咖啡注入 / 阳光斜入的瞬间光斑
- **典型 3 镜**: 窗外晨光(中远景)→ 手冲咖啡蒸汽(特写)→ 端杯轻啜(中近景)
- **环境模板(3+1)**: 木质餐桌 / 棉麻桌布 / 陶瓷杯具 + 一束小花/绿植
- **AI 生成禁区**: 商业过曝、棚拍纯色背景、塑料感

### 2.2 家居氛围(独处/阅读/发呆)

- **场景定性**: 静态美 + 微动疗愈 + 陪伴感
- **光影模板**: 暖台灯 3000K 暖光 / 侧窗漫射 4500K 柔光
- **音频皮肤**: 钢琴独奏 / 雨声白噪音 / 暖民谣
- **7秒高潮点**: 翻页光斑移动 / 猫咪跳上沙发 / 烛光摇曳
- **典型 3 镜**: 窗边书架(全景)→ 翻书手指(特写)→ 侧脸阅读(中近景)
- **环境模板(3+1)**: 实木书架 / 旧皮革沙发 / 编织毛毯 + 窗光/暖灯
- **AI 生成禁区**: 杂乱感、棚拍空盒子、过度精致的样板间感

### 2.3 慢生活 / 旅行随拍(在路上)

- **场景定性**: 自由 + 治愈 + 在场感
- **光影模板**: 黄金时刻 3500K / 阴天漫射 6000K 柔光
- **音频皮肤**: 清新民谣 / 旅行 Vlog BGM
- **7秒高潮点**: 列车窗景流光 / 街角转角光影 / 远方地平线
- **典型 3 镜**: 背影走入街道(远景)→ 手提咖啡街角(中景)→ 远眺收尾(全景)
- **环境模板(3+1)**: 异国街角 / 复古小店 / 暖光路灯 + 手提物件
- **AI 生成禁区**: 过于商业化、旅游打卡感、过于密集的人群

### 2.4 节日 / 仪式感(圣诞/新年/生日)

- **场景定性**: 暖光 + 仪式 + 治愈惊喜
- **光影模板**: 暖灯串 3000K / 烛光 2500K / 窗光
- **音频皮肤**: 钢琴 + 钟琴 / 节日民谣
- **7秒高潮点**: 礼物拆开 / 烛光点燃 / 雪花飘落
- **典型 3 镜**: 装饰桌面(全景)→ 烛光摇曳(特写)→ 举杯或微笑(中近景)
- **环境模板(3+1)**: 暖灯串 / 蜡烛 / 装饰物 + 木质桌面/壁炉
- **AI 生成禁区**: 商业过载、塑料圣诞树、过于俗气的红绿配色

## 7. 反模式(本场景常见翻车点)

| 反模式 | 症状 | 修复 |
| --- | --- | --- |
| 棚拍感 | 纯色背景空盒子 | 3+1 真实家居环境 |
| 商业过载 | 广告化精致 | 降饱和 -5,加生活痕迹 |
| 戏剧冲突 | 强情绪/大喊 | 改平静微动,只留 micro-action |
| 过度精致 | 样板间感 | 加旧物/做旧/自然使用痕迹 |
| 光影闪烁 | 跨镜跳色温 | 锁单一光源方向,跨镜≤300K |
| 镜头过快 | 来回切 | 缓推/缓拉为主,禁快速 pan |
