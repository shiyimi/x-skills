# C3. prompt-craft · Prompt 模板(执行)

> 本文件是 Step 5 · 写脚本的**模板库**：八要素骨架 + Final Prompt 拼接顺序 + 可套用模板。craft 管"模板长什么样",[C2-quality.md](C2-quality.md) 管"怎么写/写什么规则"(动作/镜头/字幕/音频/质量锁/自检)。画面/背景(3+1+动态层)+ 环境音/BGM 写进 prompt 直出;字幕/配音走后期,不写进 prompt。

---

## §1 八要素万能公式(模板骨架)

提示词严格按八个要素拼接，顺序固定，不可省略:

```
主体 + 动作 + 场景 + 光影 + 镜头语言 + 风格 + 画质 + 约束
```

| 要素 | 来自哪步 | 来源文件 | 写法要求 |
| --- | --- | --- | --- |
| 主体 | step 2 角色四层 | [M1-character.md](M1-character.md) | 身份 + 外貌 + 服装 + 气质(本步只锁关键特征) |
| 动作 | step 4 镜头结构 + micro-action | [C1-flow.md §6](C1-flow.md) | 慢、连续、单动作 + micro-action |
| 场景 | step 3 场景三层 + 3+1 + 动态层 | [M2-scene.md](M2-scene.md) | 3 可辨识元素 + 1 光源 + 1-2 动态元素 |
| 光影 | step 3 单一光源 | [M2-scene.md §5](M2-scene.md) | 整段只写一次，语义化，非数字 |
| 镜头语言 | step 4 镜头结构 | [C1-flow.md §5](C1-flow.md) | ≤2 组合，连接词分开 |
| 风格 | step 3 风格锚 | [M2-scene.md §6](M2-scene.md) | 整段 1 个标签 |
| 画质 | 本步定 | — | 后置，4K 高清/浅景深 |
| 约束 | 本步定 | — | **前置锁**（稳定/解剖/主体锁定焊进开头 1-2 行）+ **末尾负面约束**（最小集 + 内容创作负面合并去重） |

### 1.1 满分作业实例

```
(主体)一位年轻女生
(场景)在海边，木栈道 + 躺椅 + 遮阳伞，黄昏暖光
(动作)慢走，微风拂动头发，微笑看向镜头
(光影)黄昏暖光，单一光源
(画质)4K 高清
(风格)电影感
(镜头)稳定运镜
(约束)画面流畅不抖动，细节清晰。
```

### 1.2 通用反例

| 反例 | 错在哪 |
| --- | --- |
| 漏"光影"要素 | 模型默认给漫反射平光 = 廉价 3D 感 |
| 漏"约束"要素 | 主角变脸/肢体扭曲高频 |
| 风格写"好看/震撼" | 模型自由发挥，不可执行 |
| 镜头写"超高速 + 极度稳定" | AI 逻辑死锁 |

## §2 Final Prompt 拼接顺序模板(每镜一块 · 中文直书)

> **直接中文,不做翻译**:Final Prompt 用**自然中文**重述分镜表,不把技术数字(K/dB/BPM/焦段)塞进 prompt,也不做英文语义换算——直接把"画面长什么样"写成人话(如 `暖金色晨光` `柔光侧光`)。**剧情爆点数字(金额/名称/年龄/成分/型号)例外,必须原样写进 prompt**。

```
[前置锁 · 前 1-2 行]
竖屏 9:16,时长 15 秒。<风格一句总述>。画面稳定不闪烁,主体解剖正确。<i2v: 与 <图片1> 保持主体一致>

★ 镜头组(每镜一块,与分镜表 1:1 对应;动作+机位运镜锁在同一时间锚点):
镜头1 [0.0-2.5s] · <主体关键特征锁> <单一动作+微动作> · <景别/机位> <运镜> <(可选)该镜光影备注>
镜头2 [2.5-5.0s] · ...
...

★ 场景(全局 3+1 + 动态层):
[场所类型] + [3 个可辨识元素] + [1 个光源] + [1-2 个动态元素]

★ 光影(全局单一光源,整段只写一次):
[方向 + 色温语义 + 光质]

★ 音频(同源镜像,每镜对应):
- 环境音: ...
- BGM: ...
- 人声(→TTS 后期): ...

★ 风格锚(整段 1 个):
[风格标签 + 情绪弧]

★ 画质(后置):
4K 高清,浅景深

负面约束: 画面稳定不闪烁,无变形,无错字,无水印 <+ 内容创作负面合并去重>
```

> 模板内各段的**写作规则**(动作约束/镜头取词/字幕/音频/质量锁/自检)见 [C2-quality.md](C2-quality.md) §4-§5。`负面约束` 行只保留默认最小集,内容创作阶段产的负面提示词(C1 §3)与质量锁负面在此**合并去重**后输出([C2-quality.md §3.2](C2-quality.md))。**前置锁**由 [C2-quality.md §5](C2-quality.md) 质量锁推导决定焊哪些。

## §3 套用模板(需求简单时直接填)

> 上面 §2 讲拼接规则，这里给 4 套**可直接套用的现成模板**。复杂需求用 SKILL 路由后回到这里套模板。每套含:① 主 prompt(中文直书·每镜一块) ② §4 声场设计稿(展示层,数字完整版)——两份保持一致。

### 3.0 素材绑定语法(图生视频/分段接续)

i2v 锚定或分段时，用显式短语绑定素材，避免模型自由发挥:

| 目的 | 写法 |
| --- | --- |
| 主体一致 | 以 `图片1` 为主体，保持外观/logo/配色一致 |
| 首帧引导 | 以 `图片1` 作为起始画面 |
| 风格参考 | 参考 `图片1` 的色调与光影 |
| 严格编辑 | 严格编辑 `视频1`，只做以下修改 |
| 分段接续 | 以 `视频前段` 末帧作首帧，光线/色调/风格一致 |
| 关键帧锁定 | 首尾帧同 `首帧引导`/`分段接续` 保持不变;中间关键姿态帧用详细文字描述(姿态/朝向/动作幅度/视线)焊进对应镜头块 |

### 3.1 唯美人像(小红书/抖音)

```text
竖屏 9:16,时长 15 秒。治愈系生活美学,画面稳定不闪烁,主体解剖正确。

★ 镜头组:
镜头1 [0.0-2.5s]: [年龄]岁[性别],[发型/外貌],穿[服装],[气质]——全片保持外形一致 · 缓步走来 · 中景平视 · 慢推运镜
镜头2 [2.5-5.0s]: ... · 微风拂动发丝,自然微笑看向镜头 · 近景 · 横向跟拍
镜头3 [5.0-8.0s]: ... · 停顿抬眼 + 轻眨眼 · 特写 · 固定微推
...

★ 场景: 海边木栈道 + 躺椅 + 遮阳伞 + 远处海面,黄昏暖光,纱帘/树影轻晃
★ 光影: 黄昏暖光,单一光源,柔光侧光
★ 音频:
- BGM: 清新木吉他 + 钟琴,慢节奏治愈系,0s 渐入,镜3 推满,末 2s 淡出
- 环境音: 远处鸟鸣 + 微风 + 脚步落叶
- 人声: 无对白,保留呼吸/衣物摩擦
★ 风格锚: 治愈清新[情绪弧:平静→温暖→静谧]
★ 画质: 4K 高清,浅景深
负面约束: 画面稳定不闪烁,无变形,无错字,无水印
```

**§4 声场设计稿(数字完整版)**: BGM 清新民谣(木吉他+钟琴) 95 BPM 无歌词 · 0s 渐入 3s 到 -18dB · 镜3 推满 · 末 2s 淡出至 -30dB；环境音优先级 镜1 鸟鸣 -22dB / 镜2 风声 -20dB / 镜3-4 脚步 -24dB / 镜5 鸟鸣 -22dB；关键音效 镜3·2.5s 脚步加重 3dB；对白无；静音 无强制。

### 3.2 氛围感风景(空镜转场)

```text
竖屏 9:16,时长 15 秒。自然纪录电影感,画面稳定不闪烁,物理正确。

★ 镜头组:
镜头1 [0.0-5.0s]: 海边日落空镜 · 海浪轻涌 · 远景平视 · 慢横移
镜头2 [5.0-10.0s]: 山间草甸晨光 · 草叶带露轻摇 · 中景 · 慢推
镜头3 [10.0-15.0s]: 云层缓移,天空渐亮 · 大远景 · 缓拉出全景
...

★ 场景: 海边日落/山间草甸,远处云层 + 草叶露珠 + 微风,暖橙色金色时刻光
★ 光影: 暖橙金色时刻光/柔和漫射多云光,单一光源
★ 音频:
- BGM: 氛围 pad 弦乐 + 钢琴,极慢,纯环境音主导
- 环境音: 风声 / 水声 / 鸟鸣,层次清晰
- 人声: 无
★ 风格锚: 治愈静谧[情绪弧:平静→沉浸→宁静]
★ 画质: 4K 超清,运动流畅
负面约束: 画面稳定不闪烁,无残影,无文字,无水印
```

### 3.3 图生视频专用(让照片动起来)

```text
竖屏 9:16,时长 15 秒。以 <图片1> 作为首帧,与人物外貌/服装保持一致,画面稳定不闪烁,主体解剖正确。

★ 镜头组:
镜头1 [0.0-5.0s]: 以 <图片1> 为主体——[补充角色四层特征以加固] · 缓抬手转身,自然不僵硬 · 中景 · 慢推
镜头2 [5.0-10.0s]: ... · 发丝轻动,呼吸起伏,表情微变 · 近景 · 固定微动
...

★ 场景: 与参考图一致 + [补充环境细节]
★ 光影: 匹配参考图光线,单一光源,[补充光源方向]
★ 音频:
- BGM: 钢琴 + 大提琴,慢情绪弧
- 环境音: 微环境音(轻呼吸/衣料摩擦)
- 人声: 无对白,保留生理音
★ 风格锚: 电影感,自然,与参考图一致[情绪弧]
★ 画质: 高清细节,电影质感
负面约束: 与 <图片1> 保持主体一致,无变形,无僵硬感,画面稳定,无文字
```

### 3.4 多镜头示例(古风少女舞剑)

```text
竖屏 9:16,时长 15 秒。武侠电影感,画面稳定不闪烁,主体解剖正确。

★ 镜头组:
镜头1 [0.0-5.0s]: 白衣长发少女,持青钢剑,目光坚定——全片保持外形一致 · 静立后缓抬腕把剑送到胸前,竹叶轻落 · 中景平视 · 缓推
镜头2 [5.0-9.0s]: ... · 双眼低垂再抬起,逆光勾出轮廓线 · 特写 · 亲密推近
镜头3 [9.0-15.0s]: ... · 轻旋身挥剑成弧(慢动作),竹叶与剑芒划过画面 · 中景 · 慢摇 + 推近
...

★ 场景: 晨雾竹林,竹叶 + 透过竹隙的柔光 + 地面雾气,绿色竹影,背后剑芒
★ 光影: 晨雾柔背光,绿色竹影,冷白剑芒,单一光源
★ 音频:
- BGM: 古琴 + 尺八,极慢,纯古风情绪
- 环境音: 竹叶沙沙 + 远处鸟鸣 + 剑鸣
- 人声: 无对白,保留衣袖飘动摩擦
★ 风格锚: 武侠电影感,治愈清新 + 暖漫射光[情绪弧]
★ 画质: 4K 高清,画面稳定
负面约束: 画面稳定不闪烁,无变形,无错字,无水印
```
