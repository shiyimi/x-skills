# M1. character · 角色建模 schema(建模)

> Step 2 · 定人物的主文档。schema 表定义每个维度怎么填(`必填`)、怎么变(`变体轴`)、对照(`示例/反例`)——AI 现场填充,天然不千篇一律。角色一致性靠 i2v 锚定 + 关键特征锁。

---

## §1 角色建模 schema(核心表)

> 对每个主体，按下表逐维度填充。**必填 = MUST-KEEP**；`变体轴` = 每项 2-3 个候选，按 brief 取 1，避免重复。

| 维度 | 必填 | 变体轴(CAN-ROTATE) | 示例 | 反例 |
| --- | --- | --- | --- | --- |
| **身份标签** | 必填 | 职业 / 时代 / 风格身份(取 1) | "赛博朋克深海潜员" / "古风少女" | "一个女孩"(身份缺，模型自由发挥) |
| **年龄/性别档** | 必填 | 少年/青年/中年/老年档 | "a 25-year-old woman" | "很年轻的"(粒度模糊) |
| **外貌特征** | 必填 | 发型/发色/脸型/体型(每项 2-3 候选) | "长发披肩，鹅蛋脸，肤色白皙" | 堆 7 个特征(模型抓不住，5 个足够) |
| **服装描写** | 必填(信息密度最高) | 款式/颜色/材质(取搭配) | "穿黑色长风衣" / "一袭白衣" | "穿衣服"(无信息) |
| **气质/状态** | 半必填 | 气质标签(冷峻/温柔/活泼...) | "气质忧郁" | 气质与故事情绪冲突 |

**锁定原则**：主体描述词**全片/全系列锁同一套**，改一个词模型就漂移(Q1 主体锁)。

### 1.1 主体类型 schema(按主体套模板，从粗到细可裁剪)

| 主体 | 维度模板(执行层) | 变体轴 |
| --- | --- | --- |
| **人像女** | `A [age]-year-old [ethnicity] woman with [hair], [face feature], wearing [clothing], [temperament]` | 发型/服装换 2-3 套 |
| **人像男** | `A [age]-year-old [ethnicity] man with [hair], [face feature], wearing [clothing], [temperament]` | 同上 |
| **动物** | `A [age]-year-old [breed] with [coat color/pattern], [eye color] eyes, [temperament]` | 毛色/姿态 |
| **食物** | `A [size] [dish name] with [topping/garnish], [texture description], on [plate/table]` | 摆盘/表面质感 |
| **产品** | `A [size] [product] with [material/color], [brand mark in quotes], [detail]` | 配色/材质 |
| **风景** | `A [type] landscape in [time/style], with [environment details], [lighting/weather]` | 时间/天气 |

### 1.2 维度优先级(不同主体侧重不同)

| 主体类型 | 优先级 | 注意 |
| --- | --- | --- |
| **人像** | 服装 > 外貌 > 身份 > 气质 | 5 个关键特征足够，过多模型抓不住 |
| **动物** | 物种 + 年龄 + 关键外观 | 4 个月以下幼体模型易崩，优先成熟体 |
| **产品** | 品类 + 颜色 + 关键卖点 | 通用名远不如具体描述("米白色针织连衣裙，腰部系带") |
| **抽象主体** | 风格 + 配色 + 构图 | 极少用，t2v 对纯抽象概念理解差 |

## §2 多角色管理(≥2 角色)

> 纯文字描述无法保证 ≥2 角色的一致性，**必须 i2v 定妆图锚定**。移除视觉锚定，一致性评分灾难性下降。

| 角色数 | 规则 |
| --- | --- |
| **≥2 个角色** | **MANDATORY i2v**：每角色 1 张标准定妆照 |
| **含特写互动** | **MANDATORY i2v**：握手/拥抱/递物等 |
| 单人 | 推荐 i2v(关键特征锁 + 同关键词也够，但 i2v 更可靠) |

**定妆照要求**：
- 每角色 ≥1 张标准照(正面或四分之三侧面，中性表情，中性光线)
- 多机位/多镜头角色建议 3-5 张(正面/三四侧面/侧面)
- 定妆照中服装/发型/配饰 = 视频中角色服装(跨张一致)
- 参考图质量：分辨率 ≥1024×1024；角色与背景清晰分离；光线均匀
- 提交：`image_paths: [角色A定妆照, 角色B定妆照, ...]`

## §3 micro-action(让角色"活"起来)

> 主体必须含微观动作，否则画面呈"3D 模型平移感"。**micro-action 写进 Final Prompt 的 `Action` 段，不写进角色描述**——它是动作层的元素(Q 源头写对)。

| 主体类型 | micro-action 短语 |
| --- | --- |
| 动物 | `with subtle ear twitches, light tail sway, occasional eye blinks` |
| 人像 | `with soft breathing visible, hair lightly swaying, gentle eye movement` |
| 食物/产品 | `with steam rising slowly, surface texture shifting` |

## §4 人物-事件一致性检查(Q2/Q1 在本步应用)

角色四层填完后，逐项回答，任一为否就回头改：

| # | 问题 | 反例 |
| --- | --- | --- |
| 1 | **服装与场景匹配吗?** | 车间工人穿西装礼服 |
| 2 | **身份与动作匹配吗?** | 程序员操作锻压设备 |
| 3 | **外貌/气质与情绪匹配吗?** | 打工人疲惫用"气质冷峻的赛博朋克战士" |
| 4 | **年龄/体型与场景安全匹配吗?** | 老人爬脚手架 |

### 4.1 服装-场景冲突速查

| 场景 | 应避免 | 推荐 |
| --- | --- | --- |
| 车间/工厂 | 西装、礼服、睡衣、拖鞋 | 作业服 + 安全帽 + 工靴 |
| 厨房 | 西装、礼服、外套 | 围裙 + 厨师服 + 头巾 |
| 雨雪户外 | 短袖、薄衣 | 雨衣/防风衣 + 防水鞋 |
| 宴会厅 | 围裙、作业服 | 正装/礼服 |
| 雪地/冬季 | 短袖、凉鞋、单衣 | 厚外套 + 雪靴 + 毛线帽 |

### 4.2 与下游环节的接口

- **Final Prompt 的 `前置锁` 与 `★ 镜头组` 每镜块**：角色 schema 直接搬入，关键特征锁定
- **场景三层**(step 3)：服装决定光照方向(深色 → 强光提反差；浅色 → 柔光)
- **动作段**：micro-action 写进 Action 段，不放角色描述
- 完整四维度一致性矩阵见 [C1-flow.md §7](C1-flow.md)

## §5 反例(本步常见翻车点)

| 反例 | 错在哪 | 修正 |
| --- | --- | --- |
| 角色只写"一个女孩" | 身份缺，模型自由发挥 | 写"古风少女"(身份)+ "长发披肩"(外貌)+ "一袭白衣"(服装)+ "气质忧郁"(气质) |
| 全片换服装 | 主体漂移(Q1) | 主线段固定同一套四层，变装只发生在叙事情节转折处 |
| 角色描述里塞动作 | 角色层和动作层职责混乱 | 动作归动作段，角色只写"是谁、穿什么、什么感觉" |
| 微距产品拍人物 | 类型错配，模型用产品纹理填人脸 | 写"产品"主体时不要混人脸 |
