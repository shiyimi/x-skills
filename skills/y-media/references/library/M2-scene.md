# M2. scene · 场景建模 schema(建模)

> Step 3 · 定场景的主文档。场景四层 + 3+1 元素 + 动态层,逐维度填,避免"AI 空盒子"和"背景冻住"。

---

## §1 场景建模 schema(核心表)

> 每个场景按下表逐维度填充。**四层缺一不可**：缺第三层 → 画面空洞，缺第四层 → 模型默认漫反射平光 = 廉价 3D 感(Q 源头写对)。

| 维度 | 必填 | 变体轴(CAN-ROTATE) | 示例 | 反例 |
| --- | --- | --- | --- | --- |
| **场景类型** | 必填 | 场所类型(取 1) | "街头 / 酒吧 / 林间 / 车间 / 厨房" | "一个温馨的房间"(空盒子) |
| **时代/风格修饰** | 可选 | 时代/风格(取 1) | "赛博朋克风格的街道" / "现代工业风车间" | 风格词与类型冲突 |
| **环境细节(3+1)** | 必填 | 3 个可命名道具(每项候选) | "木桌、搪瓷杯、墙上挂钟" | "森林"(无道具，缺可辨识元素) |
| **光线/天气** | 必填 | 时间-季节-天气组合 | "清晨侧光，柔光" | 缺第四层 = 平光廉价感 |
| **动态层** | 必填(1-2 个) | 人物/自然/光影/粒子(取 1-2) | "纱帘轻飘 · 水面波光" | 静态背景 = 截图感 |
| **风格锚** | 必填(整段 1 个) | 抽象/中等/具体(取 1) | "BBC Earth + ARRI Alexa" | "好看/震撼"(模型自由发挥) |

---

## §2 背景真实感 3+1 元素法(核心)

**问题**:纯渐变或空棚背景 = "AI 空盒子"，画面一眼假。

**解法**:任何场景写满 `3+1`:`[具体场所] + [3 个可命名道具/纹理] + [1 个光源]`。

| 组成 | 要求 | 示例 |
| --- | --- | --- |
| 具体场所 | 可辨识的地点，不是"一个房间" | "老式早餐店" / "现代厨房" / "清晨的森林空地" |
| 3 个可命名道具 | 具体可命名的物体/纹理 | "木桌、搪瓷杯、墙上挂钟" / "砂锅、案板、油烟机" |
| 1 个光源 | 方向 + 色温 + 光质 | "清晨侧光，柔光，4500K" |

**反例**:"一个温馨的房间" = 空盒子；"森林" = 缺少可辨识道具。

---

## §3 动态层(背景不冻住)

**问题**:静态背景 = "背景冻住"，画面像截图。

**解法**:每个场景从四种动态选 **1-2 个缓慢的局部动态元素**，写进 prompt 的 `Scene` 段。

| 动态类型 | 示例 |
| --- | --- |
| 人物动态 | 背景虚化人流走动 / 邻桌客人交谈 |
| 自然动态 | 纱帘轻飘 · 树影摇曳 · 水面波光 |
| 光影动态 | 光斑缓移 · 明暗呼吸 · 屏幕微闪 |
| 粒子动态 | 蒸汽升腾 · 尘埃浮动 · 水汽 |

---

## §4 展示层 vs 执行层 转换表(层分离)

分镜表(展示层)记录人可理解的具体数字；**prompt(执行层)用模型能理解的语义化描述**。两层不可混用——混用 = 模型无法读取数字。

| 字段 | 展示层(分镜表，人读) | 执行层(prompt，模型读) |
| --- | --- | --- |
| 色温 | 4500K | `soft golden morning backlight` / `cool blue hour diffused light` |
| 光质 | 柔光 / 硬光 | `soft diffused light` / `hard direct light` |
| 光位 | 45°侧光 | `side light from the left` / `backlight from behind` |
| 焦段 | 16mm | `shot on ARRI Alexa with shallow depth of field` |

### 4.1 转换规则速查

1. **K 值 → 光源描述**: 4500K → `soft golden morning light`；6500K → `cool overcast daylight`
2. **光比 → 光源方向**: 光比大 → 单一主光源方向；光比小 → `soft diffused fill`
3. **焦段 → 摄影机/风格标签**: `shot on ARRI Alexa` / `shot on 16mm Bolex`

### 4.2 不在转换表的字段(保持原样)

| 字段 | 原因 |
| --- | --- |
| 物种月龄 | 模型理解年龄描述，`a 6-month-old ... foal` 有效 |
| 主体外观特征 | 颜色/品种模型都能执行 |
| 风格标签 | `BBC Earth` / `cinematic` 都在训练语料中 |

---

## §5 单一光源原则

Final Prompt 中**整段只写一次光源**，不每镜重写。

| 写法 | 含义 |
| --- | --- |
| `single light source — low golden morning sun behind the subject, soft fill from the sky` | 推荐，信息全 |
| `volumetric morning backlight` | 简写，够用 |
| `soft directional lighting` | 保底，光位模糊但有方向 |

> 多光源 = 模型随机混，反不如单一。

---

## §6 风格锚(整片一个)

每个镜头绑定 1 个明确风格标签，**整段只锚 1 个**，不要风格混搭(Q3 风格锁)。

| 层级 | 示例 | 效果 |
| --- | --- | --- |
| 抽象 | "好看" / "震撼" | 模型自由发挥，不可取 |
| 中等 | "治愈清新" / "赛博朋克" | 风格基本对 |
| 具体 | "BBC Earth + ARRI Alexa" | 质感锁定 |

**风格锚与场景三层的接口**: 风格锚写在 Final Prompt 末尾 `★ 风格锚` 段，场景三层写在 `★ 场景` 段；两者协同，不要把风格词塞进场景描述。

---

## §7 场景内部一致性检查(Q2 在本步应用)

场景三层填完后，检查场景类型/时代/细节/光线/天气彼此是否一致。逐项回答，任一为否就回头改:

| # | 问题 | 反例 |
| --- | --- | --- |
| 1 | **场景类型内部一致吗?** | 沙漠里出现常绿阔叶林 |
| 2 | **时代/季节与光线匹配吗?** | 黄昏 + 雪地；雪夜 + 短袖 |
| 3 | **天气与场景类型匹配吗?** | 露天无遮挡 + 雨天 |
| 4 | **环境细节与场景类型匹配吗?** | 海边 + 雪山；厨房 + 沙发 |
| 5 | **风格锚与场景类型匹配吗?** | "治愈清新" + "赛博朋克"混用 |
| 6 | **空间连续性(相邻场景关系一致吗?)** | 车间后方直接出办公室工位 |

### 7.1 时间-天气-光线组合速查

| 时间 | 季节 | 推荐光线 | 不推荐 |
| --- | --- | --- | --- |
| 清晨 | 春/夏 | `soft golden morning backlight` | 强烈侧光 |
| 清晨 | 冬 | `cold blue morning haze` | 暖金光 |
| 黄昏 | 全年 | `warm golden hour backlight` | 冷色 |
| 夜晚 | 城市 | `neon fill + warm street lamp rim` | 自然光 |
| 雨天 | 全年 | `overcast diffused daylight` | 强直射阳光 |
| 雪天 | 全年 | `cool overcast + snow reflection` | 暖色主调 |

### 7.2 天气-场景冲突速查

| 场景类型 | 安全天气 | 需遮挡才安全的天气 |
| --- | --- | --- |
| 室内 | 任意 | 无 |
| 半露台/有顶棚 | 雨/雪(需挡风) | 大风 |
| 露天户外 | 晴/多云/阴 | 雨/雪(需加雨棚/伞/改室内) |

## §8 场景一致性·生成层方法(把空间锁死)

**§7 是文案层检查**(填表后自检)，本节是**生成层手段**(prompt 阶段就把空间锁死，Q1 场景锁)。**多镜头叙事、室内/固定场景**优先套用。

**方法 A · 场景参考图锚定(Scene I2V Reference)**
> 与角色 i2v 同理，参考图是**场景**而非人物。换机位时，把同一张场景图作为首帧喂给模型。
- 适用:室内、产品棚拍、固定空间的多机位
- 写法: `image_paths: [场景定妆图]` + prompt 只写"怎么动/换哪个机位"，不重写空间
- 局限:场景受参考图起始构图限制

**方法 B · 场景九宫格法(9-Grid Space Lock)**
> 把场景生成成 **9 格不同机位视图**，一次性锁死空间结构。
- 适用:室内大场景、多镜头叙事短片
- 流程:场景定妆图 → 生成九宫格 → 每镜从九宫格挑角度 + 人物定妆图合成 → 送入视频模型

**方法 C · 统一空间描述 + 多点光源统一(Unified Space)**
> 纯文字路线，空间一致性靠**跨镜头照抄同一套场景描述** + **统一光源**。
- 场景三层描述**原样复制到每个含该场景的镜头**，只改机位/动作
- 适用:单段直出、无参考图的场景

**三方法对比(按可靠性从高到低)**:

| 方法 | 空间一致性 | 准备成本 | 适用 |
| --- | --- | --- | --- |
| B 九宫格 | ★★★★★ | 高(多一步图像生成) | 室内大场景、多镜头 |
| A 场景 i2v | ★★★★ | 中(一张场景图) | 固定空间多机位 |
| C 统一描述 | ★★★ | 低(零成本) | 单段直出、无参考图 |

## §9 反例(本步常见翻车点)

| 反例 | 错在哪 | 修正 |
| --- | --- | --- |
| 场景三层只写两层 | 模型自由发挥，出图不稳 | 完整 4 层都写 |
| 背景空盒子 | 缺 3+1，画面一眼假 | 补 3 个可命名道具 + 1 个光源 |
| 背景冻住 | 缺动态层，画面像截图 | 加 1-2 个缓慢局部动态元素 |
| 在 prompt 里写"4500K" | 数字无效 | 转换为 `soft golden morning backlight` |
| 一段多个光源方向 | 模型随机混合 | 单一光源，显式写 `single light source — ...` |
| 风格锚写 2-3 个标签 | 风格漂移(Q3) | 整段 1 个风格锚 |
| 雪夜 + 短袖 + 露天 | 时间-季节-服装三重错 | 改"雪夜厚外套 + 路灯暖光" |
