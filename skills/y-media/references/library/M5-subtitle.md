# M5. subtitle · 字幕建模 schema(建模)

> y-media 的字幕路线主文档。含字幕的 brief 必读(转化带货/投信息流/配音解说);无字幕场景只读 [M4-audio.md](M4-audio.md)。字幕可选,一旦用全片锁一套字体/主色/位置/动画。先判路线 + 逐条填四要素(类型 + 文案 + 时机 + 位置 + 样式)。字幕文案进 SRT 源,成片后 `post.cjs burn` 后期烧录——确定性、零错字可控;仅当需求显式要求"AI 直接渲染文字"或本机缺 ffmpeg 时才直出。

---

## §1 字幕建模 schema(核心表)

> 先定路线，再逐条字幕填四要素。`变体轴` = 该维度可按 brief 换的取值。

| 维度 | 必填 | 变体轴(CAN-ROTATE) | 示例 | 反例 |
| --- | --- | --- | --- | --- |
| **字幕类型** | 必填 | 6 类(见 §2) | "② 数据/卖点" | 每镜换类型，全片乱 |
| **文案** | 必填 | 钩子/卖点/背书/CTA 内容 | "1.5% 玻色因" | 模糊词"高蛋白"(无数字) |
| **时机** | 必填 | 三阶段(入场/停留/出场) | "0-2s 钩子" | 与口播不同步 |
| **位置** | 必填 | 每类固定位置 | "数据卖点下 1/3" | 遮挡产品 |
| **样式(5 锁)** | 必填 | 字体/色板/动画/描边(取套) | "思源黑体 Bold · 白底黑边" | 每镜换字体/颜色 |

---

## §2 字幕路线决策(用不用先判一次)

判定后写进 storyboard 表头"视听路线"，全片保持一致。

| 场景 | 字幕路线 | 理由 |
| --- | --- | --- |
| 目标是转化带货 + 投信息流 | **含字幕(后期烧录)** | 70% 静音播放，字幕是主信息通道 |
| 品牌/形象/艺术叙事，走高级质感/情感/感官 | **无字幕或极简字幕(≤2 条)** | 画面+表演+音频已承担 70% 信息量 |
| 拿不准 | **默认不含字幕** | 加字幕容易、加对难；宁可先无后补 |

**无字幕/极简的典型场景**:珠宝情感片、女装质感试穿片、生鲜纯纪录溯源、ASMR、高端 3C 品牌片。

## §3 六类字幕(一段不必全用)

| 类型 | 位置 | 内容 |
| --- | --- | --- |
| ① 钩子 | 0-2s | 痛点问句 / 悬念 / 反常识数据 |
| ② 数据/卖点 | 核心镜 3-7 | 具体数字+单位，避免"高蛋白"这类模糊词 |
| ③ 信任背书 | 中后段 | 品牌/成分/资质/产地/销量/口碑 |
| ④ 行动号召/slogan | 末镜 | A: 指令+利益+紧迫 / B: slogan 或情感 tag / C: 互动设问 |
| ⑤ 氛围/口播同步 | 全片 | 口播关键词高亮，不必逐字 |
| ⑥ 金句/治愈收尾 | 末镜或黑屏 | 情绪总结句，黑底白字+关键词黄底高亮 |

**字幕覆盖规则**:
- commerce 路线(转化带货):① ② ③ ④ 必用，⑤ ⑥ 选
- general 路线:按骨架选 2-4 类，不要每类都用

## §4 字幕风格锁定与动效

### 4.1 风格一致性(字幕"乱"的解药)

字幕多半是"每镜换字体/颜色/位置/动画"。表头一次锁定 5 项、全片复用。**注意:字幕不可以遮挡产品**。

| 锁 | 建议 |
| --- | --- |
| L1 字体族 | 全片 1 种(骨架 A 可"标题+正文"固定配对) |
| L2 主色板 | ≤2 色(主色+强调色)；质感片建议 1 色 |
| L3 位置 | 每类字幕固定一个位置(钩子上、卖点中、背书下、CTA 下半) |
| L4 动画 | 全片 1 种主动画(或"主+副"两种) |
| L5 描边/阴影 | 描边粗细/颜色/阴影/底板全片统一 |

### 4.2 commerce 字幕 5 风格锁定(推荐模板)

| 字段 | 锁定值 | 适用 |
| --- | --- | --- |
| 字体 | 思源黑体 Bold / 阿里巴巴普惠体 | 通用商业 |
| 色板 | 主白 `#FFFFFF` + 卖点金 `#FFD700` | ≤2 色 |
| 位置 | 钩子/CTA 居中，数据卖点下 1/3 | per type |
| 描边 | 黑边 2px(亮/暗背景都可读) | 通用 |
| 动画 | 弹入放大 0.3s + 停留 1.5s + 缓淡出 0.3s | 通用 |

### 4.3 动效三阶段 + 常用入场

**三阶段时间分配**(默认 1.5-2.0s 总寿命):

| 阶段 | 时长 | 职责 |
| --- | --- | --- |
| **入场** | 0.2-0.4s | 抓住注意力 |
| **停留** | 1.0-1.8s | 让用户"读懂" |
| **出场** | 0.2-0.4s | 干净离场 |

**常用入场动效速查**(挑 1-2 种，全段统一):

| 动效 | 视觉感受 | 适合字幕类型 |
| --- | --- | --- |
| **弹入放大** (scale 0.7→1.0) | 强注意力 | ① 钩子 ④ CTA |
| **上滑淡入** (translateY +20px→0) | 自然 | ② 数据 ③ 背书 |
| **逐字打字** (typewriter) | 节奏感 | ⑤ 口播 ⑥ 金句 |
| **硬切闪入** | 强冲击力 | ② 价格(转化类) |

> 动效是"被注意到度"的关键；同一句字幕，弹入放大 vs 缓慢淡入，完播率能差 30%。

## §5 字幕音效(让字幕"被听到")

| 字幕类型 | 配音效 | 时机 |
| --- | --- | --- |
| ① 钩子 | "叮"(短促) | 入场同帧 |
| ② 数据/卖点 | "嗒"(清脆) | 入场同帧 |
| ③ 信任背书 | "叮"低八度 | 入场后 0.1s |
| ④ CTA | "叮"+"嗒"两连击 | 入场前 0.05s |
| ⑥ 金句 | 无(留白) | 静音法则([M4-audio.md](M4-audio.md)) |

**关键规则**:
- S1 · 关键字幕配短音效(如上表)
- S2 · 音效与画面/字幕同帧(±0.1s 内)
- S4 · 价格/数据爆点"先断后响":`价格"3.9元"前 0.5-1s 全断 → "叮"+"3.9元"同帧`

---

## §6 字幕四要素(每条写清)

每条字幕写清 **文案 + 时机 + 位置 + 样式(含动画+音效)**:

```
镜1(0-2s):上1/3 出现 "<钩子≤12字>",粗黑体大字号白底黑边,
  whoosh划入+低频"咚",停留1.5s后缓淡出
镜4(6-8s):正中出现 "<数据卖点≤12字>",数字黄色加粗,
  弹入放大+一声"叮",停留2s
镜8(13-15s):下方全屏 "<CTA三要素>",红黄对比闪烁3次+上扬"叮咚"
```

**文案原则**:

| 维度 | 规则 |
| --- | --- |
| 品牌名/型号/成分名 | **零容错(R5 铁律)**:逐字回查，官方写法严格照搬，不确定时确认，绝不凭记忆猜测 |
| 句长 | 一屏一句，单句 ≤12 字，超了拆两屏 |
| 关键 token | 数字/单位/品牌名用英文引号原样包裹，让模型别改 |
| CTA 紧迫感 | 骨架A 用:"仅限今日""前100名""最后X件" |
| 时机 | 出现时机比口播提前半拍，让静音用户先看到 |
| 通读 | 全片字幕按序读一遍能读懂"钩子→卖点"完整链路 |

## §7 字幕落地:后期烧录为主(Q6)

> **后期是默认(见 [C2-quality.md §6](C2-quality.md))**:字幕走后期——文案进 SRT 源 → 成片后 `post.cjs burn` 烧录,确定性、零错字可控。仅当需求显式要求"AI 直接渲染文字"或本机缺 ffmpeg 时,才降级为 prompt 直出。

### 7.1 后期烧录(默认)

把 §6 每条字幕(文案+时机+位置+样式)落成 SRT 源,成片后烧录;样式锁定见 §4.2。SRT 是跨工具(ffmpeg/剪映/Pr)通行的最简格式。

**SRT 格式(标准)**:
```
1
00:00:00,500 --> 00:00:02,300
三块九,包邮到家

2
00:00:02,400 --> 00:00:04,000
这个材质,是纯棉的
```

- 序号 + 起止时间 + 文本，块间空行
- 一屏一句，单句 ≤12 字
- 出现时机比口播提前半拍

**烧录命令**:
```bash
node core/post.cjs burn <v>.mp4 --srt <name>.srt --out <out>.mp4
```

**能力降级**:本机 ffmpeg 缺 `subtitles` 滤镜时，post.cjs 抛 `capability_gap` 并附菜谱；用完整版 ffmpeg 或剪映执行。

### 7.2 字幕直出(特殊需求/能力缺口)

> 仅当需求**显式要求"AI 直接渲染文字"** 或本机缺 ffmpeg 时，才把字幕写进 prompt 让模型直出。**后期烧录是默认,直出是特殊需求**。

**直出写法**:在 Final Prompt 的 `★ 文字叠加` 段标明每镜字幕文案、位置和样式(见 [C2-quality.md §6.2](C2-quality.md))。

### 7.3 烧录自检

- 字幕不遮挡产品(数据/CTA 放画面下 1/3)
- 品牌名/型号/成分逐字核对(R5)，错字只重烧该段
- 时长与配音对齐(口播同步类字幕 ⑤)

---

## §8 自检 3 问(填完后 30 秒过)

1. **字幕路线对吗?** §2 决策表选的是哪一条？全片保持一致。
2. **关键节点都配齐了?** ① ② ④ 字幕配音效；价格爆点必带"先断后响"；品牌名逐字核对(R5)。
3. **字幕走后期了吗?** 文案进 SRT 源,成片后烧录;只有需求显式要求或本机缺 ffmpeg 才直出。
