# A3. emotional-levers · 5 情绪杠杆(按需辅助)

> **定位**:y-media 的商业音频杠杆库。转化/兴趣/认知视频(commerce 路线 + lifestyle 种草路线)必读;纯质感/纪录片/ASMR 类可选。

---

## §0 速选流程(先选目标 → 再选杠杆)

| 商业目标 | 必选杠杆 | 选选杠杆 | 禁用杠杆 |
| --- | --- | --- | --- |
| **转化(带货)** | L1 + L3 + L4 | L2(卖点镜卡点) | — |
| **兴趣(种草)** | L2 + L4 | — | L3(避免商业感太重) |
| **认知(品牌)** | L1 + L5 | L4(品牌声音 logo) | L3 |
| **骨架 C(多段情绪)** | L5 必用(情绪曲线) | L1(开场) | — |

> **1 段 ≤ 3 个杠杆**;**留 1-2 镜空白**(不放杠杆),让画面说话。5 个全用 = 反模式,听觉过载。

---

## §1 L1 · 开场 3s 音频钩

**用途**:静音外放场景下抓住耳朵(用户滑到第 1 镜的 0-3s,音频不抓人即划走)。

**触发条件**:
- 视频会在静音外放场景被消费(feed 滚动 + 用户未戴耳机)
- 目标 = 转化/认知(开场即留人)
- 视频无真人出镜(否则由画面/人声承担钩子)

**写法**:
- 0-3s 出现高识别音效(`叮` / `嗒` / `嗒嗒` / `whoosh` / 倒计时音)
- BGM 同步淡入(0s 入 + 2-3s ramp 到目标 dB)
- 音效峰值对齐视觉重音(产品 logo 出现 / 主体入画)

**样例**:
```
镜1 0-3s: "叮"(短促高识别) + BGM 电子鼓点 0s 同步淡入至 -14dB
```

**反例**:
- ❌ 0-3s 静音 + BGM 慢慢进入(用户没耐心等)
- ❌ 钩子音过长(超过 1.5s = 抢戏)
- ❌ 钩子音过于平淡("嗡——"无辨识度)

---

## §2 L2 · 音画卡点

**用途**:把视觉重音和音频重音锁在**同一帧** —— 价格、卖点、CTA、变装瞬间等"必须被看到"的信息。

**触发条件**:
- 节奏密集型短片(每镜 1.5-2.5s,骨架 A)
- 卖点镜 / 价格镜 / CTA 镜
- BGM 选 鼓点 / 重音明显的曲子(不是钢琴 pad / 弦乐)

**写法**:
- BGM 鼓点/重音与镜头切换**同帧**(±0.1s 内)
- 字幕入场与 BGM 鼓点同帧(见 [subtitle.md §9](A1-subtitle.md))
- 价格"99元"字幕与底鼓同帧闪入(最经典的音画卡点)

**样例**:
```
镜5 价格"3.9元": 字幕入场 = 底鼓重音同帧(±0.1s)
镜6 CTA"前1000名立减50": 字幕入场 = 底鼓下一拍重音
```

**反例**:
- ❌ 字幕比鼓点晚 0.5s(用户视觉先到 + 音频后到 = 错位)
- ❌ 字幕比鼓点早(视觉先抓眼 + 音频还没到 = 拖泥带水)
- ❌ 钢琴 pad 曲子做卡点(无重音,无法对位)

---

## §3 L3 · 静音留白 → 爆点炸开

**用途**:情绪反转/数据高能/价格爆点前的张力堆积 —— **沉默 0.5-1s,然后全频推满**。

**触发条件**:
- 价格爆点镜(L3 + L4 必组合)
- 数据/参数反差镜(从 100ms → 1ms)
- 情绪反转镜(温情 → 燃 / 共情 → 转折)
- 品牌 logo 出现 / 卖点镜(关键信息登场)

**写法**:
- 爆点镜**前** 0.5-1s 全断(BGM + 环境音 + 人声同时静音)
- 爆点镜**起**全频推满(BGM + 音效 + 字幕同步)
- 全断时长不超过 1s(超过 1.5s 用户以为视频卡死)

**样例**:
```
镜3 → 镜4: 镜3 末 0.8s 全断 → 镜4 "3.9元" + "叮" + 鼓点全频推满
```

**反例**:
- ❌ 静音 0.2s(太短,无张力堆积)
- ❌ 静音 2s(用户以为视频卡了,直接划走)
- ❌ BGM 留 30%(不算"全断",张力不够)
- ❌ 静音后无爆点音效("叮" / 鼓点)(只剩字幕 = 干)

---

## §4 L4 · 声音记忆点

**用途**:让用户在刷到第 2-3 次时"还没看清就知道是谁" —— **声音 logo**(短音效/旋律片段)。

**触发条件**:
- 品牌需要复播识别(用户多次刷到时直接认出)
- 目标 = 兴趣/认知(转化可不用)
- 品牌有自己的经典音(如 Apple 开盖音、可口可乐开瓶音)

**写法**:
- 设计 1-2 个**短**(0.5-1.5s)且**高识别**的声音 logo
- 在以下节点固定出现:产品特写 / 品牌 logo 出现 / CTA 镜
- 与视觉 logo 同步(声音 + 视觉同时强化记忆)
- 避免每镜都用(每 3-5 镜 1 次即可)

**样例**:
```
声音 logo: "叮-嗒嗒"(2 连击,高识别短旋律)
出现节点: 镜1 产品入画 / 镜5 价格出现 / 镜8 CTA
```

**反例**:
- ❌ 声音 logo 太长(超过 2s = 拖)
- ❌ 声音 logo 与品牌无关(用户记不住)
- ❌ 每镜都用 = 听觉过载,反成噪音
- ❌ 版权音(直接复制《Faded》前奏 = 侵权 + 同质化)

## §5 L5 · 情绪音量曲线

**用途**:**多段视频**(骨架 C,30s+)必备 —— BGM dB 随拍次起伏,避免听觉疲劳。

**触发条件**:
- 视频 ≥ 30s(短片用 L1+L2+L3 即可,不用 L5)
- 骨架 C(起承转合四段)
- 多段情绪(开篇平静 → 中段推满 → 收尾沉淀)

**写法**:
- **起**(0-25%):-20dB 铺垫,环境音主导
- **承**(25-50%):-16dB 推进,BGM 渐入
- **转**(50-75%):-22dB 回落(转场前 0.5s 全断)
- **合**(75-100%):-14dB 推满(BGM + 音效全频),收尾 1-2s 渐弱

**样例**(30s 视频骨架 C):
```
音量曲线(时间码 → dB):
0-8s:   -20dB(起 · 环境音主导)
8-15s:  -16dB(承 · BGM 渐入)
15-22s: -22dB(转 · 静默前 0.5s 全断)
22-30s: -14dB → 末 1s 渐弱至 -28dB(合 · 推满 → 收)
```

**反例**:
- ❌ 全程一个音量(听觉疲劳,完播率掉 30-50%)
- ❌ 曲线过于剧烈(转段 1s 内跳 10dB = 突兀)
- ❌ 短片(15s)强行套 L5(过设计)

## §6 与目标 / 骨架的搭配

### 6.1 按商业目标

| 目标 | 主推杠杆 | 次选 | 禁用 |
| --- | --- | --- | --- |
| **转化(带货)** | L1 + L3 + L4 | L2 | — |
| **兴趣(种草)** | L2 + L4 | L1(开篇) | L3(避免商业感) |
| **认知(品牌)** | L1 + L5 | L4(品牌声音 logo) | L3 |

### 6.2 按视频骨架

| 骨架 | 必选 | 选选 | 备注 |
| --- | --- | --- | --- |
| **A · 展示(9-12 镜,1-2.5s)** | L2(卡点) | L1(开场) | 短平快,L3 慎用 |
| **B · 慢切(6-8 镜,2-3s)** | L1(开场) | L3(1 处末镜) | 节奏慢,BGM 起伏要明显 |
| **C · 多段(4 段,30s+)** | L5(曲线) + L1(开场) | L2 + L3 + L4 | 多段必须 L5 |

### 6.3 commerce 路线必读(CA1/CA2)

- **CA1**:价格爆点前全断(配合 L3)
- **CA2**:字幕节奏与 BGM 鼓点同帧(配合 L2)
- 详见 [audio.md §6](M6-audio.md)
