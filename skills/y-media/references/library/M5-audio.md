# M5. audio · 音频设计(创意)

> **R3 视听双轨的音频侧**:三层(人声/环境音/BGM)每镜都要设计，别只依赖模型默认背景音。
>
> **源头写对**:三层音频用语义化描述写进 Final Prompt 的 `★ Audio` 段，让模型直出；不写 BPM/dB 数字(展示层才写)。

---

## §1. 音频风格选择(先按目标 + 情绪)

### 1.1 商业目标定「功能骨架」

| 目标 | 含义 | 三层权重(起点) | 节奏 |
| --- | --- | --- | --- |
| **认知(品牌)** | 让用户记住"是谁" | BGM 45-50 · 环境 30-40 · 人声 10-20 | 慢，情绪弧 |
| **兴趣(种草)** | 让用户觉得"我想要" | BGM 35 · 人声 35 · 环境 30 | 中，沉浸 |
| **转化(带货)** | 让用户立刻"买它" | BGM 40 · 人声 40 · 环境 20 | 快，音画卡点 |

### 1.2 query 情绪词定「风格皮肤」

| 情绪信号词 | 皮肤 | 适用 |
| --- | --- | --- |
| 食欲 / 鲜 / 香 / 爆汁 | ASMR · 环境音为主，BGM 极淡 | 美食/烹饪 |
| 燃 / 爽 / 开箱 / 低价 | 鼓点 build-up + drop | 测评/开箱 |
| 甜 / 少女 / 治愈 | 清新流行·木吉他·钟琴 | 美妆/穿搭 |
| 高级 / 质感 / 静谧 | 钢琴独奏·氛围 pad | 品牌/形象 |
| 温情 / 亲子 / 陪伴 | 弦乐·钢琴·暖民谣 | 母婴/节日 |
| 科技 / 参数 / 硬核 | 合成器电子·脉冲 | 3C/科技 |
| 共情 / 自嘲 / 破防 | 弱起钢琴 + 中段弦乐推进 + 末段鼓 | 情感/故事 |

### 1.3 BGM 4 字段(填入 storyboard 表头「音频策略」行)

`风格(乐器/参考+BPM) + 情绪 + 入点/淡出时点 + 关键节点`

```
目标: 转化(带货)
情绪信号: 燃 + 低价
↓ BGM 皮肤: 鼓点 build-up + drop
↓ 4 字段:
电子鼓点(底鼓+军鼓，120BPM，无歌词) · 抓耳/快节奏 · 0s入2s到-14dB · 镜2 buildup·镜5 drop·镜8 末拍卡点
```

### 1.4 BGM 4 字段详解

| 字段 | 含义 | 写法 | 示例 |
| --- | --- | --- | --- |
| 风格(乐器/参考+BPM) | 乐器 + 参考曲风 + 数字 BPM | 必带数字 BPM，无歌词声明 | `清新民谣(木吉他+钟琴，95BPM，无歌词)` |
| 情绪 | 一个情绪标签，不要堆叠 | "悲壮+燃+治愈" 会自相矛盾 | `轻快治愈` |
| 入点/淡出时点 | 入点 + ramp 时长 + 目标 dB | 淡出对称写在末尾 | `0s入3s到-16dB` |
| 关键节点 | BGM 在哪一镜推满/淡出 | 与分镜表镜号一一对应 | `镜3副歌推满·镜6淡出至-30dB` |

**常见错误写法**:
- "轻音乐" → 缺风格 + BPM + 情绪，无法执行。
- "开头慢慢进来，然后在副歌推满" → "进来""推满"是**静止动词**，必须改 `0s入3s到-16dB`。
- "用《Faded》那种风格" → 有版权，生产环境禁用；改 `合成器电子·脉冲(类似风格但无版权)，120BPM`。

## §2. 三层音频架构(每镜都设计，写进 prompt)

### 2.1 人声(Voice)——三选一

| 类型 | 适用 | 关键约束 |
| --- | --- | --- |
| **有对白** | 转化/测评/教程/带货 | 金句前置，口条自然(见 §4) |
| **纯 OS 心声** | 剧情/情感/溯源/共情 | 内心自语感，低音量慢速 |
| **无对白** | 质感/试穿/品牌/ASMR | 加厚环境音 + 生理音(呼吸/衣物摩擦)补信息 |

### 2.2 环境音(Ambient/SFX)——换场景就换环境音

每镜写 2-3 个可辨识环境音词；关键音效点单独标镜次+时机+音效名。

```
环境音: 家居窗边 · 风声+纱帘摩擦+远处鸟鸣
音效点(镜3·2.5s): 裙摆"沙沙"加重
```

**无对白也写"生理音"**:质感/试穿片走无对白时，保留呼吸/衣物摩擦/脚步。

```
人声: 无对白 · 镜2转身呼气 / 镜4微笑吸气 / 镜5衣物摩擦
```

### 2.3 BGM——写清 4 字段(见 §1.4)

1. **风格匹配目标**——带货片用强节拍卡点；质感/情感片避开套路 BGM。
2. **BGM 至少 1 次动态起伏**(淡入/副歌/停顿/淡出)，全程一个音量 = 听觉疲劳。
3. **带中文歌词的曲子带货可用**(助记)，剧情/情感片避免(抢戏)。

## §3. 自然口条(消除 AI 机器味)

AI 人声默认播音腔。要"像人"，把下面规则写进音频策略行。

### 3.1 每 8-12 字一次换气

| ❌ 播音腔 | ✓ 自然口条 |
| --- | --- |
| "今天给大家推荐一款我们家的明星单品" (16字不换气) | "今天给大家推荐一款，/ 嗯，就是我们家的明星单品" (9字换气) |
| "这个价格真的是全网最低" (12字) | "这个价格，/ 嗯，真的 / 是全网最低" (5字一次停顿) |

### 3.2 关键词前微停

| ❌ 平铺直叙 | ✓ 关键词前置停顿 |
| --- | --- |
| "三块九包邮到家" | "三块九，/ 包邮到家" |
| "这个材质是纯棉的" | "这个材质，/ 是纯棉的" |

### 3.3 尾字自然下沉

| ❌ 上扬尾字 | ✓ 下沉尾字 |
| --- | --- |
| "你觉得怎么样?" (尾字上挑) | "你觉得怎么样~?" (尾字下沉) |
| "家人们冲不冲?" | "家人们，冲不冲?" |

### 3.4 拟声词+语气词

| ❌ 无情绪修饰 | ✓ 有情绪修饰 |
| --- | --- |
| "这个味道很好" | "这个味道，啧~真的 / 是绝了" |
| "我不知道怎么形容" | "哎呀，这个怎么形容呢~" |

### 3.5 口条节奏参考(8-12s 镜头容量)

| 镜头时长 | 字数 | 节奏 |
| --- | --- | --- |
| 2.0s | 5-7 字 | 快切速说 |
| 3.0s | 8-12 字 | 中速带停顿 |
| 4.0s | 13-18 字 | 慢速带情绪 |
| 5.0s | 20-25 字 | 慢速 + 拟声 |

## §4. 静音法则(沉默是一种工具)

3 种静音 + 1 个反模式。

### 4.1 M1 · 情绪反转前全断(0.5-1s)

- **用途**:情感/数据/价格爆点前的张力堆积。
- **写法**:音频策略行追加 `镜N 前 0.5-1s 全断`。
- **样例**:`镜3 前 0.8s 全断 → 镜4 价格"3.9元"推满`。

### 4.2 M2 · 数据字幕前 BGM 降 6dB + 短音效

- **写法**:`镜5 数据字幕 "1mm 超薄"前 BGM 降 6dB + 短"叮"`。

### 4.3 M3 · 质感片末镜只留环境音

- **写法**:`末镜 BGM 淡出，只留环境音`。
- **样例**:`末镜 钟琴淡出，只留鸟鸣`。

### 4.4 反模式 · 全片无静音

- ❌ 信息密度被 BGM 抹平，价格/数据/CTA 被盖住
- ❌ 完播率掉 30-50%

### 4.5 自检

- 15s 段至少 1 处静音/降 BGM；30s 段至少 2 处；质感片至少 1 处末镜静音。

## §6. 配音落地(VO)与能力边界

> 直出优先；模型音画直出能满足时不需后期。只有对白/口型需要精确时，才落 VO 音轨混入成片。

### 6.1 语言锁定

**方言/外语/男声需显式指定 voice**，默认不推断语言。TTS 默认 `zh-CN` 女声。

### 6.2 音画同步

视频模型对口型的支持因 Provider 而异，配音片选镜时优先非口型特写。TTS 逐句拼接只保证"人声在对应时间段"。

### 6.3 环境音/BGM

TTS 只负责"人声落地"，环境音/BGM 仍由 prompt 直出或剪辑层实现。
