# Character · 角色设计

> 本文件是 **5 步流程的 step 2 · 定人物** 的主文档。负责定义视频主体(人物/动物/产品)的写法、颗粒度与人物-事件一致性检查。
>
> **何时用**: 分镜表骨架(A/B/C)选定后,本步确定"谁在演";Final Prompt 的 `Main subject` 段按本文件输出。
>
> **不负责**: 骨架选择([storyboard.md](storyboard.md))、场景/环境([scene.md](scene.md))、动作与镜头语言([prompt-craft.md](prompt-craft.md))。

---

## §1 角色四层结构(定人)

从粗到细四层,主角才写满三层以上:

```
[身份标签] + [外貌特征] + [服装描写] + [气质/状态修饰]
```

| 层级 | 作用 | 实例 |
| --- | --- | --- |
| 第一层 身份标签 | 调用模型已有形象模板 | "赛博朋克深海潜员" / "古风少女" / "a 6-month-old pinto foal" |
| 第二层 外貌特征 | 模型可画面化的特征 | "短发的中年男人" / "brown-and-white with a fluffy mane" |
| 第三层 服装描写 | 信息密度最高,颜色最易执行 | "穿黑色长风衣的" / "一袭白衣" |
| 第四层 气质/状态 | "看起来什么感觉" | "气质冷峻的" / "joyful temperament" |

**锁定原则**: 主体描述词**全片/全系列锁同一套**,改一个词模型就漂移。

## §2 不同主体的写法差异

| 主体类型 | 优先级 | 关键字段 | 注意事项 |
| --- | --- | --- | --- |
| **人像** | 服装 > 外貌 > 身份 > 气质 | 颜色 + 款式 + 风格(国风/街头/运动) | 5 个关键特征足够,过多描述模型抓不住 |
| **动物** | 物种 + 年龄 + 关键外观 | 物种/品种/毛色/月龄/姿态 | 4 个月以下幼体模型易崩,优先用成熟体 |
| **产品** | 品类 + 颜色 + 关键卖点 | 产品名 + 配色 + 材质 + 标志特征 | 通用名(如"连衣裙")远不如具体描述("米白色针织连衣裙,腰部系带") |
| **抽象主体**(品牌 logo / 概念) | 风格 + 配色 + 构图 | 视觉特征 | 极少用,t2v 模型对纯抽象概念理解差 |

## §3 micro-action(让角色"活"起来)

主体必须包含微观动作,否则画面呈"3D 模型平移感"。**micro-action 写进 Final Prompt 的 `Action` 段,不写进角色描述**——它是动作层的元素。

| 主体类型 | micro-action 短语 |
| --- | --- |
| 动物 | `with subtle ear twitches, light tail sway, occasional eye blinks` |
| 人像 | `with soft breathing visible, hair lightly swaying, gentle eye movement` |
| 食物/产品 | `with steam rising slowly, surface texture shifting` |

完整 micro-action 写法见 [character.md §3](character.md)。避坑三陷阱的"静止动词陷阱"执行版见 [prompt-craft.md §4.2](prompt-craft.md)。

## §4 人物-事件一致性检查(R6 在本步的应用)

**核心问题**: 角色四层填完后,检查角色是否与 step 1(写故事)定下的事件匹配。**这是 R6 事件逻辑自洽在本步的具体执行**。

### 4.1 检查项

逐项回答,任一为否就回头改:

| # | 问题 | 反例 |
| --- | --- | --- |
| 1 | **服装与场景匹配吗?** | 车间工人穿西装礼服;厨房厨师穿睡衣 |
| 2 | **身份与动作匹配吗?** | 礼仪小姐推机床;程序员操作锻压设备 |
| 3 | **外貌/气质与故事情绪匹配吗?** | 共情子型(打工人疲惫)用"气质冷峻的赛博朋克战士" |
| 4 | **年龄/体型与场景安全性匹配吗?** | 老人爬脚手架;儿童操作工业设备 |

### 4.2 服装-场景冲突速查

| 场景 | 应避免的服装 | 推荐 |
| --- | --- | --- |
| 车间/工厂 | 西装、礼服、睡衣、拖鞋 | 作业服 + 安全帽 + 工靴 |
| 厨房 | 西装、礼服、外套 | 围裙 + 厨师服 + 头巾 |
| 雨雪户外 | 短袖、薄衣 | 雨衣/防风衣 + 防水鞋 |
| 宴会厅 | 围裙、作业服 | 正装/礼服(视场合) |
| 雪地/冬季 | 短袖、凉鞋、单衣 | 厚外套 + 雪靴 + 毛线帽 |

### 4.3 与下游环节的接口

- **Final Prompt 的 `Main subject` 段**: 角色四层直接搬入,关键特征锁定(只锁关键特征,不重复全部四层)
- **场景三层**(step 3): 服装决定光照方向(深色 → 强光提反差;浅色 → 柔光)
- **动作段**: micro-action 写进 Action 段,不放角色描述
- 完整 5 维一致性矩阵见 [storyboard.md §5.6](storyboard.md)

## §5 反例(本步常见翻车点)

| 反例 | 错在哪 | 修正 |
| --- | --- | --- |
| 角色只写"一个女孩" | 第一层身份缺,模型自由发挥 | 写"古风少女"(身份)+ "长发披肩"(外貌)+ "一袭白衣"(服装)+ "气质忧郁"(气质) |
| 全片换服装 | 主体漂移,模型认不出是同一人 | 主线段固定同一套四层,变装只发生在叙事情节转折处 |
| 角色描述里塞动作 | 角色层和动作层职责混乱 | 动作归动作段,角色只写"是谁、穿什么、看起来什么感觉" |
| 微距产品拍人物 | 类型错配,模型用产品纹理填人脸 | 写"产品"主体时不要混人脸;同人像路径分镜 |
