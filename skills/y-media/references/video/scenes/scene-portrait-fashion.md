# 场景 · 人像 / 穿搭 / 时尚

> 与 [scene-nature-animal.md](scene-nature-animal.md)、[scene-lifestyle-aesthetic.md](scene-lifestyle-aesthetic.md) 平级。本文件覆盖**人物出镜/穿搭展示/时尚街拍/美妆**类场景,涉及真人或人像化主体。
>
> 重要约束:本场景 t2v 模型对**真人脸生成有风险**(参见 [../t2v-model-capability.md](../t2v-model-capability.md))。**强烈建议优先用 i2v(图生视频)以参考图锚定人脸**,不要纯 t2v 生成陌生人脸。

## 1. 场景定性

| 维度 | 内容 |
| --- | --- |
| 板块共性 | 人物为主体 + 服装/妆容细节 + 时尚氛围 |
| 首选骨架 | 骨架A快速展示(9-12镜,单镜1.0-2.5s) / 骨架B慢切(5-7镜,2.5-4.0s) |
| 视听路线 | 可含字幕(产品名/价格/CTA)/ 无字幕(高级感) |

| 美学母体 | 取决于风格——杂志/街头/古风/赛博;色温按风格定 |

## 2. 子场景卡片

### 2.1 杂志人像 / 高级感

- **场景定性**: 静态 + 高级 + 杂志质感
- **首选骨架**: 骨架B(5-7镜,慢切)
- **光影模板**: 柔光箱 4500K 光比 1.5:1 / 伦勃朗光 3800K 光比 3:1
- **音频皮肤**: 钢琴独奏 60-80BPM / 暖民谣
- **7秒高潮点**: 慢动作甩发 / 服装细节特写 / 眼神流转
- **典型 3 镜**: 全身站姿(中远景)→ 半身姿态(中景)→ 面部表情(中近景)
- **环境模板(3+1)**: 极简背景墙 / 沙发椅 / 植物 + 一束顶光/侧光
- **AI 生成禁区**: 恐怖谷、面部变形、棚拍纯色背景

### 2.2 街拍 / 时尚穿搭

- **场景定性**: 动态 + 街头 + 潮酷
- **首选骨架**: 骨架A(9-12镜,快切)
- **光影模板**: 阴天漫射 6000K / 黄金时刻 3500K / 霓虹夜景
- **音频皮肤**: trap 100-130BPM / 电子 110-140BPM
- **7秒高潮点**: 转身甩发 / 步态节奏 / 服装动态
- **典型 3 镜**: 全身走姿(全景)→ 半身跟随(中景)→ 服装细节(特写)
- **环境模板(3+1)**: 城市街道 / 涂鸦墙 / 霓虹招牌 + 行人虚化
- **AI 生成禁区**: 服装穿模、鞋底悬浮、步态僵硬

### 2.3 美妆 / 护肤展示

- **场景定性**: 极近景 + 细节 + 治愈
- **首选骨架**: 骨架B慢切(5-7镜,大量特写)
- **光影模板**: 环形灯 5000K 柔光光比 1:1 / 窗光 4500K
- **音频皮肤**: 钢琴独奏 / ASMR 无 BGM
- **7秒高潮点**: 涂抹瞬间 / 滴管落下 / 质地纹理特写
- **典型 3 镜**: 产品全景(中景)→ 质地纹理(微距特写)→ 使用过程(中近景)
- **环境模板(3+1)**: 镜面台 / 化妆刷 / 玻璃瓶器 + 柔光
- **AI 生成禁区**: 化妆品变形、手部畸形(常见 6 指)

### 2.4 古风 / 国风人像

- **场景定性**: 仙气 + 仪式 + 电影感
- **首选骨架**: 骨架B(5-7镜,慢切)
- **光影模板**: 侧逆光 4500K 薄雾 / 体积光束
- **音频皮肤**: 古琴+尺八 60-80BPM
- **7秒高潮点**: 长袖飞舞 / 衣袂飘动 / 转身侧颜
- **典型 3 镜**: 全身站姿(全景)→ 半身衣袂(中景)→ 面部特写(中近景)
- **环境模板(3+1)**: 竹林/亭台/古道 + 薄雾/灯笼/花瓣
- **AI 生成禁区**: 服装繁复花纹穿模、头发穿模

| 主体 | 角色四层模板(执行层) |

## 7. 反模式(本场景常见翻车点)

| 反模式 | 症状 | 修复 |
| --- | --- | --- |
| 恐怖谷人脸 | 面部变形/眼神诡异 | **强 i2v**,不纯 t2v |
| 6 指/多肢 | 手部畸形 | 加 `anatomically correct hands, five fingers each hand` |
| 服装穿模 | 服装花纹错乱/穿模 | 简化服装描述,避免繁复花纹 |
| 鞋底悬浮 | 走路不沾地 | 加 `gravity correct, feet on ground` |
| 步态僵硬 | 走路像 3D 平移 | 慢动作,加 微动作(头摆/臂摆) |
| 脸崩 | 跨镜脸变形 | i2v + `same face across all frames` |
| 头发穿模 | 头发穿肩/穿衣 | 短发优先,长发需多段拼接 |

## 8. i2v 绑定范式

i2v 输入时,prompt 必须显式声明:

```text
★ Main subject: Same person as <图片1> — [补充角色四层特征以加固].
keep the same facial features, hairstyle, and clothing across all frames (no character drift).
```

详见 [../t2v-model-capability.md](../t2v-model-capability.md) F11 关键帧/参考图。
