# 场景 · 美食 / ASMR

> 与 [scene-nature-animal.md](scene-nature-animal.md)、[scene-lifestyle-aesthetic.md](scene-lifestyle-aesthetic.md)、[scene-portrait-fashion.md](scene-portrait-fashion.md) 平级。本文件覆盖**食物/烹饪/饮品/ASMR**类场景。
>
> ASMR 路线的**声音描述对 t2v 模型无效**(M6),本场景的声音(咀嚼/撕包装/烹饪嗞啦)只能进 `Notes for downstream audio`,不进 prompt。

## 1. 场景定性

| 维度 | 内容 |
| --- | --- |
| 板块共性 | 感官细节 + 质地纹理 + 治愈食欲;近景/特写为主 |
| 首选骨架 | 骨架A快速展示(切/倒/咬,9-12镜,1.0-2.0s) / ASMR 极慢(3-5镜,3-5s) |
| 视听路线 | 无字幕或极简(食物名+价格);ASMR 无字幕 |
| 叙事禁区 | 避免食物变形/穿模;避免塑料感 |
| 美学母体 | 暖食欲(暖金/焦糖/奶白/番茄红),色温 3000-4500K |

## 2. 子场景卡片

### 2.1 烹饪过程(嗞啦声向)

- **场景定性**: 动态 + 感官 + 食欲
- **首选骨架**: 骨架A(切菜/下锅/翻面,6-10镜)
- **光影模板**: 顶光 4000K 柔光 / 厨房暖光 3000K
- **音频皮肤**: 无 BGM(纯烹饪音) / 暖民谣极淡
- **7秒高潮点**: 油嗞啦 / 切面展开 / 蒸汽升腾
- **典型 3 镜**: 食材全景(中景)→ 下锅瞬间(中近景)→ 翻面焦色(特写)
- **环境模板(3+1)**: 木质砧板 / 铸铁锅 / 陶瓷碗 + 蒸汽/油光
- **AI 生成禁区**: 食物穿模变形、塑料感、火焰/烟雾异常

### 2.2 成品展示(摆盘向)

- **场景定性**: 静态美 + 高级 + 食欲
- **首选骨架**: 骨架B慢切(5-7镜)
- **光影模板**: 顶光 4500K 柔光 / 侧窗 4000K
- **音频皮肤**: 钢琴独奏 / 无 BGM
- **7秒高潮点**: 360° 旋转 / 蒸汽升腾 / 拉丝/拉花
- **典型 3 镜**: 桌面全景(中远景)→ 摆盘细节(中景)→ 拉丝/拉花(特写)
- **环境模板(3+1)**: 木质餐桌 / 亚麻桌布 / 餐具 + 鲜花/绿植
- **AI 生成禁区**: 食物变色、塑料餐具、过度鲜艳

### 2.3 ASMR / 极慢感官

- **场景定性**: 极慢 + 治愈 + 极近景
- **首选骨架**: ASMR 极慢(3-5镜,3-5s,单镜长)
- **光影模板**: 顶光柔光 4500K / 环形灯 5000K
- **音频皮肤**: **无 BGM**,纯环境音
- **7秒高潮点**: 撕包装 / 切开 / 咀嚼 / 滴落
- **典型 3 镜**: 包装细节(微距)→ 撕开瞬间(微距)→ 内容物展开(微距)
- **环境模板(3+1)**: 微距主体(食物/产品) + 一束顶光 + 暗背景
- **AI 生成禁区**: 失焦、运动过快、镜头晃动

### 2.4 饮品 / 拉花

- **场景定性**: 慢动作 + 治愈 + 仪式
- **首选骨架**: 骨架B慢切(5-7镜)
- **光影模板**: 顶光 4500K 柔光 / 侧窗 4000K
- **音频皮肤**: 钢琴独奏 / 暖民谣
- **7秒高潮点**: 拉花成型 / 蒸汽升腾 / 注入瞬间
- **典型 3 镜**: 杯具全景(中景)→ 注入咖啡(中近景)→ 拉花特写(微距)
- **环境模板(3+1)**: 陶瓷杯 / 木质托盘 / 拉花缸 + 暖光
- **AI 生成禁区**: 拉花穿模、液体颜色异常、蒸汽缺失

## 4. 音频皮肤库(本场景声音密集,展示层必备)

| 情绪 | 风格 | 乐器 | BPM | 适用 |
| --- | --- | --- | --- | --- |
| 暖食欲 | 暖民谣 | 木吉他+口琴 | 65-90 | 成品/饮品 |
| 高级 | 钢琴独奏 | 钢琴 | 60-80 | 摆盘 |
| 燃节奏 | 鼓点 build-up | 鼓+合成器 | 110-130 | 变装/卡点 |
| ASMR 纯音 | 无 BGM | 环境音为主 | — | 极慢感官 |

**环境音拟声词库**(展示层,移出 prompt):
- 烹饪: 嗞啦(下锅) / 咕嘟(炖煮) / 噗(蒸汽) / 铛(金属锅)
- 切/撕: 咔嚓(切) / 嘶啦(撕包装) / 嘎嘣(咬)
- 液体: 潺潺/哗啦(注入) / 滴答(滴落) / 咕嘟(气泡)
- 咀嚼: 咔嚓/嘎嘣(脆) / 吧唧(软)
- 餐具: 叮(碰杯) / 咔哒(放盘)

## 6. 主体描述模板(执行层)

| 主体 | 描述范式 |
| --- | --- |
| 通用菜 | `A [size] [dish name] on a [plate type], with [garnish], [lighting], [micro-action: steam rising slowly]` |
| 烘焙 | `A [size] [baked good] with [texture: golden crust / soft crumb], on a wooden board, warm light` |
| 饮品 | `A [type] drink in a [cup] with [topping: latte art / foam], steam rising, soft window light` |
| 水果 | `[Number] [fruit type]s with dew drops, on a ceramic plate, soft side light, vibrant colors` |
| ASMR 主体 | `A close-up of [object], with [micro-action: tearing / pouring / cutting], under top key light, dark background` |

## 7. 反模式(本场景常见翻车点)

| 反模式 | 症状 | 修复 |
| --- | --- | --- |
| 食物变形 | 食物穿模/变形状 | 加 `food keeps natural shape, no deformation` |
| 塑料感 | 颜色过饱和/反光异常 | 降饱和 -5,加 `natural food texture` |
| 火焰异常 | 油火/烟雾变形 | 简化,不写明火,加 `steam/smoke natural` |
| 颜色怪异 | 食物变色(熟肉发蓝等) | 写实色彩锚,加 `natural food colors` |
| 镜头过快 | 切/撕动作僵硬 | 慢动作,加 `slow motion` |
| 失焦 | ASMR 微距脱焦 | 浅景深但主体对焦明确 |
| 餐具穿模 | 刀叉穿食物 | 简化餐具,或避免与食物同镜 |

## 8. ASMR 路线特殊约束

| 约束 | 原因 | 修复 |
| --- | --- | --- |
| 声音不进 prompt | M6: 当前 Agnes 不生成分时音频(边界见 t2v-model-capability.md) | 全部进 `Notes for downstream audio` |
| 必须极慢 | ASMR 灵魂是慢 | 3-5s/镜,加 `slow motion` 或 `time-lapse of micro motion` |
| 必须微距 | 感官细节 | `macro lens, 1:1 close-up`,主体占画面 80%+ |
| 暗背景 | 突出主体 | `dark background with top key light` |
| 无 BGM | 保留环境音主体 | 不写 BGM,只写 `pure ambient sound` (在 Notes) |
