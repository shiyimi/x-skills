# 字幕规范(Subtitle Spec)

> **定位**:y-media 的字幕路线主文档。一支片里字幕"用不用 / 用什么 / 怎么用"由本文方法决定。
>
> **与 storyboard.md 的关系**:分镜表「屏显字幕」列的内容、动效、音效按本文填写;[prompt-craft.md](prompt-craft.md) §3 拼接模板的字幕段引用本文。
>
> **核心心智(R3 视听双轨)**:① 字幕**可选**(质感/ASMR/情感片可不用);② 一旦使用,全片字体族/主色/位置/动画锁一套,不要每镜换样;③ 字幕最好由模型直出,尽量不后期烧录。

## 1. 用不用字幕(先判一次)

判定后写进 storyboard 表头"视听路线",全片保持一致。

| 场景 | 字幕路线 | 理由 |
| --- | --- | --- |
| 目标是转化带货 + 投信息流 | **含字幕** | 70% 静音播放,字幕是主信息通道 |
| 品牌/形象/艺术叙事,或走高级质感/情感/感官 | **无字幕或极简字幕(≤2 条)** | 画面+表演+音频已承担 70% 信息量,字幕就是污染物 |
| 拿不准 | **默认不含字幕** | 加字幕容易、加对难;宁可先无后补 |

**无字幕/极简的典型场景**:珠宝情感片、女装质感试穿片、生鲜纯纪录溯源、ASMR、家居空间片、高端 3C 品牌片。

## 2. 六类字幕(一段不必全用)

字幕是独立于口播的第二叙事层。给出不同类型的字幕出现形式,一段中不要求全部出现,在用户需求的基础上适当加上能增加亮点的字幕。

| 类型 | 位置 | 内容 |
| --- | --- | --- |
| ① 钩子 | 0-2s | 痛点问句 / 悬念 / 反常识数据 |
| ② 数据/卖点 | 核心镜 3-7 | 具体数字+单位,避免"高蛋白"这类模糊词 |
| ③ 信任背书 | 中后段 | 品牌/成分/资质/产地/销量/口碑 |
| ④ 行动号召/slogan | 末镜 | A: 指令+利益+紧迫 / B: slogan 或情感 tag / C: 互动设问(骨架C 收尾) |
| ⑤ 氛围/口播同步 | 全片 | 口播关键词高亮,不必逐字 |
| ⑥ 金句/治愈收尾 | 末镜或黑屏 | 情绪总结句,骨架C 合拍必用;黑底白字+关键词黄底高亮 |

**字幕覆盖规则**:
- commerce 路线(转化带货):① ② ③ ④ 必用,⑤ ⑥ 选
- general 路线:按骨架选 2-4 类,不要每类都用

## 3. 风格一致性(字幕"乱"的解药)

字幕多半是"每镜换字体/颜色/位置/动画"。表头一次锁定 5 项、全片复用。**注意:字幕不可以遮挡产品**。

| 锁 | 建议 |
| --- | --- |
| L1 字体族 | 全片 1 种(骨架 A 可"标题+正文"固定配对) |
| L2 主色板 | ≤2 色(主色+强调色);质感片建议 1 色 |
| L3 位置 | 每类字幕固定一个位置(钩子上、卖点中、背书下、CTA 下半) |
| L4 动画 | 全片 1 种主动画(或"主+副"两种),见 §4 |
| L5 描边/阴影 | 描边粗细/颜色/阴影/底板全片统一 |

### 3.1 commerce 字幕 5 风格锁定(推荐模板)

| 字段 | 锁定值 | 适用 |
| --- | --- | --- |
| 字体 | 思源黑体 Bold / 阿里巴巴普惠体 | 通用商业 |
| 色板 | 主白 `#FFFFFF` + 卖点金 `#FFD700` | ≤2 色 |
| 位置 | 钩子/CTA 居中,数据卖点下 1/3 | per type |
| 描边 | 黑边 2px(亮/暗背景都可读) | 通用 |
| 动画 | 弹入放大 0.3s + 停留 1.5s + 缓淡出 0.3s | 通用 |

## 4. 动效设计规范(三阶段 + 6 种入场 + 3 类节奏)

> 字幕**不只是字**,动效决定了字幕的"被注意到度"。同一句字幕,弹入放大 vs 缓慢淡入,完播率能差 30%。

### 4.1 三阶段时间分配(默认 1.5-2.0s 总寿命)

| 阶段 | 时长 | 职责 | 反例 |
| --- | --- | --- | --- |
| **入场** | 0.2-0.4s | 抓住注意力,让用户"看见" | 入场 > 0.6s = 慢吞吞,丢钩子 |
| **停留** | 1.0-1.8s | 让用户"读懂" | 停留 < 0.8s = 没看清;停留 > 2.5s = 占画面 |
| **出场** | 0.2-0.4s | 干净离场,不抢下一镜 | 出场 > 0.6s = 拖泥带水 |

### 4.2 6 种入场动效速查(挑 1-2 种,全段统一)

| 动效 | 视觉感受 | 适合字幕类型 | 风险 |
| --- | --- | --- | --- |
| **弹入放大** (scale 0.7→1.0) | 强注意力,适合钩子/CTA | ① 钩子 ④ CTA | 频繁用会审美疲劳 |
| **上滑淡入** (translateY +20px→0, opacity 0→1) | 自然,适合卖点/数据 | ② 数据 ③ 背书 | 视觉冲击力弱 |
| **逐字打字** (typewriter, 一字一字出) | 节奏感,适合口播同步/金句 | ⑤ 口播 ⑥ 金句 | 不适合长句(>12字) |
| **硬切闪入** (瞬时出现,无渐变) | 强冲击力,适合价格/数字 | ② 价格(转化类) | 用多会"吵" |
| **左滑飞入** (translateX -100%→0) | 横向节奏,适合横向排版 | ② 数据/横向排版 | 竖屏慎用 |
| **黑底白字闪出** (背景淡入+字) | 强对比,适合金句/合拍 | ⑥ 金句(骨架C 合) | 仅末镜或合拍用 |

### 4.3 3 类出场(默认统一,不要混)

| 出场 | 适用 | 反例 |
| --- | --- | --- |
| **缓淡出** (opacity 1→0) | 通用默认 | — |
| **下滑淡出** (translateY 0→+20px, opacity 1→0) | 与"上滑淡入"对称 | 钩子镜慎用,会冲淡钩子 |
| **直接消失** (无渐变,瞬间移除) | 黑底金句/数据卡片 | 普通字幕禁用,太突兀 |

## 5. 音效设计规范(让字幕"被听到")

> 字幕的核心功能之一是"抢静音播放的耳朵"。下面 5 条规则直接给可执行清单。

### 5.1 S1 · 关键字幕配短音效

为"被看到"+"被听到"双通道刺激。

| 字幕类型 | 配音效 | 写法 | 时机 |
| --- | --- | --- | --- |
| ① 钩子 | "叮"(短促) | 前 0.1s 响 | 入场同帧 |
| ② 数据/卖点 | "嗒"(清脆) | 前 0.1s 响 | 入场同帧 |
| ③ 信任背书 | "叮"低八度 | 与"背书"对齐 | 入场后 0.1s |
| ④ CTA | "叮"+"嗒"两连击 | 与"CTA"对齐 | 入场前 0.05s |
| ⑥ 金句 | 无(留白) | — | 静音法则(见 [audio-design.md §5.3](audio-design.md)) |

### 5.2 S2 · 音效与画面/字幕同帧(±0.1s 内)

不然后期剪辑对不上。

写法:在 storyboard 音频策略行写 `镜N 数据字幕"1mm"前 0.1s "叮"`。

### 5.3 S3 · 同一字幕不要重复音效

重复 = 廉价,只给关键字幕(L1+L3+L4 杠杆)配音效,普通字幕走默认 BGM 节奏。

### 5.4 S4 · 价格/数据爆点"先断后响"

写法:`价格"3.9元"前 0.5-1s 全断 → "叮"+"3.9元"同帧`。(即 [audio-design.md §5.1 M1](audio-design.md) + 本节 S1 联动)

### 5.5 S5 · BGM 降 6dB 反衬

音效响起时,同步把 BGM 音量降 6dB(约一半),让音效凸显;0.3-0.5s 后 BGM 自动恢复。

写法:在音频策略行写 `镜N 字幕"叮"前 0.1s BGM 降 6dB,0.3s 后恢复`。

## 6. commerce 增强版(转化类视频的 5 项强制)

> commerce 路线在 §1-§5 的基础上有 5 项强制动作,确保转化类视频"字幕+音效"配齐。

| # | 强制项 | 含义 | 反例 |
| --- | --- | --- | --- |
| **C1** | **6 类字幕按 commerce 规则覆盖** | commerce 必查 ① ② ③ ④ 必用,⑤ ⑥ 选 | 只用钩子+CTA = 信息不足 |
| **C2** | **卖点字幕配音效** | ② ③ 类字幕 100% 配 "叮"/"嗒" | 卖点字幕无声 = 转化率掉 20%+ |
| **C3** | **价格爆点前全断** | ④ CTA 类含价格时,前 0.5-1s 全断(M1) | 平铺直叙的价格 = 不被听到 |
| **C4** | **品牌名逐字渲染** | 品牌名/型号/成分/SPF 用引号 `"ESTĒE LAUDER 雅诗兰黛"` 写入 prompt | 品牌错字 = 信任崩盘 |
| **C5** | **字幕节奏与 BGM 鼓点同帧** | 卖点镜/价格镜字幕入场与 BGM 鼓点同帧(±0.1s) | 字幕比鼓点晚 = 不抓人 |

## 7. 文案原则

| 维度 | 规则 |
| --- | --- |
| 品牌名/型号/成分名 | **零容错(R5 铁律)**:写完后逐字回查,用户给了官方写法严格照搬(大小写·空格·标点),不确定时主动向用户确认,绝不凭记忆猜测 |
| 句长 | 一屏一句,单句 ≤12 字,超了拆两屏 |
| 关键 token | 数字/单位/品牌名用英文引号原样包裹,让模型别改 |
| 绝对化 | 避免"最好""根治""秒变";功效类(滋补/防晒/口腔/母婴)避免"增肌X斤""美白X度" |
| CTA 紧迫感 | 骨架A 用:"仅限今日""前100名""最后X件" |
| 时机 | 出现时机比口播提前半拍,让静音用户先看到 |
| 通读 | 全片字幕按序读一遍能读懂"钩子→卖点"完整链路 |

## 8. 写进 prompt 的四要素

每条字幕写清 **文案 + 时机 + 位置 + 样式(含动画+音效)**:

```
镜1(0-2s):上1/3 出现 "<钩子≤12字>",粗黑体大字号白底黑边,
  whoosh划入+低频"咚",停留1.5s后缓淡出
镜4(6-8s):正中出现 "<数据卖点≤12字>",数字黄色加粗,
  弹入放大+一声"叮"(前0.1s降6dB),停留2s
镜8(13-15s):下方全屏 "<CTA三要素>",红黄对比闪烁3次+上扬"叮咚"
```

关键 token 保真:英文引号包裹并声明"按引号内文字渲染";超 8 字的品牌名可拆两条;出片后逐帧核对,错字只重生成该段。

## 9. 自检 3 问(填完后 30 秒过)

1. **字幕路线对吗?** §1 决策表选的是哪一条?全片保持一致。
2. **关键字幕都配音效了?** ① ② ④ 必配音效(S1),价格爆点必带 S4 静音法则。
3. **品牌名逐字核对了吗?** R5 铁律:长品牌名/型号/成分/SPF/价格/资质/限量数字逐字核对,引号包裹,prompt 加 `verbatim` 指令。
