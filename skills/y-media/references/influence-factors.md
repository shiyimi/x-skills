# 视频生成影响因子与要素清单 · Influence Factors

> 本文件定义"一个视频生成 prompt 的质量由哪些因子决定",以及每个因子的**有效填写阈值**。当 [storyboard-methodology.md](storyboard-methodology.md) 要求"填满 11 列"时,本文件解释"为什么填、填到什么程度模型才听话、填错会出什么问题"。与 [cinematography-reference.md](cinematography-reference.md) 配合:那里给"填什么词",这里给"填到什么数"。

---

## 0. 总览:10 个影响因子

视频生成质量 = f(以下 10 个因子的填充质量)。每个因子有**权重**(对成片的影响程度)和**阈值**(低于此值模型会"自由发挥"导致失控)。

| # | 因子 | 权重 | 核心问题 | 失控症状 |
| --- | --- | --- | --- | --- |
| F1 | 主体保真度 | 极高 | 主体长什么样? | 漂移、畸形、恐怖谷 |
| F2 | 运动物理 | 极高 | 主体怎么动? | 反物理、扭曲、穿模 |
| F3 | 光影连续性 | 高 | 光从哪来、什么质感? | 闪烁、跳色温、塑料感 |
| F4 | 色彩一致性 | 高 | 什么色调、饱和多少? | 跳色、违和、AI味 |
| F5 | 景深与焦段 | 高 | 什么镜头、虚化多少? | 全清晰无层次、畸变 |
| F6 | 音画同步 | 中 | 声音与画面对应吗? | 声画错位、音量失衡 |
| F7 | 时长与帧率 | 中 | 多长、多少帧? | 卡顿、时长不符、8n+1违规 |
| F8 | 构图与景别 | 中 | 主体在哪、占多少? | 主体偏移、留白错乱 |
| F9 | 情绪传达 | 中 | 什么情绪、怎么递进? | 情绪平、无高潮、割裂 |
| F10 | 约束有效性 | 高 | 不要什么? | 出现禁用元素、文字乱码 |

## F1. 主体保真度 Subject Fidelity

**决定模型能否稳定生成同一主体。** 这是视频生成的头号难题——多镜头间主体漂移是模型最大痛点。

### 影响要素

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 物种/品类 | 明确物种名 | 必填,模糊词(如"动物")必漂移 |
| 年龄/规格 | 具体数值(6个月大/50ml/25岁) | 必填 |
| 外观特征 | 颜色+形态+材质(棕白相间/鬃毛蓬松/四肢修长) | ≥3个特征词 |
| 标识/文字 | 引号原样(品牌名/型号) | 有则必填,引号包裹 |
| 参考图绑定 | image-to-video 用 `以<图片1>为主体` | 有参考图必填 |

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 主体每镜长得不一样 | 特征词太少或每镜改词 | 全片锁同一套描述词,逐字复用 |
| 畸形/多肢/恐怖谷 | 物种+解剖未约束 | 加 `动物解剖与运动物理正确,禁止畸形` |
| 颜色漂移 | 颜色词模糊("棕色") | 改具体("棕白相间,腹部白色,背部棕色") |

### 多镜头一致性策略

1. **描述词锁定**: 第1镜写全主体描述,后续镜复用关键词子集(颜色+物种+1特征)
2. **参考图锚定**: 优先用 image-to-video,`以<图片1>为主体,保持外观一致`
3. **分段接续**: 多段时 `以<前段>末帧作首帧`
4. **避免每镜重写**: 每镜换描述词=每镜换主体

## F2. 运动物理 Motion Physics

**决定动作是否真实可信。** 模型默认运动常反物理(悬浮、穿模、非生物运动)。

### 影响要素

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 动作类型 | 单一具体动作(小跑/冲刺/甩头) | 一镜一动作,多动作必乱 |
| 运动方向 | 方向词(自左向右/由远及近) | 必填 |
| 运动速度 | 量化(m/s 或 x倍速) | 必填,否则默认匀速 |
| 物理约束 | `运动物理正确/重力正确` | 动物/液体/坠落必填 |
| 慢动作 | `约0.8x速(慢动作感)` | 需要时显式声明 |

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 悬浮/不沾地 | 重力未约束 | 加 `重力正确,四蹄落地` |
| 肢体扭曲 | 动作太复杂 | 一镜一动作,拆成多镜 |
| 运动僵硬 | 速度未指定 | 加量化速度 + `运动流畅自然` |
| 穿模(蹄穿地) | 物理未约束 | 加 `运动物理正确,无穿模` |

### 运动速度参考(填到这个数)

- 静止 0 / 缓行 0.3-0.6m/s / 小跑 0.8-1.5m/s / 冲刺 2-5m/s / 奔跑 5-8m/s
- 慢动作: `约0.8x速` / `约0.5x速`;快动作: `约1.5x速`

## F3. 光影连续性 Lighting Continuity

**决定画面是否有"真实拍摄感"。** 模型默认光影常闪烁、跳色温、塑料感。

### 影响要素(四要素全填)

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 光位 | 角度(45°侧光/150°逆光) | 必填 |
| 色温 | 具体K值(4500K) | 必填,不写"暖光" |
| 光比 | 数字比(2:1/4:1) | 必填 |
| 光质 | 硬光/柔光/半硬 | 必填 |
| 光源方向 | 与主体关系(左后侧/正顶) | 必填 |

### 连续性规则

- 同片色温漂移 ≤ ±300K(刻意转场除外)
- 光位方向跨镜不冲突(上一镜左光,下一镜不能右光,除非环绕)
- 时段光要连续(不能上一镜清晨4500K下一镜正午5500K)

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 画面闪烁 | 光位/色温跨镜不连续 | 锁美学母体色温区间,跨镜≤300K |
| 塑料感/扁平 | 光比未填(默认1:1) | 加光比(2:1起,立体感) |
| 棚拍感 | 无环境光描述 | 加 `环境光填充` + 真实场景光源 |
| 过曝/欠曝 | 光比过大未补光 | 三点布光,加辅光降比 |

## F4. 色彩一致性 Color Consistency

**决定色调是否统一、是否有AI味。** 模型默认色彩常过饱和、跳色、违和。

### 影响要素

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 主色 | 命名色(嫩绿/暖金) | 必填 |
| 辅色 | 命名色 | 必填 |
| 色调 | 风格词(治愈/冷调/暖调) | 必填 |
| 饱和度 | ±数值(饱和度+10) | 建议填,默认常过饱 |
| 渐变/对比 | 渐变方向或对比关系 | 有则填 |

### 美学母体锁定

全片锁一套色板,每镜复用。色板写进表头 `美学母体` 行,例:
`嫩绿+暖金+柔粉,清新治愈自然纪录片质感;色温4500-5200K区间自然爬升`

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 跳色/每镜颜色不同 | 未锁美学母体 | 表头锁色板,每镜复用 |
| 过饱和AI味 | 饱和度未约束 | 加 `饱和度+10` 或 `降饱和-10,避免过饱和` |
| 违和配色 | 互补色乱用 | 改邻近色或单色系 |

---

## F5. 景深与焦段 Depth of Field & Focal Length

**决定画面层次与电影感。** 模型默认常全清晰无虚化,缺乏层次。

### 影响要素

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 焦段 | 等效mm(85mm中焦) | 建议填 |
| 景深 | 浅景深/深景深 | 必填,浅景深是电影感关键 |
| 虚化层 | 前景虚焦/背景bokeh | 竖屏必填前景虚焦 |

### 焦段切换规则

- 同片焦段跨度: 16mm↔85mm 自然,跨度过大(16mm↔200mm)易出错
- 竖屏建议: 广角(16-24mm)建环境 → 中焦(50-85mm)抓主体特写

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 全清晰无层次 | 景深未填 | 加 `浅景深` + `前景虚焦/背景bokeh` |
| 画面扁平 | 无前景层 | 加前景虚焦物体(草尖/纱帘) |
| 畸变 | 广角用太近 | 广角只用于远景,近景换50mm+ |

## F6. 音画同步 Audio-Visual Sync

**决定声音是否与画面对应。** 注意:多数视频生成模型音频能力有限,本因子主要规范 prompt 中的音频描述质量,实际成片音频可能需后期。

### 影响要素

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 人声层 | 类型+参数(无对白/OS/对白) | 必填,三选一 |
| 环境音层 | 2-3拟声词+dB | 每镜必填 |
| BGM层 | 4字段(风格+BPM+情绪+节点) | 必填 |
| 音效点 | 镜次·时机·音效·处理 | 关键点必填 |
| 音量关系 | dB值 + 相对关系 | 必填,避免失衡 |

### 音量平衡规则

- BGM 主体 -16dB,高潮 -12dB,收尾淡出至 -30dB
- 人声比 BGM 高 +6dB(对白)或 +3dB(OS)
- 环境音 -20 至 -28dB,不抢主
- 爆点前可全降 6-12dB 反衬

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 音量失衡/听不清 | dB未填 | 填具体dB + 相对关系 |
| 声画错位 | 音效点未标时机 | 加 `音效点(镜3·2.5s)` |
| 听觉疲劳 | BGM全程同音量 | 加动态起伏(淡入/副歌/淡出) |

## F7. 时长与帧率 Duration & Frame Rate

**决定生成是否成功、时长是否匹配。** 帧数违规会导致生成失败或截断。

### 影响要素

| 要素 | 填法 | 规则 |
| --- | --- | --- |
| 时长 | 精确0.1s(2.5s) | 镜头时长之和=目标时长 |
| 帧率 fps | 24/30/60 | 24=电影感首选 |
| 总帧数 | num_frames=round(时长×fps) | ≤441 且满足 8n+1 |
| 快门 | 180°(标准) | 建议填进约束 |

### 帧数速查(8n+1)

| 时长@24fps | 帧数 | 合规 |
| --- | --- | --- |
| 5s | 121 | ✓(8×15+1) |
| 10s | 241 | ✓(8×30+1) |
| 15s | 361 | ✓(8×45+1) |
| 18s | 433 | ✗ 超441,需拆 |

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 生成失败 | 帧数>441或不满足8n+1 | 调整到合规帧数 |
| 时长不对 | 镜头时长之和≠目标 | 重算镜头时长 |
| 卡顿 | 帧率太低 | 提至24fps+ |

---

## F8. 构图与景别 Composition & Shot Size

**决定主体位置与画面信息密度。**

### 影响要素

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 景别 | 命名景别(中近景) | 必填 |
| 机位角度 | 角度(平视/仰拍10°) | 必填 |
| 构图法 | 三分法/中心/留白 | 建议填 |
| 三层结构 | 前景/中景/背景 | 必填,竖屏必填前景 |
| 主体位置 | 画面占比/位置 | 建议填 |

### 竖屏构图规则

- 竖屏必须有前景虚焦层,否则画面扁平
- 中近景以上才填得满竖画面
- 主体通常居中或三分线下交点

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 主体偏移/出画 | 主体位置未填 | 加 `主体居中` / `主体置于三分线` |
| 画面扁平 | 无前景层 | 加 `前景:XXX(虚焦)` |
| 留白错乱 | 构图法未填 | 明确构图法 |

---

## F9. 情绪传达 Emotion Conveyance

**决定情绪是否到位、是否有高潮。** 模型默认情绪常平淡、无起伏。

### 影响要素

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 情绪基调 | 1-2词(欢快无忧/治愈) | 表头必填 |
| 情绪曲线 | 起→承→转→合 或 高起→维持→爆点→收 | 必填,选骨架对应曲线 |
| 高潮点 | ≤7s 出现 | 必填,否则完播率崩 |
| 情绪锚点 | 每镜情绪词(明亮/满足/顶点) | 每镜建议填 |

### 情绪曲线范式

```
骨架A(带货): 高起→维持→7s爆点→收CTA
骨架B(叙事): 缓起→渐升→7s情绪反转→收束
骨架C(共鸣): 痛点起→堆积→7s转折→金句收
```

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 情绪平淡无起伏 | 未设计情绪曲线 | 选骨架曲线,标注每镜情绪拍 |
| 无高潮/完播率低 | 7s前无爆点 | 7s内置视觉或情绪爆点 |
| 情绪割裂 | 跨镜情绪跳变 | 情绪递进,不跳变 |

## F10. 约束有效性 Constraint Effectiveness

**决定模型是否听话、是否出现禁用元素。** 约束块是 prompt 的"负面清单"。

### 影响要素

| 要素 | 填法 | 阈值 |
| --- | --- | --- |
| 背景约束 | `避免纯色渐变背景/棚拍空盒子` | 必填 |
| 色调过渡 | `色调从X自然过渡到Y` | 必填 |
| 路线约束 | 字幕路线约束/无字幕禁文字 | 按路线填 |
| 主体物理 | `运动物理正确/禁止畸形` | 动物/人物必填 |
| 技术参数 | `24fps,快门180°,浅景深` | 建议填 |
| 文字约束 | `禁止文字/字幕/Logo/水印` | 无字幕路线必填 |

### 有效 vs 无效约束

| 有效(具体可执行) | 无效(抽象难执行) |
| --- | --- |
| `禁止恐怖谷或畸形马匹` | `要有高级感` |
| `24fps,快门180°` | `画质要好` |
| `禁止出现任何文字` | `自然一点` |
| `色调从嫩绿过渡到暖金` | `风格统一` |
| `动物解剖与运动物理正确` | `真实感强` |

### 失控症状与修复

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 出现禁用元素 | 约束块缺失或不具体 | 补具体约束(禁什么写什么) |
| 文字乱码 | 字体/编码未约束 | 加 `字体Noto Sans CJK SC,UTF-8,禁拉丁字体` |
| 棚拍感 | 背景约束缺失 | 加 `避免棚拍空盒子` + 真实场景 |

## 11. 因子自查清单(提交前必过)

提交 prompt 前逐项核对,任一不达标则补:

- [ ] **F1 主体**: 物种+年龄+≥3特征词,全片锁同一套?
- [ ] **F2 运动**: 一镜一动作+方向+速度+物理约束?
- [ ] **F3 光影**: 四要素(光位/色温/光比/光质)全填,跨镜≤300K?
- [ ] **F4 色彩**: 主辅色+色调+饱和度,美学母体锁定?
- [ ] **F5 景深**: 浅景深+焦段+前景虚焦层?
- [ ] **F6 音频**: 三层全填+dB值+音效点时机?
- [ ] **F7 帧数**: 时长和=目标,帧数≤441且8n+1?
- [ ] **F8 构图**: 景别+机位+三层结构?
- [ ] **F9 情绪**: 情绪曲线+7s高潮+每镜情绪锚点?
- [ ] **F10 约束**: 约束块具体可执行,无抽象词?

---

## 12. 因子权重与优先级

资源有限时按权重补:

```
P0(必填,缺失即失控): F1主体 > F2运动 > F10约束
P1(必填,影响质量): F3光影 > F5景深 > F4色彩
P2(必填,影响完整度): F6音频 > F9情绪 > F7帧数
P3(建议填,提升精度): F8构图
```

P0 缺一项,成片基本不可用;P1 缺一项,成片可用但质感差;P2 缺一项,成片完整但平淡;P3 缺一项,成片可用但精度略逊。
