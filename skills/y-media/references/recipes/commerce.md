## 1. 商业场景共性

- **产品外观 + 卖点细节 + 利益点证明;主体识别度 100%**
- **首选骨架**:骨架 A 展示(9-12 镜,1.0-2.5s) / 骨架 B(高客单/品牌)
- **视听路线**:**含字幕** + 6 类字幕全用(钩/数据/背书/CTA)
- **路径选择**:① **G-i2v 锚定**(默认:无实拍,先出产品/场景参考图→image-to-video) ② **G-t2v**(纯氛围) ③ **H 分段混合**(产品实拍+场景 AI) ④ **E 纯剪辑**(实拍已备)
- **叙事禁区**:过度修图/穿模/塑料感;对标竞品拉踩;医疗/极限承诺
- **美学母体**:主体居中 + 背景虚化 + 单一光源
- **产品四元素(15s 内必填)**:外观(Look) + 功能(Function) + 信任(Proof) + 驱动(Hook)

## 2. 六大子品类差异

### 2.1 美妆个护

- **场景定性**:细节 + 质地 + 前后对比 + 强 i2v
- **光影**:环形灯 5000K(质地特写) / 侧光 4500K(模特局部)
- **音频**:清新流行(木吉他+钟琴,90-110BPM) / 美妆品牌"开盖音"
- **7s 高潮**:质地特写 / 上脸瞬间 / 前后对比同框
- **典型 6 镜**:外观(钩子)★ → 质地特写 ★ → 上脸 ★ → 前后对比 → 资质/成分 → 价格+CTA ★
- **3+1 真实环境**:浅色大理石台面 / 化妆镜 / 绿植 + 顶光柔光
- **AI 禁区**:化妆品穿模/塑料感;人物面部变形;颜色过艳
- **品牌名零错字**:R5,品牌/成分/SPF 值逐字核对

### 2.2 服饰穿搭

- **场景定性**:强 i2v + 多角度 + 细节材质
- **光影**:街拍侧光 4500K(自然感) / 棚拍柔光 5000K(质感)
- **音频**:时尚电子 / 鼓点 build-up / 清新民谣
- **7s 高潮**:变装瞬间 / 转身动态 / 细节拉链/缝线
- **典型 6 镜**:街拍远景 → 中景走动 ★ → 细节(面料/缝线)★ → 转身/回头 ★ → 多角度同框 → 价格+CTA ★
- **3+1 真实环境**:城市街景 / 棚拍背景 / 镜面 + 自然光或环形灯
- **AI 禁区**:服饰穿模/错位;品牌 logo 变形;面料塑料感

### 2.3 家居家纺

- **场景定性**:场景化 + 治愈 + 真实使用
- **光影**:侧窗 4000K(早午餐) / 顶光 4500K(卧室/客厅)
- **音频**:钢琴独奏 / 暖民谣 / ASMR 极淡
- **7s 高潮**:阳光洒入 / 蒸汽升腾 / 拉链/折叠动作
- **典型 5 镜**:房间全景(钩子)★ → 产品入镜 ★ → 使用微动作 ★ → 细节特写 → 价格+CTA ★
- **3+1 真实环境**:实木家具 / 亚麻布 / 绿植/鲜花 + 侧窗自然光
- **AI 禁区**:房间穿模/物品漂浮;塑料感;品牌 logo 错误

### 2.4 数码家电

- **场景定性**:参数 + 实测 + 强对比
- **光影**:顶光 5000K(科技感) / 暗背景顶光(高端展示)
- **音频**:合成器电子(脉冲音效,115-130BPM) / 极淡科技 pad
- **7s 高潮**:开机/启动瞬间 / 数据飞涨 / 屏幕特写
- **典型 6 镜**:产品全景(暗背景)★ → 开机/启动 ★ → 屏幕特写 → 实测对比(左旧右新)★ → 数据字幕 → 价格+CTA ★
- **3+1 真实环境**:暗色桌面 / 数字屏幕 / 线材 + 顶光
- **AI 禁区**:屏幕内容穿模/乱码;按钮/接口错位;数字乱跳
- **数字零错字**:参数/价格/型号逐字核对(R5)

### 2.5 母婴亲子

- **场景定性**:温情 + 安全 + 信任背书
- **光影**:暖光 3500K(母婴安全) / 侧窗 4000K(亲子日常)
- **音频**:弦乐+钢琴+暖民谣(65-90BPM) / 钟琴
- **7s 高潮**:宝宝笑 / 妈妈抚触 / 安全感细节
- **典型 5 镜**:宝宝日常(钩子)★ → 产品特写 ★ → 使用微动作 ★ → 安全/成分字幕 → 价格+CTA ★
- **3+1 真实环境**:婴儿房 / 木质玩具 / 棉织物 + 暖光
- **AI 禁区**:宝宝面部穿模(伦理高敏);颜色过艳
- **0-3 岁宝宝面部**:走 E 纯剪辑,AI 生成禁用

### 2.6 通用带货 / 通用产品演示

- **场景定性**:跨品类 / 无明确品类归属 / 试用品
- **光影**:顶光 4500K 柔光(通用安全牌)
- **音频**:鼓点 build-up + drop(转化) / 清新民谣(种草)
- **7s 高潮**:产品开箱 / 核心功能 / 价格爆点
- **典型 6 镜**:开箱瞬间 ★ → 产品全景 ★ → 核心功能 ★ → 前后/同框对比 → 数据/资质 → 价格+CTA ★
- **3+1 真实环境**:浅色背景 / 木质桌面 / 极简道具 + 顶光

## 7. 商业场景反模式

| 反模式                 | 症状                 | 修复                                                                                    |
| ---------------------- | -------------------- | --------------------------------------------------------------------------------------- |
| 产品穿模               | 物品漂浮/穿插        | 加 `product keeps natural shape, no deformation, no floating`                           |
| 塑料感                 | 颜色过饱和/反光异常  | 降饱和 -5,加 `natural material texture`                                                 |
| 品牌错字               | 品牌名拼错/logo 变形 | 强制 R5,品牌/型号逐字核对                                                               |
| 数字乱跳               | 价格/规格/容量错乱   | 数字逐字核对,加 `numbers and brand names in quotes must be rendered exactly as written` |
| 价格无紧迫感           | 转化类不给优惠锚     | CTA 加 `前 N 名 / 仅限今日 / 限时 24h`                                                  |
| 真人面部变形           | 模特脸/手穿模        | 涉及真人走 E 纯剪辑;走 H 路径时用手部/局部特写                                          |
| 颜色过艳               | 美妆/服饰过饱和      | 降饱和 -5 ~ -10                                                                         |
| 背景太花               | 产品被背景抢戏       | 背景虚化 + 浅色系,主体占画面 50%+                                                       |
| 0-3 岁宝宝面部 AI 生成 | 伦理高敏             | 走 E 纯剪辑,AI 不生成;局部特写(手脚/产品)可以 AI                                        |

## 8. 商业场景合规清单(发布前必查)

| 维度      | 必查                                    |
| --------- | --------------------------------------- |
| 广告法    | 无"最/第一/国家级/销量冠军"等绝对化用语 |
| 品牌名    | 逐字核对,逐字渲染                       |
| 价格/优惠 | 数字 + 单位 + 期限均明确                |
| 资质/认证 | 有据可查,不可伪造                       |
| 功效      | 不做医疗承诺;化妆品不写"治疗"           |
| 母婴      | 不出现 0-3 岁宝宝面部(AI 生成禁用)      |
| 版权 BGM  | 不直接用《Faded》等版权曲,改无版权皮肤  |

## 9. 商业场景主体描述模板

- 美妆: `A [brand] [product type] in [color], on a [surface], with [texture: glossy / matte / creamy], under [ring light], [micro-action]`
- 服饰: `A [gender] wearing [brand] [item], [material: cotton / linen / leather], [fit: slim / loose], [micro-action: 转身/走/拉链]`
- 家居: `A [room type] with [item] in [color/material], [lighting], [micro-action: 铺/折/擦]`
- 数码: `A [brand] [product] in [color], on a [dark / minimal] surface, screen [state], [micro-action: 开机/滑动/按键]`
- 母婴: `A [item] in [color], on a [wooden / fabric] surface, [warm light], [safety: food-grade / organic / CE-marked]`
- 通用: `A [product type] in [color], on a [neutral] surface, with [key feature], [micro-action], under [top key light]`
