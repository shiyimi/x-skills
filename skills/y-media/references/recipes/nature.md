## 1. 板块共性

- **情绪治愈 + 真实自然 + 无对白 + 慢节奏**
- **首选骨架**:骨架B(5-8 镜,单镜 2.0-5.0s)
- **视听路线**:**无字幕**(画面+BGM+环境音承担信息)

- **美学母体**:自然色(嫩绿/暖金/天蓝/大地色),色温 4500-5200K,浅景深

## 2. 三大子场景差异(本场景才有)

### 2.1 野生动物 / 自然纪录片

- **光影**: 黄金时刻(3200-4000K,15-30°低角) / 清晨侧逆光(4500K,光比 3:1) / 阴天漫射(6000K,1.5:1)
- **音频**(M5 §1):清新民谣(90-110BPM) / 氛围 pad(60-80) / 纯环境音无 BGM
- **7s 高潮**:动物突然动作爆点(冲刺/跃起/甩头)或逆光剪影定格
- **典型 3 镜**:草甸晨雾(全景) → 动物特写(中近景) → 动作瞬间(微距)
- **3+1 真实环境**:草甸(草尖+野花+晨雾+侧逆光) / 森林(树干+苔藓+光斑+顶光) / 水边(卵石+水波+芦苇+侧光)

### 2.2 宠物治愈 Vlog

- **光影**:室内窗光(侧窗光 4500K,光比 2:1) / 暖顶灯(3000K,1.5:1) / 阳台自然光(5000K)
- **音频**:暖民谣(65-90BPM) / 钢琴独奏(60-80)
- **7s 高潮**:宠物表情特写(歪头/打哈欠/摇尾)或互动瞬间
- **3+1 真实环境**:客厅(沙发+抱枕+地毯+窗光) / 卧室(床+窗帘+台灯+暖光) / 草坪(草地+玩具+树影+日光)

### 2.3 自然风景 / 风光

- **光影**:蓝调时刻(8000-10000K) / 黄金时刻(3200-4000K) / 雾天漫射(6500K)
- **音频**:氛围 pad(60-80BPM) / 纯环境音(风声/水声/鸟鸣)
- **7s 高潮**:光线变化爆点(日出破云/云海流动/光束穿透)或大远景揭示
- **3+1 真实环境**:山景(山脊+云海+松林+黄金光) / 水景(湖面+倒影+芦苇+侧光) / 森林(树干+苔藓+光斑+顶光)

## 3. 视听默认(一句话)

- **音频皮肤**:清新民谣(90-110BPM)/氛围 pad(60-80)/纯环境音无 BGM
- **字幕默认**:**不用**;仅在纪录片叙述/科普(OS 解说)时启用 OS 字幕
- **美学母体**:自然色(嫩绿/暖金/天蓝/大地色),色温 4500-5200K,浅景深,16mm→85mm 自然切换

## 4. prompt 模板片段(本场景常用)

**角色四层**(动物类):
```
A [age]-month-old / [age]-year-old [species] with [coat pattern/feature],
[age-appropriate temperament: protective / curious / playful],
anatomically correct, natural wildlife proportions
```

**光影句**(数字留 §4 声场设计稿,prompt 走语义):
```
Soft golden morning backlight filtering through [trees / mist],
volumetric light shafts (Tyndall effect), low-angle sun at 15-30°
```

**运动句**(自然治愈):
```
The [subject] moves slowly and continuously with subtle micro-actions:
[ear twitches / tail sway / gentle breathing / paw lift],
single fluid motion, no whip pans, no shaky-cam
```

## 5. 反模式(本场景专属)

| 反模式 | 症状 | 修复 |
| --- | --- | --- |
| 恐怖谷 | 动物/宠物面部畸形 | 强 i2v 锚定,加 `anatomically correct` |
| 棚拍感 | 纯色背景空盒子 | 3+1 真实环境(见 §2 各子场景) |
| 反物理运动 | 漂移/飘浮 | 锁主体位置,加 `gravity correct` |
| 跨镜动作突变 | 动物突然瞬移/变形 | 单镜 1 动作,跨镜小步推进 |
| 颜色过艳 | 花/草/天饱和爆表 | 降饱和 -5,加 `natural color` |
