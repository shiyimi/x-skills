## §1 图层与文字版式

### 1.1 文字层定义

| 层 | 视觉大小 | 用途 | 范式 |
| --- | --- | --- | --- |
| **主标题** | 画面占比 5-15% | 核心信息(产品名/slogan/日期) | 中文手写衬线/宋体;英文大写宽字距 |
| **副标题** | 画面占比 1-3% | 辅助信息(场景/特征) | 较小,英文大写宽字距 |
| **角标** | 画面占比 0.5-1% | 日期/编号/小标识 | 最小最安静 |

> **锁 4 件套**:字体族(一个族)/ 色板(≤2 色)/ 位置(按类型)/ 描边或阴影(统一)。
>
> **媒介统一**:每组文字都要有融入画面的视觉设计,和画面同一种媒介质感(见 §3.1 约束块)。

### 1.2 R5 · 文字零错字铁律

- **品牌名/型号/成分/数字/日期** 用引号包裹: `"ESTĒE LAUDER 雅诗兰黛"`
- prompt 末尾加 `按引号内文字原样渲染` 指令
- **绝对化用语禁用**: "最/第一/国家级/销量冠军"
- 长句禁用,短标签渲染更可靠

### 1.3 拼贴/分区(zone)的边界与材质

适用于骨架B(H 路径)。每个 zone 必填 4 字段:

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| **区域占比** | 百分比或分数 | 上 38% / 下 62% |
| **区域材质** | 纹理 + 颜色 + 内容 | 牛皮纸,浅棕到中棕自然过渡 |
| **边界过渡** | 边缘处理 | 不规则手撕水平边;硬线;自然渐隐 |
| **区域编辑** | i2i 路径下说明 | "原图上半天空被移除,替换为牛皮纸" |

### 1.4 安全边距

prompt 结尾固定加: `主标题、主体和所有文字完整居中在画框内,四周留出安全边距,不贴边、不裁切`。

## §2 Prompt 七维度

### 2.1 七维度写作骨架

风格总领句必须是**自造短词组**(题材气质 + 表达手法 + 编辑属性),不能是抽象形容词。

```
[风格总领句] + [主体] + [动作/状态] + [场景/环境] + [光线/色调] + [视角/构图] + [视觉风格/画质] + [约束条件]
```

| 维度 | 规则 | 示例 |
| --- | --- | --- |
| 风格总领句 | 自造短词组:题材气质+表达手法+编辑属性;含画幅+美学基调 | 独立杂志剪贴结合做旧印刷日记感,vertical 3:4 |
| 主体 | 具体、单一主体,带材质/状态 | 一只大号南美白虾仁,表面冷凝水珠 |
| 动作/状态 | 一个静态姿势或冻结瞬间 | 从冰水中捞起的瞬间,水珠滑落 |
| 场景/环境 | §3 的 `3+1` 规则,前/中/背景三层 | 大理石台面+木铲+绿叶,背景虚化 |
| 光线/色调 | 方向 + 色温 + 对比度 + 光质 | 45°侧光,6000K,柔光高对比,青白冷调 |
| 视角/构图 | 景别 + 机位 + 构图 | 微距特写,低角度仰拍,居中 |
| 视觉风格/画质 | 摄影风格 + 保真线索 | 食物摄影,浅景深,超清细节 |
| 约束 | 防 AI 合成感/文字/负向/安全边距 | 避免纯色渐变背景;不贴边不裁切 |

### 2.2 t2i vs i2i 写法差异

**G 纯生成(t2i)**:完整七维度全填。

**E 二次编辑(i2i)**:`保持<保留项>,把<修改项>替换为<新内容>`。局部编辑:`仅修改<区域>,其余保持不变`。

**元素级绑定**:显式列元素清单,例如:
```
以上传照片作为杯子、吸管、桌面、街道和阳光的确切来源。
不要替换杯子,也不要改变真实场景。
```

**H 多图分区**:每个 zone 独立 prompt,显式标 `Zone 1` / `Zone 2`。边界与材质规范见 §1.3。

### 2.3 画幅比

| 画幅 | 用途 | 推荐 size | 高清档 |
| --- | --- | --- | --- |
| 竖 9:16 | 封面/信息流/小红书 | 720x1280 | 1440x2560 |
| 竖 3:4 | 详情页/海报/朋友圈 | 864x1152 | 1728x2304 |
| 方 1:1 | 商品图/头像/Instagram | 1024x1024 | 2048x2048 |
| 横 16:9 | 横幅/社媒头图 | 1280x720 | 2560x1440 |
| 横 4:3 | 印刷/Banner | 1152x864 | 2304x1728 |

> 实际值以 Provider 的 `capability_limits` 为准([../../providers/agnes/api.md](../../providers/agnes/api.md))。

## §3 约束块与负面约束写法

### 3.1 约束块(必加收尾)

每个 prompt 以此收尾:

```
约束(必加):
— 避免纯色渐变背景,避免棚拍空盒子感
— 色调过渡流畅不跳戏
— 所有文字按引号内文字原样渲染,零错字
— R5 铁律:品牌名/型号/成分/数字逐字核对
— 主标题、主体和所有文字完整居中在画框内,四周留安全边距
— 每组文字都有融入画面的视觉设计,和画面同一种媒介质感
— 如有实拍参考:<保留项>必须与原图一致;<修改项>替换为<新内容>
```

- 海报/拼贴类额外加 `分区边界自然过渡,不要有硬接缝`
- 商业类额外加 `品牌元素真实可信,符合产品品类常识,无虚构资质`

### 3.2 Negative Prompt 字段说明

**图像路径不独立维护 `negative_prompt`**,所有负面约束用 §3.1 约束块的 `no X, no Y, no Z` 正向写法焊死在主 prompt 末尾——内容创作([I1-flow.md §3](I1-flow.md))产出的 `负面提示词` 以 `no X` 并入此处,与 §3.1 约束块合并去重。image-brief.md 保留 `## Negative Prompt` 部分,写一行占位:

```text
## Negative Prompt
— 内容创作负面提示词(3-5 项)以 no X 并入 §3 Final Prompt 的 `★ 硬性约束` 块,不独立维护 negative_prompt。
```

## §4 Prompt 拼装顺序模板

> **直接中文,不做翻译**:Final Prompt 用**自然中文**重述规范表,不把技术数字(色温 K/光比/焦段)塞进 prompt,也不做英文语义换算——直接把"画面长什么样"写成人话(如 `暖金色晨光` `柔光侧光`)。**剧情爆点数字(金额/名称/年龄/成分/型号/品牌名)例外,必须原样写进 prompt**。

```
[风格总领句], [画幅].

★ 主体: [≥3 特征 + 材质]
★ 场景: [前/中/背景三层]
★ 光影: [方向+色温+光比+光质]
★ 色彩: [主色+辅色+色调]
★ 视角/构图: [景别+机位+构图]
★ 硬性约束: [约束块 §3.1]
```

> 完整拼装实例见 [I4-image-example.md](I4-image-example.md)。写法对照(具体 vs 抽象)与反模式见 [I2-quality.md](I2-quality.md)。
