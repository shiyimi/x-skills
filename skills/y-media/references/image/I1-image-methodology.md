## §0. 五条核心原则 (R1-R5)

R1-R5 视频版的**单帧降维版**。R2/R3/R5 直接沿用;R1/R4 重写。

| # | 原则 | 展开说明 |
| --- | --- | --- |
| **R1** | **一次定路径,坚持到底**:尽早选择路线 (t2i/i2i/多图拼贴);prompt 中途不切换 | §1.1 |
| **R2** | **视觉驱动,而非罗列要点**:1 张图 ≤ 1-3 个视觉重点(★) | §2, §3 |
| **R3** | **图层纪律**:前景/中景/背景各有可命名元素 + 1 光源;文字层锁定字体/色板/位置/描边 | §2, §3 |
| **R4** | **1 秒内首眼钩子**:首屏视觉冲击在前 1/3 画面 | §2.3 |
| **R5** | **零错字,品牌名逐字照搬**:大小写·空格·标点全部照搬 | §4.2 |

## §1. Brief 与图片文档

解析为 3 个槽位,缺位用既定默认值填(表头标 `默认假设`):

| 槽位 | 必填字段 | 缺位默认 |
| --- | --- | --- |
| 主题/产品 | subject, 1-3 个视觉重点/卖点, 素材(参考图/品牌色) | 来自 request; 真缺失就 1 轮追问 |
| 人群/受众 | 目标用户,使用场景 | 通用 9:16 信息流素材 |
| 目标 | 认知(品牌)/ 兴趣(种草)/ 转化(带货)/ 实用(教程/标识) | 按 request 判断 |

产出 `<name>.image-brief.md` sidecar,至少含 3 部分:

1. **图片主要目标**: `产品/主题 × 人群 × 目标 × 视觉骨架(§2) × 画幅 × 用途`
2. **视觉规范表**: 一行或多行,§3;表头锁定 `默认假设` / `美学母体` / `文字策略` / `生成路径`
3. **图片 prompt**: 一段完整 prompt,§5

### 1.1 路径判定(text-to-image / image-to-image / 多图分区)

| 判定问题 | 是 → 路径 | 否 → 路径 |
| --- | --- | --- |
| Q1. 有**实拍参考图**且需**保留主体/构图**? | **E 二次编辑** — i2i 或分区替换 | 进入 Q2 |
| Q2. 需**从头生成新图**? | **G 纯生成** — 完整 prompt → Provider | — |

**路径详解**:

| 路径 | 触发 | 主体保真度 | y-media 动作 |
| --- | --- | --- | --- |
| **G 纯生成** | 无参考图/从 0 设计 | 取决于 prompt 锁定 | §3 规范表 + §5 prompt → Provider |
| **E 二次编辑** | 有实拍参考图,需保留主体 | 与原图完全一致 | §5.2: `保持<保留项>,把<修改项>替换为<新内容>` |
| **H 多图分区** | 海报/拼贴(多图层多区域) | 每区域独立 | §4.3 分区边界 + §5.2 H 路径 |

**sidecar 写入**: `生成路径: G (纯生成) | E (二次编辑) | H (多图分区拼贴)`

## §2. 视觉骨架 (Composition Skeleton)

### 2.1 速选决策树

| 信号 | 骨架 | 元素数 | 文字层 | 用途 |
| --- | --- | --- | --- | --- |
| "产品图"/"白底图"/"商品图" | **A 主体居中** | 1 主体 + 3+1 道具 | 无或 ≤1 | 电商/产品详情/广告 |
| "海报"/"封面"/"推广" | **B 分区拼贴** | 1-2 主体 + 多区域 | 1-3 层 | 品牌/活动/社媒 |
| "人像"/"穿搭"/"lookbook" | **C 人物构图** | 1 人物 + 场景 | 无或 ≤1 | 时尚/形象/社交 |
| "概念图"/"插画"/"氛围" | **D 场景叙事** | 1-2 主体 + 场景 | 无 | 故事/治愈/概念 |
| "标识"/"icon"/"logo" | **E 极简符号** | 1 主体 | 1 层(品牌名) | 品牌/UI/水印 |

### 2.2 视觉重点 ★ 密度

| 骨架 | ★ 数 | 分布 | 自检 |
| --- | --- | --- | --- |
| A 主体居中 | 1 ★(主体) | 中心 50% | 一眼看清? |
| B 分区拼贴 | 1-2 ★(主标题区 + 主体区) | 上下或左右各 1 | 扫一眼抓重点? |
| C 人物构图 | 1 ★(人物) | 1/3 构图点 | 有故事感? |
| D 场景叙事 | 1-2 ★(主体 + 氛围锚) | 1 主体 + 1 锚点 | 一秒入戏? |
| E 极简符号 | 1 ★(符号本体) | 中心 | 高识别度? |

### 2.3 R4 · 首眼钩子

| 钩子类型 | 范式 | 适合 |
| --- | --- | --- |
| **对比钩** | 强对比(冷暖/明暗/大小)在前 1/3 画面 | A 产品图 / B 海报 |
| **构图钩** | 1/3 构图点 + 引导线 | C 人物 / D 场景 |
| **色彩钩** | 主色占画面 60%+,极端色环位置 | B 海报 / E 符号 |

> **自检**:缩到 200x200,眯眼扫 1s,能立刻看到主体?

## §3. 视觉规范表 (Visual Spec Table)

### 3.0 单行模板

| 字段 | 规则 | 示例(产品图) |
| --- | --- | --- |
| 区域 ID | `Z01`(分区时用 Z01/Z02/...) | Z01 |
| 用途 | 该区域功能 | 产品主体 |
| 主体 | ≥3 特征 + 材质/状态 | 哑光黑色蓝牙耳机,充电盒,金属铰链 |
| 景别与视角 | 景别 + 机位 + 构图 | 中近景,平视,中心构图 |
| 光影 | 方向 + 色温 + 光比 + 光质 | 顶光 45°,5000K,光比 2:1,柔光 |
| 色彩 | 主色 + 辅色 + 色调 | 哑光黑+冷灰,中低饱和冷调 |
| 前景/中景/背景 | 3+1 规则(可命名道具 + 光源) | 前景:耳机/中景:充电盒/背景:米白窗帘虚化 |
| 文字层 | §4.1(无文字则 —) | 主标题"BlackBeats X1"中下,黑字白边 |
| 视觉重点 | ★ = 封面级 | ★ |
| 视觉重点 2 | 二级 ★(可选) | — |
| 风格 | 摄影类型 + 美学基调 + 负向 | 产品摄影,Apple 极简 |

### 3.1 颗粒度标尺

| 字段 | 抽象(reject) | 具体(accept) |
| --- | --- | --- |
| 光影·色温 | "暖光" | `4500K` |
| 光影·光比 | "柔和" | `2:1` |
| 光影·光质 | "好看的光" | `柔光`/`硬光` |
| 色彩·饱和 | "鲜艳" | `饱和度+10` |
| 焦段 | "广角" | `16mm 广角` |
| 主体 | "一个耳机" | `哑光黑色蓝牙耳机,充电盒,金属铰链`(≥3 特征) |
| 约束 | "要有高级感" | `24fps,快门 180°,禁止文字`(可执行) |

### 3.2 场景路由

| 主体类型 | 默认配置 | 关键点 |
| --- | --- | --- |
| 产品(无实拍) | 骨架A + 中近景 + 顶光 5000K + 浅色背景 | 强 i2v 推荐(若有产品实拍) |
| 产品(有实拍) | 路径E + 仅修改背景/光影 | 列明保留项(主体/材质/品牌) |
| 海报/拼贴 | 骨架B + 分区 + 多字体 + 角标 | §4.3 多区结构 + §5.2 H 路径 |
| 人像/穿搭 | 骨架C + 1/3 构图 + 自然光 | **强 i2v**(若有人物实拍) |
| 美食/ASMR | 骨架A + 微距 + 顶光 4500K | 路径 G |
| 风景/氛围 | 骨架D + 广角 + 黄金时刻光 | 加 1-2 动态元素避免空盒子感 |
| 标识/logo | 骨架E + 极简 + 主色 60%+ | 锁品牌色,逐字渲染 |
| **商业带货** | [../recipes/commerce.md §5](../recipes/commerce.md) 品类配置 + R5 + 合规清单 | **i2i 优先**(实拍) |

## §4. 图层与文字版式

### 4.1 文字层定义

| 层 | 视觉大小 | 用途 | 范式 |
| --- | --- | --- | --- |
| **主标题** | 画面占比 5-15% | 核心信息(产品名/slogan/日期) | 中文手写衬线/宋体;英文大写宽字距 |
| **副标题** | 画面占比 1-3% | 辅助信息(场景/特征) | 较小,英文大写宽字距 |
| **角标** | 画面占比 0.5-1% | 日期/编号/小标识 | 最小最安静 |

> **锁 4 件套**:字体族(一个族)/ 色板(≤2 色)/ 位置(按类型)/ 描边或阴影(统一)。

### 4.2 R5 · 文字零错字铁律

- **品牌名/型号/成分/数字/日期** 用引号包裹: `"ESTĒE LAUDER 雅诗兰黛"`
- prompt 末尾加 `按引号内文字原样渲染` 指令
- **绝对化用语禁用**: "最/第一/国家级/销量冠军"
- 长句禁用,短标签渲染更可靠

### 4.3 拼贴/分区(zone)的边界与材质

适用于骨架B 和路径H。每个 zone 必填 4 字段:

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| **区域占比** | 百分比或分数 | 上 38% / 下 62% |
| **区域材质** | 纹理 + 颜色 + 内容 | 牛皮纸,浅棕到中棕自然过渡 |
| **边界过渡** | 边缘处理 | 不规则手撕水平边;硬线;自然渐隐 |
| **区域编辑** | i2i 路径下说明 | "原图上半天空被移除,替换为牛皮纸" |

### 4.4 安全边距

prompt 结尾固定加: `主标题、主体和所有文字完整居中在画框内,四周留出安全边距,不贴边、不裁切`。

### 4.5 约束块

每个 prompt 以此收尾:

```
约束(必加):
— 避免纯色渐变背景,避免棚拍空盒子感
— 色调过渡流畅不跳戏
— 所有文字按引号内文字原样渲染,零错字
— R5 铁律:品牌名/型号/成分/数字逐字核对
— 主标题、主体和所有文字完整居中在画框内,四周留安全边距
— 每组文字都有融入画面的视觉设计,和画面同一种媒介质感
— 如有实拍参考:<保留项>必须与原图一致;<修改项>替换为<新内容>
```

- 海报/拼贴类额外加 `分区边界自然过渡,不要有硬接缝`
- 商业类额外加 `品牌元素真实可信,符合产品品类常识,无虚构资质`

## §5. 图片 Prompt

### 5.1 七维度写作骨架

风格总领句必须是**自造短词组**(题材气质 + 表达手法 + 编辑属性),不能是抽象形容词。

```
[风格总领句] + [主体] + [动作/状态] + [场景/环境] + [光线/色调] + [视角/构图] + [视觉风格/画质] + [约束条件]
```

| 维度 | 规则 | 示例 |
| --- | --- | --- |
| 风格总领句 | 自造短词组:题材气质+表达手法+编辑属性;含画幅+美学基调 | 独立杂志剪贴结合做旧印刷日记感,vertical 3:4 |
| 主体 | 具体、单一主体,带材质/状态 | 一只大号南美白虾仁,表面冷凝水珠 |
| 动作/状态 | 一个静态姿势或冻结瞬间 | 从冰水中捞起的瞬间,水珠滑落 |
| 场景/环境 | §3 的 `3+1` 规则,前/中/背景三层 | 大理石台面+木铲+绿叶,背景虚化 |
| 光线/色调 | 方向 + 色温 + 对比度 + 光质 | 45°侧光,6000K,柔光高对比,青白冷调 |
| 视角/构图 | 景别 + 机位 + 构图 | 微距特写,低角度仰拍,居中 |
| 视觉风格/画质 | 摄影风格 + 保真线索 | 食物摄影,浅景深,超清细节 |
| 约束 | 防 AI 合成感/文字/负向/安全边距 | 避免纯色渐变背景;不贴边不裁切 |

### 5.2 t2i vs i2i 写法差异

**G 纯生成(t2i)**:完整七维度全填。

**E 二次编辑(i2i)**:`保持<保留项>,把<修改项>替换为<新内容>`。局部编辑:`仅修改<区域>,其余保持不变`。

**元素级绑定**:显式列元素清单,例如:
```
Use the uploaded photo as the exact source for the cup, straw, table, street, and sunlight.
Do not replace the cup or change the real-life scene.
```

**H 多图分区**:每个 zone 独立 prompt,显式标 `Zone 1` / `Zone 2`。边界与材质规范见 §4.3。

### 5.3 画幅比

| 画幅 | 用途 | 推荐 size |
| --- | --- | --- |
| 竖 9:16 | 封面/信息流/小红书 | 720x1280 |
| 竖 3:4 | 详情页/海报/朋友圈 | 864x1152 |
| 方 1:1 | 商品图/头像/Instagram | 1024x1024 |
| 横 16:9 | 横幅/社媒头图 | 1280x720 |
| 横 4:3 | 印刷/Banner | 1152x864 |

### 5.4 Prompt 拼装示例

完整示例见 [I2-image-example.md](I2-image-example.md)。核心结构:

```text
[风格总领句], [画幅].

★ Main subject: [≥3 特征 + 材质]
★ Scene: [前/中/背景三层]
★ Lighting: [方向+色温+光比+光质]
★ Color: [主色+辅色+色调]
★ Camera / composition: [景别+机位+构图]
★ Hard constraints: [约束块]
```

## §6. 图片反模式

| 反模式 | 症状 | 修复 |
| --- | --- | --- |
| 抽象堆砌 | "高级感"无参数 | 给具体数字/术语 |
| 多主体混淆 | 1 图 >1 主体 | 锁 1 主体,1 动作 |
| 文字错字 | 品牌/数字写错 | R5 铁律,引号 + verbatim |
| 文字层缺位置/字体 | 字在哪/字体未明 | §4.1 锁 4 件套 |
| 空盒子背景 | 主体居中,四周纯白 | 加 3+1 道具/纹理 |
| 过度 AI 合成感 | 颜色过艳/边缘发虚 | 加 `no AI artifacts` |
| 拼贴无边界过渡 | 区域硬接 | 说明手撕/硬线/渐变 |
| i2i 漂移 | 参考图主体被重画 | 列元素级绑定清单 |
| 比例异常 | 构图与画幅不匹配 | 说明"主体居左,右侧留白" |
| 商业类缺 R5 | 品牌错字/数字错 | R5 + [../recipes/commerce.md §5.13](../recipes/commerce.md) |
| 系列图漂移 | 3 张图主体不像同一物 | §9 锁主体描述符 + 美学母体 |

## §7. 自检 4 问

1. **生成路径写了吗?** `生成路径: G | E | H`(§1.1)
2. **视觉规范表 11 列都填了?** 分区图多行(§3.0)
3. **R5 铁律查了?** 品牌名/型号/成分/数字引号 + verbatim(§4.2)
4. **首屏 1 秒钩子有吗?** 缩到 200x200,眯眼扫 1s 能看到主体?(§2.3)

## §9. 系列图一致性

| 字段 | 锁 | 变 |
| --- | --- | --- |
| 主体描述符 | ≥3 特征(品牌/颜色/材质) | — |
| 美学母体 | 主色 + 辅色 + 灯光风格 | — |
| 焦段/景别 | — | 1 远 / 1 中 / 1 近 |
| 场景/道具 | — | 每次换 1-2 个 |
| 文字层 | 字体/色板/位置/描边 | 文字内容可改 |
| 视觉重点 ★ | 每张图 ≥1 ★ | ★ 位置可改 |

> **变体法则**:每张图只换 ≤3 个变量;一次换太多 = 主体漂移。

## §10. 图片作为视频输入

- **首帧引导**: `以 <图片1> 作为起始画面`
- **风格参考**: `参考 <图片1> 的色调与光影`
- **主体一致**: `以 <图片1> 为主体,保持产品外观/logo/配色一致`

> **i2v 自检**:① 主体完整?② 构图与 video 运镜匹配?③ 主体与背景对比度足够?

## §11. Negative Prompt 字段说明

**图像路径不独立维护 `negative_prompt`**,所有负面约束用 §4.5 约束块的 `no X, no Y, no Z` 正向写法焊死在主 prompt 末尾。image-brief.md 保留 `## Negative Prompt` 部分,写一行占位:

```text
## Negative Prompt
— (图像路径不独立维护 negative_prompt,所有负面约束在 §3 Final Prompt 的 Hard Constraints 块内。)
```
