# I2. quality · 图片质量(颗粒度 · 反模式 · 系列一致性)

> 怎么写得具体(颗粒度标尺)、怎么不翻车(反模式)、怎么保持系列一致(一致性锁)。流程入口在 [I1-flow.md](I1-flow.md),模板在 [I3-prompt.md](I3-prompt.md)。

---

## §1 颗粒度标尺(抽象 vs 具体)

| 字段 | 抽象(reject) | 具体(accept) |
| --- | --- | --- |
| 光影·色温 | "暖光" | `4500K` |
| 光影·光比 | "柔和" | `2:1` |
| 光影·光质 | "好看的光" | `柔光`/`硬光` |
| 色彩·饱和 | "鲜艳" | `饱和度+10` |
| 焦段 | "广角" | `16mm 广角` |
| 主体 | "一个耳机" | `哑光黑色蓝牙耳机,充电盒,金属铰链`(≥3 特征) |
| 约束 | "要有高级感" | `24fps,快门 180°,禁止文字`(可执行) |

## §2 图片反模式

| 反模式 | 症状 | 修复 |
| --- | --- | --- |
| 抽象堆砌 | "高级感"无参数 | §1 给具体数字/术语 |
| 多主体混淆 | 1 图 >1 主体 | 锁 1 主体,1 动作 |
| 文字错字 | 品牌/数字写错 | R5 铁律,引号 + verbatim([I3-prompt.md §1.2](I3-prompt.md)) |
| 文字层缺位置/字体 | 字在哪/字体未明 | [I3-prompt.md §1.1](I3-prompt.md) 锁 4 件套 |
| 空盒子背景 | 主体居中,四周纯白 | 加 3+1 道具/纹理 |
| 过度 AI 合成感 | 颜色过艳/边缘发虚 | 加 `no AI artifacts` |
| 拼贴无边界过渡 | 区域硬接 | 说明手撕/硬线/渐变 |
| i2i 漂移 | 参考图主体被重画 | 列元素级绑定清单([I3-prompt.md §2.2](I3-prompt.md)) |
| 比例异常 | 构图与画幅不匹配 | 说明"主体居左,右侧留白" |
| 商业类缺 R5 | 品牌错字/数字错 | R5 + [../recipes/commerce.md §5](../recipes/commerce.md) |
| 系列图漂移 | 3 张图主体不像同一物 | §3 锁主体描述符 + 美学母体 |

---

## §3 系列图一致性

| 字段 | 锁 | 变 |
| --- | --- | --- |
| 主体描述符 | ≥3 特征(品牌/颜色/材质) | — |
| 美学母体 | 主色 + 辅色 + 灯光风格 | — |
| 焦段/景别 | — | 1 远 / 1 中 / 1 近 |
| 场景/道具 | — | 每次换 1-2 个 |
| 文字层 | 字体/色板/位置/描边 | 文字内容可改 |
| 视觉重点 ★ | 每张图 ≥1 ★ | ★ 位置可改 |

> **变体法则**:每张图只换 ≤3 个变量;一次换太多 = 主体漂移。
