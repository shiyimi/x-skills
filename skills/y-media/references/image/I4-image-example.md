# I4. image-example · 图片 Brief 示例

> 本文件是 [I1-flow.md](I1-flow.md) 的完整示例。每条示例都按"image-brief.md"结构填写:1. 图片主要目标 / 2. 提示词(创作内容) / 3. 视觉规范表 / 4. 图片 prompt。
>
> 写新 image-brief 前必读,作为颗粒度校准锚。
>
> **Negative Prompt 字段**: 图像路径不独立维护 `negative_prompt`,所有负面约束以正向写法 `no X, no Y, no Z` 焊死在 §4 Final Prompt 的 `★ 硬性约束` 块内。详见 [I3-prompt.md §3.2](I3-prompt.md) 与 [providers/agnes/api.md](../../providers/agnes/api.md)。

## 示例 1 · 蓝牙耳机产品图(纯生成,G 路径)

**用途**:电商详情页主图;白底+产品;**转化为主**

### 1. 图片主要目标

```
品牌 BlackBeats × 25-35 岁男性通勤族 × 转化(转化) × 骨架A(主体居中) × 画幅 1:1(方图) × 用途:电商详情页主图
```

**默认假设**:
- 无真人出镜(产品图),无实拍参考图 → G 纯生成
- 主体颜色:哑光黑(品牌色)
- 文字策略:无文字(详情页主图,文字在详情页内单独设计)

**美学母体**:
```
主色 哑光黑(#1A1A1A) + 辅色 冷灰金属 + 暖金高光反射 + 浅米背景
灯光 顶光 + 后侧补光,5000K,光比 3:1,半硬光
质感 Apple 极简产品摄影,无过度装饰
```

**生成路径**: G(纯生成,默认推荐)

### 2. 提示词(创作内容)

- **主体**: 哑光黑色蓝牙耳机(金属铰链,USB-C 充电口),充电盒顶部居中品牌 logo `BlackBeats`(逐字)。
- **场景**: 浅米窗帘虚化背景 + 侧窗光,前景耳机、中景充电盒+备用耳塞。
- **视觉重点**: 产品主体(哑光黑质感 + 暖金高光)。
- **基调**: Apple 极简产品摄影,中低饱和冷调。
- **负面提示词**(最终并入 §4 prompt 的 `★ 硬性约束`): 无人 / 无反射遮挡产品 / 无额外配件·无品牌贴纸·无价签 / 无水印·无背景文字。

### 3. 视觉规范表

| 字段 | 内容 |
| --- | --- |
| 区域 ID | Z01 |
| 用途 | 产品主体(详情页主图) |
| 主体 | 哑光黑色蓝牙耳机,金属铰链,USB-C 充电口,品牌 logo `BlackBeats` 在充电盒顶部居中(逐字) |
| 景别与视角 | 中近景,平视,中心构图,产品占画面 60% |
| 光影 | 顶光 45° + 后侧补光,5000K,光比 3:1,半硬光 |
| 色彩 | 哑光黑+冷灰金属+暖金高光,中低饱和冷调 |
| 前景/中景/背景 | 前景:耳机主体/中景:充电盒+1 颗备用耳塞/背景:浅米窗帘虚化+侧窗光 |
| 文字层 | —(无文字) |
| 视觉重点 | ★ |
| 视觉重点 2 | — |
| 风格 | 产品摄影,Apple 极简,无金属反光,无额外配件,无人 |

### 4. 图片 prompt(七维度 + 约束块 · 直接中文)

```text
产品摄影,方图 1:1,极简科技美学。

★ 主体:
一对哑光黑色蓝牙耳机,磁吸充电盒,USB-C 充电口,充电盒顶部居中刻有品牌名 "BlackBeats" 。两只耳机都放在盒内,盒盖打开 90 度。

★ 场景:
前景:一对哑光黑色备用耳塞
中景:打开着的充电盒,耳机就位
背景:浅米色薄纱窗帘虚化,带柔和侧窗光

★ 动作/状态:
冻结瞬间——盒子静止,盒盖打开,无运动,无人。

★ 光影:
单一主光从顶部 45° 打下,5000K,后侧窗光柔光补光,光比 3:1,半硬光,金属铰链上有细微暖色高光。

★ 色彩:
哑光黑(#1A1A1A) + 冷灰金属 + 金属边缘暖金高光,整体低饱和冷调。

★ 视角/构图:
平视,产品居中,占画面 60%,1:1 方图,浅景深。

★ 风格锚(1 个标签):
产品摄影,Apple 极简,高端消费电子,无人,无杂乱。

★ 画质(后置强化):
4K 超清,产品细节锐利,哑光表面微纹理可见,不过度锐化。

★ 硬性约束(焊死 · 必加):
— 充电盒顶部的 "BlackBeats" 品牌 logo 必须按引号内文字原样渲染。
— 哑光表面无遮挡产品的反射。
— 无人,无额外配件,无品牌贴纸,无价签,无水印,无背景文字。
— 构图干净极简,单一主体聚焦。
```

**逐项对照 [I1-flow.md §5.0](I1-flow.md) 视觉规范表**:

| 规范表字段 | 本 prompt 写法 | 转换/保留 |
| --- | --- | --- |
| 主体 | 哑光黑色蓝牙耳机,金属铰链,USB-C 充电口 | ≥3 特征 + 材质保留 |
| 景别与视角 | 中近景,平视,中心构图 | 完整保留 |
| 光影·色温 | `5000K` | K 值保留(image 不必转换) |
| 光影·光比 | `3:1` | 数字保留 |
| 色彩 | `#1A1A1A` 哑光黑 | 16 进制 + 命名 |
| 文字 | `"BlackBeats"`(引号) | R5 铁律逐字 |

## 示例 2 · 咖啡海报拼贴(多图分区,H 路径)

**用途**:社媒活动封面/品牌海报;**品牌+种草**

### 1. 图片主要目标

```
品牌 一杯咖啡的午后 × 25-35 文艺女性 × 兴趣(种草) × 骨架B(分区拼贴) × 画幅 3:4(竖版海报) × 用途:小红书/微博 活动封面
```

**默认假设**:
- 用户提供了实拍咖啡杯照片作为参考图 → H 路径(分区拼贴 + 元素级绑定)
- 主体颜色:暖棕(牛皮纸)+ 透明塑料杯 + 阳光
- 文字策略:含文字(主标题"一杯咖啡的午后" + 副标题英文 + 角标日期)

**美学母体**:
```
主色 暖棕牛皮纸 + 透明咖啡杯 + 阳光街道
材质 牛皮纸(可见纤维纹理) + 木桌 + 透明塑料
灯光 暖午阳光 45°侧光,4000K,光比 2:1,柔光
质感 独立杂志剪贴结合做旧印刷日记感(风格总领句,[I3-prompt.md §2.1](I3-prompt.md))
```

**生成路径**: H(多图分区拼贴)

### 2. 提示词(创作内容)

- **主体**: 一杯透明塑料冰咖啡(实拍参考图元素级绑定,吸管/冰块/木桌/街道/阳光) + 品牌主标题 `"一杯咖啡的午后"`。
- **场景**: 上 38% 暖棕牛皮纸(手撕纤维边) + 下 62% 街头咖啡实拍照片(木桌 + 窗外阳光街道)。
- **视觉重点**: 主标题(手写衬线/宋体黑墨水) + 咖啡杯(手撕拼贴质感)。
- **基调**: 独立杂志剪贴结合做旧印刷日记感,低饱和暖调。
- **负面提示词**(最终并入 §4 prompt 的 `★ 硬性约束`): 无人 / 无文字被裁切·无叠字 / 无过度修图·无荧光过饱和 / 无水印·无 logo 乱入。

### 3. 视觉规范表(多区)

**Z01 · 牛皮纸区(上 38%)**

| 字段 | 内容 |
| --- | --- |
| 区域 ID | Z01 |
| 区域占比 | 上 38% |
| 区域材质 | 暖棕牛皮纸,可见天然纤维纹理,轻微褶皱,浅棕到中棕自然色变 |
| 边界过渡 | 不规则手撕水平边,粗糙纤维向下 |
| 主体 | 中文主标题 `"一杯咖啡的午后"`(手写衬线/宋体,黑墨水) |
| 文字层 | 主标题 + 副标题 `AFTERNOON · COFFEE · GREEN`(小字宽字距) + 角标 `"2026.08"`(右上角) |

**Z02 · 咖啡照片区(下 62%)**

| 字段 | 内容 |
| --- | --- |
| 区域 ID | Z02 |
| 区域占比 | 下 62% |
| 区域材质 | 真实街景照片,透明塑料冰咖啡杯+木桌+阳光街道+斑马线 |
| 边界过渡 | 上边界与牛皮纸手撕边自然融合(无硬接缝) |
| 主体 | 透明塑料杯(满冰咖啡)+ 透明吸管 + 木桌 + 阳光街道(虚化背景) |
| 文字层 | — |
| 视觉重点 | ★(透明杯+冰咖啡+阳光) |

**点缀(Accent)**:
```
1.5cm 见方 实心焦糖棕方块,放在主标题旁略偏移,作为拼贴装饰
```

**视觉规范·共同列**:

| 字段 | 内容 |
| --- | --- |
| 景别与视角 | 静帧,平视,主体居中偏下,四周出血延伸至所有边缘 |
| 光影 | 暖午阳光 45°侧光,4000K,光比 2:1,柔光 |
| 色彩 | 暖棕 + 透明 + 阳光街道,低饱和暖调 |
| 风格 | 生活拼贴海报,独立 zine,微信朋友圈 × 独立咖啡杂志 |

### 4. 图片 prompt(七维度 + 约束块 + 分区写法 · 直接中文)

```text
生活拼贴海报,竖版 3:4,暖调独立 zine 美学。

★ 构图(分区拼贴 · 38% + 62%):
海报分成两个区域。
- Z01(上 38%):暖棕色牛皮纸层,可见天然纤维纹理,轻微褶皱,颜色从浅棕到中棕自然过渡。牛皮纸底部是不规则手撕水平边,下层粗糙纤维向下延伸,与下方照片自然衔接。
- Z02(下 62%):真实街边咖啡照片——透明的塑料冰咖啡杯带透明吸管,放在窗边的木桌上。窗外:阳光街道带斑马线,温暖午后阳光投下柔和阴影。咖啡杯位于画面下方视觉中心。照片四周出血延伸到所有边缘。原图上半部分天空和杂乱背景被移除,替换为牛皮纸。

★ 主体:
透明的塑料冰咖啡杯带透明吸管,放在阳光照到的窗边木桌上。杯内装满浅棕色冰咖啡和几颗冰块,杯壁有细微冷凝水珠。

★ 场景:
前景:手撕牛皮纸边缘,粗糙纤维
中景:位于下方视觉中心的咖啡杯
背景:虚化的阳光街道带斑马线,温暖午后阳光

★ 动作/状态:
冻结瞬间——杯子静止,无液体晃动,无外溅,无人移动。

★ 光影:
单一自然光源——从窗户洒入的温暖午后阳光,45° 侧光,4000K,柔光补光,光比 2:1,柔光。

★ 色彩:
暖棕牛皮纸 + 透明杯 + 阳光街道,低饱和暖调独立 zine 配色。

★ 视角/构图:
静态视角,平视,主体放置于下方视觉中心,照片四周出血延伸至所有边缘,牛皮纸有轻微倾斜角度。

★ 文字版式(主/副/角标三层 · 媒介统一 [I3-prompt.md §1.1](I3-prompt.md)):
- 主标题:在牛皮纸区居中偏下,大号中文标题 "一杯咖啡的午后",用**手写毛笔书法风,可见笔触与轻微墨迹晕染**,与做旧纸质感匹配——优雅、略带书法感,仿佛用传统毛笔直接画在牛皮纸上。
- 副标题:中文标题下方,小号大写英文宽字距:"AFTERNOON · COFFEE · GREEN",老式打字机字体,带轻微油墨瑕疵。
- 角标:牛皮纸区右上角,小号黑色文字 "2026.08",极简无衬线。
- **文字融合(媒介统一 [I3-prompt.md §1.1](I3-prompt.md))**:标题与副标题视觉上融入纸面纹理——墨迹轻微渗入纸纤维,文字与媒介自然结合。

★ 点缀(点缀元素):
主标题旁放一小块实心焦糖棕方块(约 1.5cm 视觉大小),作为拼贴装饰元素,相对文字轻微偏移。

★ 风格方向(自造词组 [I3-prompt.md §2.1](I3-prompt.md)):
独立杂志剪贴结合做旧印刷日记感,竖版 3:4,温暖午后阳光 zine 美学。

★ 画质(后置强化):
4K 超清,扫描纸面颗粒纹理,轻微做旧,牛皮纸上有细微折痕。

★ 参考绑定(元素级绑定 · H 路径必填):
以上传照片作为下方部分的咖啡杯、吸管、木桌、街景、斑马线和阳光的确切来源。不要替换杯子,也不要改变真实场景。

★ 硬性约束(焊死 · 必加):
— 所有中英文文字必须按引号内文字原样渲染,零错字:"一杯咖啡的午后" / "AFTERNOON · COFFEE · GREEN" / "2026.08"。
— 牛皮纸与照片之间的手撕边必须自然有纤维感,无生硬切缝。
— 无额外咖啡杯,无人,无额外的桌子,无商业按钮,无霓虹,无渐变,无 3D,无 AI 合成感。
— 平面、拼贴、安静、温暖、日记式、独立编辑美学。
```

**逐项对照 [I1-flow.md §5.0](I1-flow.md) + [I3-prompt.md §1](I3-prompt.md) 视觉规范表**:

| 规范表字段 | 本 prompt 写法 | 转换/保留 |
| --- | --- | --- |
| 区域 ID | Z01(38%) / Z02(62%) | 显式分区 |
| 区域材质 | 牛皮纸 + 透明塑料杯 | 完整保留 |
| 边界过渡 | 不规则手撕水平边,粗糙纤维 | 显式说明 |
| 文字 | `"一杯咖啡的午后"` / `"AFTERNOON · COFFEE · GREEN"` / `"2026.08"` | 引号 + verbatim |
| Accent | 1.5cm 见方实心焦糖棕 | 4 字段全 |
| 参考绑定 | `REFERENCE:` 段 | 元素级绑定清单 |

## 反例对照(自检前看 1 分钟)

| ❌ 反例 | ✓ 修复 |
| --- | --- |
| 抽象主体:"一个耳机" | ≥3 特征:"哑光黑色蓝牙耳机,金属铰链,USB-C 充电口" |
| 抽象光影:"柔和光" | 具体光影:"顶光 45°,5000K,光比 3:1,半硬光" |
| 数字乱跳:"¥199"(未核对) | 逐字核对 + 引号:"`199`" 或 "RMB 199" |
