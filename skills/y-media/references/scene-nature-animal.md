# 场景参考 · 自然 / 动物 / 治愈系

> 本文件是 y-media "去商业化"后补回的**场景化领域知识**,对应自然风景、野生动物、宠物、治愈系生活流等非电商场景。写分镜前根据主体类型打开对应场景模板,取光影/音频/骨架/7秒高潮的现成参数,再填进分镜表。其他场景模板(生活质感/人像穿搭/美食ASMR)可按本文件结构补充。

---

## 1. 场景定性

| 维度 | 内容 |
| --- | --- |
| 板块共性 | 情绪治愈 + 真实自然 + 无对白或极简OS + 慢节奏 |
| 首选骨架 | 骨架B(情感叙事·线性起承转合,5-8镜,单镜2.0-5.0s) |
| 视听路线 | 无字幕(画面+BGM+环境音承担信息) |
| 叙事禁区 | 避免拟人化过度台词;避免棚拍感;避免过饱和AI味 |
| 美学母体 | 自然色(嫩绿/暖金/天蓝/大地色),色温4500-5200K,浅景深 |

## 2. 子场景卡片

### 2.1 野生动物 / 自然纪录片

- **品类定性**: 真实自然 + 动物行为 + 治愈
- **首选骨架**: 骨架B,6镜,单镜2.0-3.5s
- **光影模板**: 黄金时刻光(3200-4000K,15-30°低角) / 清晨侧逆光(4500K,柔光,光比3:1) / 阴天漫射(6000K,光比1.5:1,柔光)
- **音频皮肤**: 清新民谣(木吉他+钟琴,90-110BPM) / 氛围pad(60-80BPM) / 纯环境音无BGM
- **7秒高潮点**: 动物突然动作爆点(冲刺/跃起/甩头)或逆光剪影定格
- **AI生成禁区**: 恐怖谷/畸形解剖/反物理运动/棚拍背景
- **环境模板(3+1)**: 草甸(草尖+野花+晨雾+侧逆光) / 森林(树干+苔藓+光斑+顶光) / 水边(卵石+水波+芦苇+侧光)

### 2.2 宠物治愈 Vlog

- **品类定性**: 情绪陪伴 + 日常感 + 治愈
- **首选骨架**: 骨架B慢切,5-7镜,单镜2.5-4.0s
- **光影模板**: 室内窗光(侧窗光4500K,柔光,光比2:1) / 暖顶灯(3000K,暖,光比1.5:1) / 阳台自然光(5000K)
- **音频皮肤**: 暖民谣(木吉他+口琴,65-90BPM) / 钢琴独奏(60-80BPM)
- **7秒高潮点**: 宠物表情特写(歪头/打哈欠/摇尾)或互动瞬间(蹭手/翻肚)
- **AI生成禁区**: 拟人化台词/恐怖谷/棚拍纯色背景
- **环境模板(3+1)**: 客厅(沙发+抱枕+地毯+窗光) / 卧室(床+窗帘+台灯+暖光) / 草坪(草地+玩具+树影+日光)

### 2.3 自然风景 / 风光

- **品类定性**: 沉浸 + 氛围 + 治愈
- **首选骨架**: 骨架B慢切,4-6镜,单镜3.0-5.0s(可更长)
- **光影模板**: 蓝调时刻(8000-10000K,漫射) / 黄金时刻(3200-4000K,低角) / 雾天漫射(6500K,柔光)
- **音频皮肤**: 氛围pad(60-80BPM) / 纯环境音(风声/水声/鸟鸣,无BGM)
- **7秒高潮点**: 光线变化爆点(日出破云/云海流动/光束穿透)或大远景揭示
- **AI生成禁区**: 过饱和/棚拍感/无前景层次
- **环境模板(3+1)**: 山景(山脊+云海+松林+黄金光) / 水景(湖面+倒影+芦苇+侧光) / 森林(树干+苔藓+光斑+顶光)

### 2.4 治愈生活流

- **品类定性**: 日常美学 + 慢生活 + 治愈
- **首选骨架**: 骨架B慢切,5-7镜,单镜2.5-4.0s
- **光影模板**: 窗光(侧窗4500K,柔光) / 暖灯(3000K,暖) / 黄昏光(3500K,低角)
- **音频皮肤**: 暖民谣(65-90BPM) / 钢琴独奏(60-80BPM) / 环境音为主BGM极淡
- **7秒高潮点**: 日常动作特写(倒咖啡/翻书/插花)的光影爆点
- **AI生成禁区**: 棚拍空盒子/无生活痕迹/过饱和
- **环境模板(3+1)**: 厨房(灶台+木台+绿植+窗光) / 书桌(书本+台灯+咖啡杯+暖光) / 阳台(绿植+藤椅+纱帘+侧光)

## 5. 7秒高潮点范式

骨架B的7秒高潮是情绪反转/视觉爆点,不是卖点罗列。

| 子场景 | 7秒高潮类型 | 范式 |
| --- | --- | --- |
| 野生动物 | 动作爆点 | 突然冲刺/跃起/甩头,配鼓点轻进+欢快嘶鸣 |
| 宠物 | 表情爆点 | 歪头/打哈欠/摇尾特写,配BGM副歌 |
| 风光 | 光线爆点 | 日出破云/光束穿透/云海流动,配BGM推满 |
| 生活流 | 动作光影爆点 | 倒咖啡蒸汽升腾/翻书光斑移动,配音效点 |

## 6. 骨架B起承转合(自然治愈版)

| 拍 | 时长占比 | 镜数 | 职责 | 光影 | 音频 |
| --- | --- | --- | --- | --- | --- |
| 起 | ~25% | 1-2 | 环境/主体入画,缓推建立 | 侧逆光/低色温晨光 | BGM冷启渐入+环境音 |
| 承 | ~30% | 2-3 | 主体动作展开,节奏渐快 | 色温爬升+光比增大 | BGM成型+环境音丰富 |
| 转 | ~25% | 1-2 | 7秒高潮爆点(动作/光线/表情) | 强逆光/顶光,情绪顶 | BGM推满+音效点 |
| 合 | ~20% | 1 | 渐远/收束,留白余韵 | 黄金光/蓝调,降饱和 | BGM淡出+环境音收尾 |

## 8. 反模式(本场景常见翻车点)

| 反模式 | 症状 | 修复 |
| --- | --- | --- |
| 拟人化台词 | 动物开口说话 | 无对白路线,只留嘶鸣/叫声 |
| 棚拍纯色背景 | 塑料感空背景 | 3+1真实环境+前景虚焦层 |
| 过饱和AI味 | 颜色荧光感 | 降饱和-5至-10,锁自然色板 |
| 恐怖谷动物 | 畸形/多肢/眼神诡异 | `动物解剖与运动物理正确,禁止畸形` |
| 全清晰无层次 | 画面扁平 | 浅景深+前景虚焦+焦段切换 |
| 情绪平淡 | 无高潮完播率低 | 7秒内置爆点+情绪曲线递进 |
| 光影闪烁 | 跨镜跳色温 | 锁色温区间±300K,美学母体统一 |
