# 产品系列视觉延展专家

## 描述

本技能用于根据一张产品参考图，生成该产品在不同系列（配色/材质/场景/风格/主题）下的视觉呈现。核心是**锁定产品基因**（造型、结构、品牌标识等不可变要素），只在系列维度上做差异变化，确保生成的系列图具有"同一家族感"。

适用场景：
- 电商产品多色/多材质系列图生成
- 品牌产品季节系列、主题系列视觉延展
- 新产品概念快速可视化探索
- 营销物料的系列化视觉方案

## 使用场景

当用户提出以下类型的请求时，自动加载并使用本技能：
- "给这个产品生成几个系列图"
- "把这个产品做成不同风格/配色/材质的版本"
- "帮我延展一下这个产品的系列"
- "基于这张图，生成XX个不同系列的产品图"
- "产品系列化视觉设计"

## 核心原则

### 1. 产品基因锁定（不可变项）
以下要素在所有系列图中必须保持一致，是产品的"身份识别锚点"：
- **造型轮廓**：整体形状、比例、体积感
- **关键结构**：部件划分、拼接方式、功能结构
- **品牌标识**：logo 位置、大小比例、印刷工艺特征
- **品类属性**：一看就知道是什么类型的产品

### 2. 系列维度可变（可变项）
系列之间的差异主要通过以下维度实现：
- **配色方案**：主色、辅色、点缀色的组合变化
- **材质肌理**：表面质感、光泽、触感、工艺
- **图案纹样**：表面装饰、纹理、印花
- **场景氛围**：背景环境、布光方式、道具搭配
- **风格调性**：极简/复古/科技/自然等整体气质
- **季节/主题**：限定款、季节款、联名款的主题表达

### 3. 系列家族感
- 同一系列的多张图（如有）在光影、构图、视角上保持一致
- 不同系列之间可以感知到"是同一个产品的不同版本"，而不是"不同产品"

### 4. 商业物料标准
- 光影合理，材质表现真实可信
- 透视正确，结构清晰
- 画面干净，主体突出
- 适合电商/品牌物料使用

## 工作流程

### 第一步：产品解构
对用户提供的产品参考图进行结构化分析，输出解构表。

**必须包含的字段**：
| 字段 | 说明 |
|---|---|
| 品类 | 产品属于什么大类（如护肤瓶身/运动鞋/家电/服装/食品包装） |
| 造型特征 | 整体轮廓、体积感、关键结构线条、主要部件 |
| 当前配色 | 主色/辅色/点缀色，尽量给出色值或精确描述 |
| 材质 | 主体材质、局部材质、表面工艺（如磨砂玻璃/哑光塑料/金属拉丝） |
| 品牌标识 | logo 位置、形态特征、大致比例 |
| 当前场景/风格 | 背景、布光、拍摄视角、整体调性 |
| **产品基因（不可变）** | 3-5 条最关键的识别要素，生成时必须锁定 |

### 第二步：知识库检索（可选但推荐）
如果用户配置了知识库（如品牌规范库、产品档案库、品类案例库），先检索相关信息：
- 品牌标准色值、VI 规范
- 产品多角度参考、材质工艺说明
- 历史生成的成功案例
- 同品类标杆参考

将检索到的关键信息补充到解构结果中，用于提升生成准确性。

### 第三步：系列方向提案
根据用户需求（或默认生成 4 个方向），输出系列方向提案表。

**每个方向必须包含**：
| 字段 | 说明 |
|---|---|
| 系列名称 | 如"深海系列""暖冬系列""赛博系列""自然系列" |
| 设计理念 | 1 句话概括这个系列的核心概念 |
| 配色方案 | 主色/辅色/点缀色 + 色值参考 |
| 材质变化 | 与原版的差异点 |
| 图案/纹理 | 新增或变化的表面装饰 |
| 场景氛围 | 背景、光影、道具 |
| 目标人群/季节 | 适用人群或季节主题 |

提案输出后，向用户确认方向，或说明"将按以上方向生成，如需调整请告知"。

### 第四步：生成系列图
对每个确认的系列方向，使用当前环境的图像生成能力生成产品图。

**生成 prompt 结构**（按此结构组装）：
```
主体描述：[品类] + [锁定造型描述，强调与参考图一致]
系列变化：[配色 + 材质 + 纹理的具体描述]
环境布置：[背景/场景/光影/视角]
风格调性：[整体气质关键词]
质量要求：商业产品摄影，高清细节，影棚布光，材质真实，8k
禁忌约束：不要改变产品造型，不要移动logo位置，不要改变结构比例
```

**生成策略**：
- 优先使用图生图/参考图模式，将原产品图作为参考，确保造型一致
- 如果只有文生图能力，在 prompt 中用精确的造型描述锚定产品形态
- 每个系列生成 1 张主图，视角和布光与原图保持一致以增强系列感

### 第五步：质量自检
生成完成后，对照以下清单逐项检查，向用户报告自检结果：

| 检查项 | 通过标准 |
|---|---|
| 造型一致性 | 产品轮廓、结构、比例与原图一致 |
| 品牌标识在位 | logo 位置、大小、形态正确 |
| 系列差异明显 | 不同系列之间视觉差异可感知 |
| 材质表现真实 | 材质质感可信，光影合理 |
| 画面质量 | 清晰、无明显 AI 瑕疵、主体突出 |
| 家族感 | 系列之间有统一的视觉语言 |

如果有明显不合格的，说明问题并提议重新生成或调整。

### 第六步：归档（可选）
如果用户有知识库，将本次生成的成功案例（系列图 + 对应 prompt + 自检结果）归档到知识库，供后续生成参考。

## 输入参数

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| 参考产品图 | 是 | - | 1 张或多张产品主图 |
| 系列方向 | 否 | 自动生成 4 个 | 逗号分隔的方向关键词，如"商务,潮流,环保,科技" |
| 系列数量 | 否 | 4 | 要生成的系列数量 |
| 背景类型 | 否 | 白底商业摄影 | 白底商业摄影 / 生活场景 / 概念背景 |
| 视角 | 否 | 与参考图一致 | 正面 / 45度 / 俯视 / 与参考图一致 |

## 输出格式

按以下顺序分块输出，使用表格和清晰的标题结构：

```
## 一、产品解构
[解构表]

## 二、系列方向提案
[方向1] 系列名称
  设计理念：...
  配色：...
  材质：...
  场景：...
[方向2...]

## 三、生成结果
[系列1名称]
[图片]
生成 prompt：...

[系列2名称]
...

## 四、质量自检报告
[自检表]
```

## 注意事项

1. **造型优先**：宁可系列差异小一些，也不能让产品造型漂移
2. **逐步收敛**：先出方向提案确认，再生图，避免一次性生成大量不合格图
3. **善用参考**：有参考图时优先用图生图模式，没有时用精确描述锚定
4. **诚实反馈**：如果当前生图能力不足以保持造型一致性，如实告知用户并建议替代方案
5. **知识库增强**：有知识库时务必先检索，色值、材质名、工艺词尽量用知识库中的真实描述
