# 示例：护肤精华瓶系列生成

## 输入

**参考图**：一张白色磨砂玻璃护肤精华瓶，圆柱形瓶身，银色旋盖，正面有品牌logo和产品名，白底影棚拍摄，45度视角。

**用户指令**：基于这张精华瓶图，生成 4 个系列。

---

## 输出示例

### 一、产品解构

| 字段 | 内容 |
|---|---|
| 品类 | 护肤精华瓶 |
| 造型特征 | 圆柱形瓶身，高瘦比例，银色旋盖，瓶肩略收，底部平底 |
| 当前配色 | 主色：磨砂白 / 辅色：银色瓶盖 / 点缀：黑色logo文字 |
| 材质 | 瓶身：磨砂玻璃 / 瓶盖：金属拉丝铝 / logo：丝网印刷 |
| 品牌标识 | 瓶身正面居中，logo在上，产品名在下，约占瓶身高度 1/3 |
| 当前场景 | 纯白色背景，影棚柔光，45度前视角 |
| **产品基因（不可变）** | 1. 圆柱形瓶身轮廓及高瘦比例<br>2. 银色旋盖造型及比例<br>3. 正面居中的品牌标识布局<br>4. 瓶肩微收、平底的结构特征 |

---

### 二、系列方向提案

#### 系列 1：深海系列
- **设计理念**：源自深海的静谧与滋养，深蓝调传递深层修护感
- **配色**：主色深海蓝 #0F4C75 / 辅色银色瓶盖 / 点缀金箔烫印
- **材质**：瓶身深海蓝磨砂玻璃，质感更温润
- **场景**：渐变深蓝背景，柔和顶光，水波纹投影

#### 系列 2：玫瑰金系列
- **设计理念**：轻奢优雅，玫瑰金调传递精致女性气质
- **配色**：主色裸粉 #F5E6E0 / 辅色玫瑰金瓶盖 / 点缀玫瑰金烫金
- **材质**：瓶身珠光粉色玻璃，微闪质感
- **场景**：浅米色背景，暖光，玫瑰花道具点缀

#### 系列 3：森系绿踪系列
- **设计理念**：天然植萃，有机纯净，传递自然成分理念
- **配色**：主色草木绿 #4A7C59 / 辅色原木色盖 / 点缀植物拓印纹理
- **材质**：瓶身哑光草木绿陶瓷质感
- **场景**：自然光影，绿叶背景，木质台面

#### 系列 4：黑金臻享系列
- **设计理念**：顶级奢宠，黑金配色传递高端抗老定位
- **配色**：主色曜石黑 #1A1A1A / 辅色金色瓶盖 / 点缀金色浮雕logo
- **材质**：瓶身黑色亮面玻璃，高反光质感
- **场景**：深灰渐变背景，聚光效果，金色光斑点缀
