# Topic to Video — 主题转抖音短视频

根据用户给定的主题，自动完成"脚本→音频→配图→字幕→视频→标题描述"的全流程，生成 1-3 分钟竖版短视频（1080x1920）。

## 整体流程

1. **需求理解** — 确认主题、时长、风格偏好
2. **脚本生成** — 撰写结构化分段脚本（JSON 格式）
3. **音视频生成** — 调用 `generate_video.py` 生成 TTS 音频 + 画面 + 合成视频
4. **标题与描述** — 生成适合抖音的标题和简介
5. **交付** — 输出视频文件、标题、描述

---

## Phase 1：需求理解

用户给出主题后，确认以下信息（如用户未明确，使用默认值）：

| 项目 | 默认值 | 说明 |
|------|--------|------|
| 时长 | 1-3 分钟 | 根据主题复杂度可调整 |
| 音色 | zh-CN-YunxiNeural（男声，活泼阳光） | 可选女声 zh-CN-XiaoxiaoNeural（温暖）或 zh-CN-YunyangNeural（男声，专业） |
| 风格 | 知识分享 | 画面为深色背景 + 标题 + 字幕 |

如用户只给了一个主题词，直接使用默认值开始，无需反复确认。

---

## Phase 2：脚本生成

### 脚本撰写原则

- **口语化**：适合听而不是读，避免书面长句
- **节奏感**：每段 3-5 句话，句式长短交替
- **信息密度**：每段聚焦一个要点，不贪多
- **开头抓人**：第一段用提问、反差或悬念开场
- **结尾有力**：最后一段给出观点、行动指引或金句
- **1-3 分钟视频**：总字数控制在 300-800 字

### 脚本输出格式

生成 JSON 文件保存到 workspace，格式如下：

```json
[
  {
    "title": "第一段标题（画面上方显示）",
    "text": "第一段正文，用于语音朗读和字幕显示。每句以句号结尾便于拆分。",
    "voice": "zh-CN-YunxiNeural"
  },
  {
    "title": "第二段标题",
    "text": "第二段正文...",
    "voice": "zh-CN-YunxiNeural"
  }
]
```

保存路径：`/sandbox/workspace/outputs/script.json`

脚本生成后，向用户展示脚本全文，让用户确认或修改。用户确认后再进入 Phase 3。

**这是一个确认门——必须等用户确认后才继续。**

## Phase 3：音视频生成

### 确保依赖就绪

运行前检查并安装必要依赖：

```bash
# 检查 ffmpeg
ffmpeg -version

# 检查 edge-tts
python3 -c "import edge_tts"

# 检查 Pillow
python3 -c "from PIL import Image"
```

如缺少依赖，先安装：
```bash
pip install edge-tts Pillow
apt-get install -y ffmpeg
```

### 运行生成脚本

```bash
python3 /sandbox/workspace/skills/topic-to-video/scripts/generate_video.py \
  /sandbox/workspace/outputs/script.json \
  /sandbox/workspace/outputs/output.mp4
```

脚本会自动完成：
1. 逐段生成 TTS 语音（edge-tts）
2. 为每句话生成画面帧（深色背景 + 标题 + 字幕）
3. 用 ffmpeg 将帧序列 + 音频合成为视频
4. 拼接所有段落

### 可用中文音色

| 音色 ID | 性别 | 风格 |
|---------|------|------|
| zh-CN-YunxiNeural | 男 | 活泼阳光（默认） |
| zh-CN-YunyangNeural | 男 | 专业稳重 |
| zh-CN-YunjianNeural | 男 | 激情有力 |
| zh-CN-XiaoxiaoNeural | 女 | 温暖知性 |
| zh-CN-XiaoyiNeural | 女 | 活泼可爱 |

生成过程中向用户报告进度（第 X/Y 段、总时长等）。

## Phase 4：标题与描述

视频生成后，为抖音平台撰写：

### 标题
- 20 字以内，含关键词
- 用数字、问号、反差制造好奇心
- 示例：`"3个让你效率翻倍的方法"、"为什么聪明人都在用这个策略"`

### 描述
- 50-100 字
- 包含核心观点摘要
- 加 3-5 个话题标签（#标签）
- 引导互动（"你觉得呢？"、"评论区告诉我"）

输出格式：
```
📌 标题：xxx
📝 描述：xxx #标签1 #标签2 #标签3
```

## Phase 5：交付

1. 通过 `provide_file` 提供视频下载链接
2. 一并输出标题和描述文案
3. 告知用户可调整的方向：音色、时长、脚本内容、画面风格

---

## 常见调整

| 用户说 | 操作 |
|--------|------|
| "换女声" | 将 voice 改为 zh-CN-XiaoxiaoNeural，重新生成 |
| "再长一点" | 扩充脚本段落或增加每段字数，目标 3-5 分钟 |
| "开头不够吸引人" | 重写第一段，用提问/反差/悬念开场 |
| "字幕太大/太小" | 修改 generate_video.py 中的 FONT_SIZE |
| "换背景色" | 修改 generate_video.py 中的 BG_COLOR |
| "加上背景音乐" | 用 ffmpeg 混入 BGM：`ffmpeg -i video.mp4 -i bgm.mp3 -filter_complex "[1:a]volume=0.3[bgm];[0:a][bgm]amix=inputs=2[a]" -map 0:v -map "[a]" -c:v copy output.mp4` |

## 工作流示例

**示例 1：简单主题**

> 用户："帮我做一个关于时间管理的短视频"

1. 直接使用默认配置（1-3分钟，男声，知识分享风格）
2. 生成 4-6 段脚本，覆盖：开头悬念 → 核心方法1 → 核心方法2 → 总结
3. 用户确认脚本后运行生成
4. 输出视频 + 标题 "3个时间管理技巧，每天多出2小时" + 描述

**示例 2：指定偏好**

> 用户："用女声做一个关于AI发展趋势的视频，2分钟左右"

1. 音色设为 zh-CN-XiaoxiaoNeural，目标 2 分钟（约 500 字）
2. 生成 4-5 段脚本，侧重趋势和观点
3. 用户确认后生成
4. 输出视频 + 标题 "2025年AI会怎样？这3个趋势你必须知道" + 描述
