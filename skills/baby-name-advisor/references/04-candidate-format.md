# 候选名字输出格式

## 整体输出结构

每次生成名字必须按以下四段式输出：

```
一、命名策略
二、候选名字（8-12 个）
三、Top 3 shortlist
四、下一轮迭代建议
```

---

## 一、命名策略

```markdown
### 已知条件
- 姓氏：
- 性别倾向：
- 其他明确输入：（季节/五行/生肖/辈分/地域/避讳等）

### 默认假设
- （信息不足时声明的假设，如未提供则跳过）

### 取名方式路由
- 主取名方式：
- 辅助参考：

### 命名主线
- 风格定位：
- 文化借鉴方向：

### 本轮规避点
- （谐音风险、避讳字、用户明确排除的风格等）
```

---

## 二、候选名字

每个候选名字按以下统一格式输出：

### 名字卡片模板

```markdown
### 候选 N：[完整姓名]

**拼音**：[标准拼音]  
**风格标签**：[2-3 个关键词，如：文雅、安定、书卷气]

#### 核心说明
- **取名方式**：[主方式] + [辅方式]
- **文化来源**：[典籍/气质/寓意来源，按出处表述规范]
- **寓意说明**：[核心寓意与价值取向，1-2 句]

#### 适配检查
- **天时**：[五行/生肖/季节适配，或标准表述]
- **地利**：[地域/方言适配，或标准表述]
- **人和**：[辈分/避讳/兄弟姐妹协调，或标准表述]
- **文脉**：[典籍/历史人物参考，或标准表述]
- **实用**：[发音/书写/国际化检查]

#### 推荐与注意
- **推荐理由**：[为什么适合当前家庭偏好]
- **注意点**：[潜在风险或局限]
```

---

## 三、Top 3 shortlist

```markdown
### 排序结果
1. **[第一名]**：一句话核心理由
2. **[第二名]**：一句话核心理由
3. **[第三名]**：一句话核心理由

### 排序依据
- **综合匹配度**：[与家庭偏好的整体契合程度]
- **音形义平衡**：[读音、书写、寓意的综合质量]
- **家庭偏好契合度**：[对用户明确要求的满足程度]
```

---

## 四、下一轮迭代建议

```markdown
- **更偏文雅**：可调整方向（如提高典籍密度、增加书卷气用字）
- **更偏现代**：可调整方向（如简化结构、降低古风感）
- **更偏独特**：可调整方向（如结构新鲜、气质清晰，不靠生僻字）
- **是否追加**：乳名 / 英文名 / 双语名 / 其他
```

---

## 条件性输出规则

### 五大维度标准表述

| 维度 | 用户提供信息时 | 未提供信息时 |
|------|----------------|--------------|
| **天时** | 五行属性分析、生肖宜忌检查、季节意象关联 | "未提供五行/生肖/季节信息，无明显冲克" |
| **地利** | 地域文化关联、方言读音检查 | "未提供出生地/祖籍，未特别适配地域" |
| **人和** | 辈分字使用、避讳检查、兄弟姐妹协调 | "无辈分字/避讳要求，未提供兄弟姐妹名字" |
| **文脉** | 典籍来源、历史人物气质联想 | "未特别要求典籍/人物参考，按寓意期望取名" |
| **实用** | 发音/书写/国际化检查结果（必输出） | 同左 |

### 实用适配（每个名字必输出）

- **发音**：普通话读音是否顺畅，有无负面谐音
- **书写**：笔画是否适中，有无生僻字
- **国际化**：拼音观感是否自然，英文转写是否别扭

---

## 注意点检查清单

生成每个名字时必须逐项检查：

- [ ] 无明显负面谐音
- [ ] 不过于生僻难写
- [ ] 与姓氏连读不拗口
- [ ] 不易与高频重名撞风格
- [ ] 不违反用户明确避讳

---

## 收敛 shortlist 要求

- 明确排序，而非平铺罗列
- 说明为什么更值得优先考虑
- 如果用户偏好"更文雅 / 更现代 / 更独特"，说明下一轮如何收窄
