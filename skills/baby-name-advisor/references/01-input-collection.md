# 极简输入收集

## 顾问开场

"取个好名字，我需要了解几个基本信息："

## 必须收集的信息

### 基础信息
```
姓氏：[必填]
性别：[男孩/女孩/中性]
```

### 核心偏好
```
想要什么感觉？
□ 文雅书香
□ 现代简约  
□ 传统稳重
□ 清新自然
□ 大气开阔
□ 其他：_______
```

### 特殊要求
```
有什么必须满足的吗？
□ 辈分字：_______
□ 五行偏好：_______
□ 生肖考虑：_______
□ 寓意期望：_______
□ 无特殊要求
```

## 默认假设

如果信息不足，采用以下默认假设：

```
未指定感觉偏好 → 现代简约风格，平衡传统与现代
未提供特殊要求 → 不做五行生肖适配，优先音形义平衡
未说明字数偏好 → 双字名为主，单字名为辅
```

## 快速决策

基于收集的信息，快速确定主取名方向：

| 用户偏好 | 主取名方式 | 辅助参考 |
|---------|-----------|---------|
| 文雅书香 | 文化典籍取材 | 寓意期望 |
| 现代简约 | 寓意期望 | 音形义平衡 |
| 传统稳重 | 辈分字派/寓意期望 | 文化典籍 |
| 清新自然 | 季节时令 | 文化典籍 |
| 大气开阔 | 历史人物典故 | 寓意期望 |

## 输入示例

### 标准输入
```
姓氏：林
性别：女孩
感觉偏好：文雅书香
特殊要求：无
```

### 复杂输入
```
姓氏：张
性别：男孩
感觉偏好：传统稳重
特殊要求：辈分字"文"，五行喜火
```

### 极简输入
```
姓氏：李，性别：女孩
```
→ 自动采用现代简约风格，生成8个候选

## 处理原则

1. **信息够用就开工**：不追求完美信息，有基础信息就开始
2. **明确说明假设**：告诉用户用了什么默认假设
3. **快速给出结果**：避免过度询问，先给第一轮建议
4. **支持迭代优化**：根据用户反馈调整方向

## 质量保证

- 即使信息简单，也要保证候选名字质量
- 默认假设要安全、稳妥、大众化
- 复杂需求要明确主次，不面面俱到
- 所有候选都要经过基本筛选（谐音、重名、书写等）
