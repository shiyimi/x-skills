# 输入收集与默认假设

## 顾问开场

在正式给名之前，先用专家顾问口吻完成以下动作：

- 复述已知条件，不机械重复用户原话，而是整理成命名判断依据。
- 明确本轮会优先考虑什么（姓氏搭配、文化底色、读音顺口、重名风险、国际化适配）。
- 如果信息缺失，直接声明本轮采用的默认假设，而不是停在单纯追问。
- 若用户明确要求"名人风""古籍风""成语风"，先说明将如何借鉴而非直接照搬。

## 优先收集的输入

### 基础信息（必填/高优）

| 维度           | 说明                   |
| -------------- | ---------------------- |
| 姓氏           | 必填，影响整体搭配     |
| 性别或性别倾向 | 影响用字倾向与风格路由 |
| 名字字数偏好   | 单字名 / 双字名        |

### 天时维度（出生时间相关）

| 维度          | 说明                                                      |
| ------------- | --------------------------------------------------------- |
| 出生季节      | 春/夏/秋/冬，影响季节意象用字（如春生、夏木、秋实、冬雪） |
| 出生月份/节气 | 更精细的时间意象（如正月、清明、霜降）                    |
| 五行偏好      | 金/木/水/火/土，或是否需要补某一行                        |
| 生肖          | 当年生肖及宜忌用字（如龙年宜水、宜大，忌小、忌困）        |
| 出生年月日时  | 用于八字推算（如用户提供）                                |

### 地利维度（地域文化相关）

| 维度         | 说明                                 |
| ------------ | ------------------------------------ |
| 出生地/祖籍  | 可用于地名意象或地域文化取名         |
| 方言考量     | 是否考虑粤语、闽南语、吴语等方言读音 |
| 地域审美偏好 | 不同地区对名字风格有不同偏好         |

### 人和维度（家族与社会相关）

| 维度         | 说明                                     |
| ------------ | ---------------------------------------- |
| 辈分字派     | 家族是否有辈分用字要求                   |
| 家族避讳     | 需要避开的字、音、谐音或家庭中已占用的字 |
| 兄弟姐妹名字 | 用于风格统一或互补检查                   |
| 父母期望     | 德行、健康、才华、志向、美好等寓意取向   |
| 纪念意义     | 是否需要纪念特殊事件、恩人、长辈         |

### 文脉维度（文化典籍相关）

| 维度         | 说明                                               |
| ------------ | -------------------------------------------------- |
| 风格偏好     | 文雅、诗意、现代、简洁、大气、书卷气、国际化、中性 |
| 寓意关键词   | 聪慧、平安、明朗、坚韧、温柔、自由等               |
| 文化参考     | 是否参考诗词、楚辞、论语、唐诗宋词等语料           |
| 历史名人偏好 | 是否希望借鉴某类历史人物的气质                     |

### 实用维度（日常使用相关）

| 维度     | 说明                                       |
| -------- | ------------------------------------------ |
| 发音考量 | 是否考虑普通话、粤语、闽南语或英文发音     |
| 书写要求 | 是否要求笔画简单、避免生僻字               |
| 附加需求 | 是否需要乳名、英文名、兄弟姐妹名字风格统一 |

## 信息缺失时的默认假设

如果缺失部分信息，按以下默认策略继续：

- 默认以"日常易用、音形义均衡、不过度生僻"为优先。
- 默认输出中文正式名候选。
- 默认不引入高生僻字和强命理结论。
- 默认给出稳妥型优先 + 少量风格化候选的组合。
- 默认不特别适配季节、五行、生肖（如用户未提供）。

## 使用提醒

- 如果用户一次只给了姓氏，也要先给出可用首版，而不是停在追问。
- 如果用户给了多个家庭成员名字，优先检查整体风格是否协调。
- 如果用户明确不喜欢某几个字或读音，后续候选中不要重复出现。
- 如果用户要求乳名或英文名，正式名完成后可追加一组配套方案。
- 如果用户提供了出生年月日时，可作为五行参考，但不宣称命理效果。
