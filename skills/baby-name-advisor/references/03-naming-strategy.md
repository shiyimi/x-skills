# 命名策略与风格路由

## 命名策略制定

在输出名字前，先用 3 到 5 句话总结：

- 当前已知偏好
- 姓氏特点分析及搭配原则
- 需要规避的风险（重点：谐音、声调、字形）
- 本轮命名的主风格路线
- 若存在假设，明确写出假设
- 若要引入历史名人、古籍、成语路线，说明准备从哪些文化源头借鉴

## 取名方式路由

根据用户输入，选择 1-2 种主要取名方式，其他作为辅助参考。

### 路由决策表

| 用户输入特征                   | 主取名方式            | 辅助参考             |
| ------------------------------ | --------------------- | -------------------- |
| 提到"诗经""楚辞""论语""古诗词" | 文化典籍取材          | 寓意期望、音形义平衡 |
| 提供出生年月日时或五行偏好     | 五行八字              | 生肖宜忌、季节时令   |
| 提到生肖或出生年份             | 生肖宜忌              | 五行八字、寓意期望   |
| 提供辈分字或族谱要求           | 辈分字派              | 寓意期望、音形义平衡 |
| 提到出生季节或月份             | 季节时令              | 文化典籍、寓意期望   |
| 提到"希望有寓意""期望孩子..."  | 寓意期望              | 文化典籍、音形义平衡 |
| 提到某类历史人物或时代风貌     | 历史人物典故          | 文化典籍、寓意期望   |
| 提到地名、纪念意义             | 地域文化/纪念         | 寓意期望、音形义平衡 |
| 信息极少或模糊                 | 寓意期望 + 音形义平衡 | 文化典籍（稳妥型）   |

### 多方式组合规则

- **主次分明**：确定 1-2 种主要方式，其他作为辅助
- **不冲突原则**：多种方式之间不应产生矛盾（如生肖忌用字与五行用字冲突时，以生肖忌用优先）
- **质量底线**：无论采用哪种方式，音形义平衡是基础
- **避免极端**：不为了"有典"而牺牲名字本身的顺口与现代可用性

## 八大取名方式详解

### 一、文化典籍取材

**适用场景**：用户明确提到文化底蕴、诗词气质、书卷气

**取材路线**：

- 《诗经》：温润、自然、含蓄 → 文雅诗意
- 《楚辞》：浪漫、开阔、志向 → 大气明朗
- 《论语》《孟子》：德行、品格、修养 → 书卷气
- 《道德经》：淡泊、自然、无为 → 文雅诗意
- 《周易》：变化、哲理、格局 → 大气明朗
- 唐诗宋词：意象丰富、节奏感强 → 文雅诗意/现代简洁

**使用原则**：

- 取其意境，不直接复刻原句
- 优先提取品格词、自然意象、德行取向
- 不编造具体篇名、章节、原句
- 兼顾现代适配性

### 二、五行八字

**适用场景**：用户提供出生年月日时或明确五行偏好

**五行用字规则**：
| 五行 | 偏旁部首 | 常用字举例 | 气质特点 |
|------|----------|------------|----------|
| 木 | 木、艹、竹 | 林、森、桐、芷、筠 | 生长、向上、温润 |
| 火 | 火、日、光 | 炎、煜、熙、明、晖 | 热情、明朗、活力 |
| 土 | 土、山、石 | 坤、培、垣、岩、磊 | 稳重、厚实、包容 |
| 金 | 金、钅、玉 | 铭、锐、锦、瑜、瑾 | 坚毅、珍贵、清正 |
| 水 | 水、氵、雨 | 涵、泽、清、润、霖 | 灵动、深邃、润泽 |

**使用原则**：

- 作为参考维度之一，不宣称命理改运效果
- 不输出强命理结论
- 与生肖宜忌冲突时，以生肖忌用优先

### 三、生肖宜忌

**适用场景**：用户提供出生年份或生肖

**常见生肖宜忌**：
| 生肖 | 宜用 | 忌用 |
|------|------|------|
| 鼠 | 米、豆、口、宀 | 马、火、刀 |
| 牛 | 草、禾、车、宀 | 羊、刀、心 |
| 虎 | 山、木、王、大 | 蛇、小、人 |
| 兔 | 草、禾、口、宀 | 酉、鸟、心 |
| 龙 | 水、雨、王、大 | 狗、小、口 |
| 蛇 | 草、木、口、宀 | 猪、亥、人 |
| 马 | 草、木、目、宀 | 鼠、子、水 |
| 羊 | 草、木、米、宀 | 牛、丑、刀 |
| 猴 | 木、禾、口、宀 | 虎、寅、火 |
| 鸡 | 米、豆、口、宀 | 兔、卯、刀 |
| 狗 | 人、口、宀、心 | 龙、辰、水 |
| 猪 | 草、木、口、宀 | 蛇、巳、刀 |

**使用原则**：

- 作为参考维度之一，不绝对化
- 与五行用字冲突时，以生肖忌用优先
- 不宣称生肖决定命运

### 四、辈分字派

**适用场景**：家族有辈分用字要求

**格式**：

- 姓 + 辈分字 + 个人字（如"张德明""德华""德辉"）
- 辈分字通常来自族谱中预先拟定的字辈诗

**使用原则**：

- 辈分字为硬性约束，不可替换
- 重点在个人字的选择上与辈分字搭配协调
- 与兄弟姐妹名字风格统一或互补

### 五、季节时令

**适用场景**：用户提供出生季节、月份或节气

**季节意象用字**：
| 季节 | 常用字 | 意象联想 |
|------|--------|----------|
| 春 | 春、芳、萌、荣、熙、暖 | 生机、希望、温暖 |
| 夏 | 夏、炎、荷、蝉、繁、茂 | 热烈、繁盛、活力 |
| 秋 | 秋、实、霜、雁、澄、朗 | 收获、清爽、高远 |
| 冬 | 冬、雪、梅、寒、凝、洁 | 纯净、坚韧、内敛 |

**使用原则**：

- 可结合当月节气、物候特征
- 不局限于季节字本身，可用季节意象
- 与五行八字可结合（如春属木、夏属火）

### 六、寓意期望

**适用场景**：用户提到"希望孩子...""期望..."或提供寓意关键词

**常见寓意分类**：
| 类别 | 常用字 | 寓意 |
|------|--------|------|
| 德行 | 仁、义、礼、智、信、德 | 品德高尚 |
| 健康 | 康、健、安、宁、泰 | 平安健康 |
| 才华 | 文、才、慧、敏、哲 | 聪明有才 |
| 志向 | 志、远、宏、图、鹏 | 志向远大 |
| 美好 | 美、丽、雅、秀、婉 | 容貌气质 |
| 坚韧 | 坚、毅、韧、刚、强 | 意志坚定 |
| 温柔 | 柔、婉、淑、静、娴 | 温柔贤淑 |
| 自由 | 飞、翔、逸、游、逍 | 自由洒脱 |

**使用原则**：

- 最基础的取名方式，可与其他任何方式组合
- 避免过度直白（如直接叫"聪明""美丽"）
- 通过意象、典故间接表达寓意更佳

### 七、历史人物典故

**适用场景**：用户提到某类历史人物、时代风貌或气质联想

**使用原则**：

- 关注姓名气质、时代风貌、人格联想与用字审美
- 输出时可说明"偏向沉稳书卷型""偏向明朗志向型""偏向温润君子型"等风格
- 不直接复刻高辨识度历史人物全名
- 借鉴气质与时代风貌，而非复制名字

### 八、其他方式

**地域文化**：

- 出生地、祖籍地的山川、河流、名胜意象
- 方言读音考量（普通话、粤语、闽南语、吴语等）
- 地域审美偏好

**纪念取名**：

- 纪念特殊事件、恩人、长辈
- 梦兆、抓周等传统方式

**使用原则**：

- 作为辅助参考，不单独作为主取名方式
- 需与音形义平衡原则结合

## 风格路由

### 文雅诗意

- 偏重含蓄、留白、书卷气
- 常见关键词：清、言、宁、知、若、安、和、宸、予、书
- 可优先从《诗经》、唐诗、宋词、古文意象中提炼温润、澄明、雅正的气质

### 现代简洁

- 偏重利落、清爽、辨识度高
- 优先考虑笔画适中、发音干净的搭配
- 可借鉴现代审美下仍保留古典底色的用字，避免过度网感或潮流词化

### 大气明朗

- 偏重开阔、积极、阳光、自信
- 适合希望名字更有外向能量感的场景
- 可参考历史人物名中的开阔感、志向感与正向品格，但避免直接复制著名人物名

### 中性国际化

- 偏重男女都适配、中文自然、英文转写不别扭
- 适合未来可能存在双语环境的场景
- 若提供英文名，优先保证中文本名与英文名气质一致，而非只做音近映射

## 推荐决策规则

- 如果用户只给模糊偏好，优先给一组稳妥型名字，再给少量风格化候选，不要一上来全走极端风格
- 如果用户强调文化底蕴，优先提高古籍意象和品格解释密度，而非提高生僻度
- 如果用户强调独特性，先从结构新鲜、气质清晰入手，不优先靠冷僻字制造差异
- 如果用户强调国际化，优先保证普通话读音顺畅、拼音观感自然、英文延展不拗口
- 如果用户强调家族传承，优先检查与兄弟姐妹、父母偏好、辈分字或家庭避讳的一致性
- 如果用户提供多种维度信息，按主次分明原则组合，不堆砌所有维度
