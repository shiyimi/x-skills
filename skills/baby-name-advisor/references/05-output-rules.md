# 出处表述与推荐决策

## 出处表述规范

### 基本表述原则

| 确认程度                       | 表述方式                                       |
| ------------------------------ | ---------------------------------------------- |
| 已确认到具体文本但未逐字核对   | "可联想到""常见于""取其意境"                   |
| 已确认到明确来源且上下文可支撑 | "参考""出自""化用"                             |
| 无法确认具体出处               | "借其文化气质""借其品格联想""借其历史人物风格" |

### 八大取名方式的出处表述规范

#### 1. 文化典籍取材

**正确表述**：

- "取自《诗经》中'XX'的意境"
- "参考《楚辞》的开阔气质"
- "化用《论语》'XX'的品格内涵"
- "借唐诗宋词的XX意象"

**错误表述**：

- "出自《诗经·XX篇》第X章"（未核实具体篇名）
- "此名直接引用古文原句"（未逐字核对）

#### 2. 五行八字

**正确表述**：

- "用字属水，可补足所需五行"
- "偏旁带氵，五行属水"
- "字形结构属木，呼应五行需求"
- "无明显五行冲克"

**错误表述**：

- "此名可改运"
- "命中缺水必须补水"
- "五行决定命运"

#### 3. 生肖宜忌

**正确表述**：

- "用字带宀，符合生肖宜用"
- "无明显生肖冲克"
- "字形结构适合当年生肖"
- "避免生肖忌用字"

**错误表述**：

- "此名旺生肖"
- "忌用字会带来厄运"
- "生肖决定运势"

#### 4. 辈分字派

**正确表述**：

- "包含辈分字'X'，符合族谱要求"
- "遵循家族字派序列"
- "兼顾辈分与寓意平衡"

**错误表述**：

- "辈分字决定命运"
- "必须严格按字派"

#### 5. 季节时令

**正确表述**：

- "取秋季'澄朗'意象"
- "呼应出生季节的清爽感"
- "借春夏秋冬的自然气质"
- "符合时令特征"

**错误表述**：

- "生于秋季必须用秋字"
- "季节决定性格"

#### 6. 寓意期望

**正确表述**：

- "寓意坚韧不拔"
- "寄托平安健康的期望"
- "体现德行修养的追求"
- "表达才华志向的期许"

**错误表述**：

- "此名保证孩子成功"
- "寓意决定人生"

#### 7. 历史人物典故

**正确表述**：

- "偏向沉稳书卷型气质"
- "借鉴XX时代的开阔风貌"
- "取其历史人物的品格内涵"
- "借其文化精神气质"

**错误表述**：

- "复刻XX名人的名字"
- "直接使用历史人物全名"

#### 8. 地域文化/纪念

**正确表述**：

- "取自出生地'XX'的文化意象"
- "纪念XX事件"
- "结合地域文化特色"
- "借地名文化内涵"

**错误表述**：

- "此地名带来好运"
- "地域决定命运"

### 禁止行为

- 不要伪造篇名、章节名、原句、作者上下文或时代背景
- 不要把未核实的内容说成确定事实
- 不要宣称命理改运效果
- 不要输出强命理结论
- 不要直接复刻高辨识度历史人物全名
- 不要为了"有典"而牺牲名字本身的顺口与现代可用性

## 推荐决策规则

### 基于八大取名方式的决策策略

| 用户输入特征                   | 主取名方式            | 辅助参考             | 输出策略                     |
| ------------------------------ | --------------------- | -------------------- | ---------------------------- |
| 提到"诗经""楚辞""论语""古诗词" | 文化典籍取材          | 寓意期望、音形义平衡 | 提高古籍意象密度，避免生僻字 |
| 提供出生年月日时或五行偏好     | 五行八字              | 生肖宜忌、季节时令   | 以五行补缺为主，不极端化     |
| 提到生肖或出生年份             | 生肖宜忌              | 五行八字、寓意期望   | 优先生肖适配，兼顾寓意       |
| 提供辈分字或族谱要求           | 辈分字派              | 寓意期望、音形义平衡 | 严格遵循字派，平衡寓意       |
| 提到出生季节或月份             | 季节时令              | 文化典籍、寓意期望   | 借季节意象，不强行用季节字   |
| 提到"希望有寓意""期望孩子..."  | 寓意期望              | 文化典籍、音形义平衡 | 明确寓意方向，避免空泛       |
| 提到某类历史人物或时代风貌     | 历史人物典故          | 文化典籍、寓意期望   | 借气质不复制，避免全名       |
| 提到地名、纪念意义             | 地域文化/纪念         | 寓意期望、音形义平衡 | 取文化意象，不直接用地名     |
| 信息极少或模糊                 | 寓意期望 + 音形义平衡 | 文化典籍（稳妥型）   | 稳妥型优先，少量风格化       |

### 用户偏好适配策略

| 用户偏好     | 具体策略                                           |
| ------------ | -------------------------------------------------- |
| 模糊偏好     | 稳妥型优先 + 少量风格化候选，不走极端              |
| 强调文化底蕴 | 提高古籍意象和品格解释密度，而非提高生僻度         |
| 强调独特性   | 结构新鲜、气质清晰入手，不靠冷僻字制造差异         |
| 强调国际化   | 保证普通话读音顺畅、拼音观感自然、英文延展不拗口   |
| 强调家族传承 | 检查与兄弟姐妹、父母偏好、辈分字或家庭避讳的一致性 |
| 提供多种维度 | 按主次分明原则组合，不堆砌所有维度                 |
| 强调五行平衡 | 以五行补缺为主，生肖宜忌为辅，不极端化             |
| 强调地域文化 | 结合出生地/祖籍意象，兼顾方言读音检查              |

## 多方式组合的表述规范

### 主次分明原则

当采用多种取名方式时，需明确说明主次关系：

- **主方式**：详细说明取材来源、取意方式
- **辅方式**：简要说明如何配合主方式
- **冲突处理**：如多种方式产生矛盾，说明以哪种为准及原因

### 常见组合表述模板

#### 文化典籍 + 五行八字

> "本名以文化典籍取材为主，取自《诗经》中'XX'的温润意境；同时考虑五行偏好，用字属水以补足所需。生肖方面无明显冲克。"

#### 五行八字 + 生肖宜忌

> "主要考虑五行补缺需求，用字属木以平衡所需；同时符合当年生肖宜用字型，无生肖冲克。文化寓意方面体现坚韧品格。"

#### 辈分字派 + 寓意期望

> "严格遵循家族字派要求，包含辈分字'X'；在此基础上寄托平安健康的期望，兼顾音形义平衡。"

#### 季节时令 + 文化典籍

> "呼应出生季节的清爽感，取秋季'澄朗'意象；同时化用唐诗宋词的开阔气质，避免直接使用季节字。"

#### 历史人物典故 + 寓意期望

> "借鉴XX时代的沉稳书卷型气质，取其历史人物的品格内涵；寄托德行修养的追求，避免直接复刻全名。"

#### 地域文化 + 寓意期望

> "取自出生地'XX'的文化意象，结合地域文化特色；寄托才华志向的期许，兼顾现代使用便利性。"

### 冲突处理原则

1. **安全优先**：辈分字派 > 生肖宜忌 > 五行八字
2. **文化优先**：文化典籍取材 > 寓意期望 > 音形义平衡
3. **实用优先**：音形义平衡 > 季节时令 > 历史人物典故
4. **明确说明**：如需妥协，必须说明取舍原因

## 输出风格参考

### 专家开场示例

> "你给的信息已经足够做第一轮筛选。我会先从姓氏搭配、整体气质、日常使用便利性三个维度来收窄，再根据你偏好的文化方向拆成两到三条命名路线。若某些出处无法精确核定，我会明确用'取其意境'或'借其气质'来表达，不会把未核实的典故写成确定出处。"

#### 示例1：文化典籍 + 五行八字

## 长期维护建议

- 每次新增能力后，至少用评测样例重新过一遍，确认没有破坏原有风格
- 若后续加入命理、生肖、五行类扩展，应与当前文化命名主线明确分层，避免混成单一口径
- 若后续补独立 evals 文件，优先把评测内容拆成结构化测试样例，而非重写一套新标准
- 定期更新生肖宜忌表，确保与当年生肖对应准确
