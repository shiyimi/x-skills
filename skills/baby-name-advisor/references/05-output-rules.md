# 出处表述与推荐决策

## 出处表述规范

| 确认程度                       | 表述方式                                       |
| ------------------------------ | ---------------------------------------------- |
| 已确认到具体文本但未逐字核对   | "可联想到""常见于""取其意境"                   |
| 已确认到明确来源且上下文可支撑 | "参考""出自""化用"                             |
| 无法确认具体出处               | "借其文化气质""借其品格联想""借其历史人物风格" |

### 八大取名方式的出处表述

| 取名方式         | 正确表述                                           | 错误表述                           |
| ---------------- | -------------------------------------------------- | ---------------------------------- |
| 文化典籍取材     | "取自《诗经》中'XX'的意境""参考《楚辞》的开阔气质" | "出自《诗经·XX篇》第X章"（未核实） |
| 五行八字         | "用字属水，可补足所需五行""偏旁带氵，五行属水"     | "此名可改运""命中缺水必须补水"     |
| 生肖宜忌         | "用字带宀，符合生肖宜用""无明显生肖冲克"           | "此名旺生肖""忌用字会带来厄运"     |
| 辈分字派         | "包含辈分字'X'，符合族谱要求"                      | "辈分字决定命运"                   |
| 季节时令         | "取秋季'澄朗'意象""呼应出生季节的清爽感"           | "生于秋季必须用秋字"               |
| 寓意期望         | "寓意坚韧不拔""寄托平安健康的期望"                 | "此名保证孩子成功"                 |
| 历史人物典故     | "偏向沉稳书卷型气质""借鉴XX时代的开阔风貌"         | "复刻XX名人的名字"                 |
| 地域文化/纪念    | "取自出生地'XX'的文化意象""纪念XX事件"             | "此地名带来好运"                   |

### 禁止行为

- 不要伪造篇名、章节名、原句、作者上下文或时代背景
- 不要把未核实的内容说成确定事实
- 不要宣称命理改运效果
- 不要输出强命理结论
- 不要直接复刻高辨识度历史人物全名
- 不要为了"有典"而牺牲名字本身的顺口与现代可用性

## 推荐决策规则

| 用户偏好         | 策略                                               |
| ---------------- | -------------------------------------------------- |
| 模糊偏好         | 稳妥型优先 + 少量风格化候选，不走极端              |
| 强调文化底蕴     | 提高古籍意象和品格解释密度，而非提高生僻度         |
| 强调独特性       | 结构新鲜、气质清晰入手，不靠冷僻字制造差异         |
| 强调国际化       | 保证普通话读音顺畅、拼音观感自然、英文延展不拗口   |
| 强调家族传承     | 检查与兄弟姐妹、父母偏好、辈分字或家庭避讳的一致性 |
| 提供多种维度     | 按主次分明原则组合，不堆砌所有维度                 |
| 强调五行平衡     | 以五行补缺为主，生肖宜忌为辅，不极端化             |
| 强调地域文化     | 结合出生地/祖籍意象，兼顾方言读音检查              |

## 多方式组合的表述规范

当采用多种取名方式时，需明确说明主次关系：

- **主方式**：详细说明取材来源、取意方式
- **辅方式**：简要说明如何配合主方式
- **冲突处理**：如多种方式产生矛盾，说明以哪种为准及原因

示例：

> "本名以文化典籍取材为主，取自《诗经》中'XX'的温润意境；同时考虑五行偏好，用字属水以补足所需。生肖方面无明显冲克。"

## 输出风格参考

### 专家开场示例

> "你给的信息已经足够做第一轮筛选。我会先从姓氏搭配、整体气质、日常使用便利性三个维度来收窄，再根据你偏好的文化方向拆成两到三条命名路线。若某些出处无法精确核定，我会明确用'取其意境'或'借其气质'来表达，不会把未核实的典故写成确定出处。"

### 候选解释示例

- **名字**：知宁
- **拼音**：zhī níng
- **风格标签**：文雅、安定、书卷气
- **取名方式**：寓意期望 + 文化典籍
- **文化来源或联想**：可联想到古籍中"知"与"宁"所代表的明辨、自持、安宁气质
- **寓意说明**：强调内在清明与心性安稳
- **与姓氏搭配分析**：与"林"连读轻盈，不压姓，也不显得拖沓
- **日常使用分析**：常见字组合，辨识度够用，书写和认读成本低
- **天时适配**：未提供五行偏好，未特别适配五行；未提供生肖信息，无明显冲克
- **人和适配**：无辈分字要求；无避讳要求
- **推荐理由**：适合希望女孩名字温柔而不弱、安静但不寡淡的方向
- **注意点**：若家庭希望更强烈的明艳感，这个方向会偏含蓄

## 长期维护建议

- 每次新增能力后，至少用评测样例重新过一遍，确认没有破坏原有风格
- 若后续加入命理、生肖、五行类扩展，应与当前文化命名主线明确分层，避免混成单一口径
- 若后续补独立 evals 文件，优先把评测内容拆成结构化测试样例，而非重写一套新标准
- 定期更新生肖宜忌表，确保与当年生肖对应准确
