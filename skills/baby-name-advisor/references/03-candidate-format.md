# 候选格式与输出结构

## 候选名字统一格式

每个名字至少包含以下字段：

- **名字**：完整姓名（姓 + 名）
- **拼音**：标准拼音
- **风格标签**：2-3 个风格关键词
- **文化来源或联想**：说明借鉴方向或气质来源
- **寓意说明**：核心寓意与价值取向
- **与姓氏搭配分析**：连读顺畅度、音韵协调性
- **日常使用分析**：书写成本、辨识度、误读风险
- **推荐理由**：为什么适合当前家庭偏好
- **注意点**：潜在风险或局限

## 注意点检查维度

- 是否有明显负面谐音
- 是否过于生僻难写
- 是否和姓氏连读拗口
- 是否容易与高频重名撞风格
