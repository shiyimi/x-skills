# 系列图生成 Prompt 模板

使用此模板组装每个系列的生成 prompt。根据解构结果和系列方向填充占位符。

---

## 模板：通用产品系列图生成

```
一张[品类名称]的商业产品摄影图，[视角描述]，[背景类型]。

【产品造型 - 必须严格保持】
[产品基因描述，逐条列出不可变项]
- 造型轮廓：[描述]
- 关键结构：[描述]
- 品牌标识：[描述 - 位置/大小/形态]
- 整体比例：[描述]

【系列变化 - 本系列专属】
配色方案：
- 主色：[颜色名 + 色值]
- 辅色：[颜色名 + 色值]
- 点缀色：[颜色名 + 色值]

材质变化：
- 主体材质：[材质描述]
- 表面工艺：[工艺描述]
- 光泽质感：[光泽描述]

图案/纹理：
[图案描述，如无则写"无额外图案"]

【环境与光影】
背景：[背景描述]
布光：[布光方式，如影棚柔光、自然光、赛博霓虹]
视角：[视角描述]
构图：[构图描述]

【风格调性】
整体风格：[风格关键词，如极简现代、自然有机、未来科技、复古经典]
目标人群：[人群描述]
季节/主题：[季节或主题，如非限定款可省略]

【质量要求】
商业产品摄影，8K超高清，极致细节，专业影棚布光，材质表现真实，
光影自然，结构清晰，主体突出，画面干净，适合电商展示

【禁忌 - 严格遵守】
- 不要改变产品的造型轮廓和结构比例
- 不要移动或改变品牌标识的位置和形态
- 不要添加额外的产品部件
- 不要改变产品的整体尺寸和比例
- 不要出现文字错误或logo变形
```

---

## 使用说明

1. 将 `[占位符]` 替换为从解构结果和系列提案中提取的具体描述
2. 产品造型部分越精确，生成一致性越好
3. 禁忌部分务必保留，提醒模型不要改动核心识别要素
4. 根据实际生图引擎的能力，适当调整 prompt 长度和细节程度
